Camera System Design & Implementation Guide

Document Date: May 15, 2026
Purpose: Full specification for porting the Escape camera system (ShiftLock + CameraBoom + optional Spectator) to another Roblox project.
Target Audience: AI agents recreating this system in a new codebase.

System Overview​

The camera system comprises two core components and one optional advanced feature:

ComponentPurposeRequiredDependencies
ShiftLock CameraToggle between dynamic camera (locked center, autorotate) and free camera (Roblox default)✅ YesTweenService (or MotionMaster), UserInputService, ContextActionService
CameraBoomPrevent camera clipping through walls via raycast occlusion detection✅ YesRaycasting, RunService
Spectator ModePost-death freelook with player focus cycling and idle orbit camera❌ OptionalAll of above + advanced state management

Key Behaviors​

ShiftLock Mode (Dynamic Camera):

  • Mouse locked to center of screen (Enum.MouseBehavior.LockCenter)
  • Humanoid.AutoRotate disabled; player rotates to face movement direction
  • Camera offset to right shoulder (configurable)
  • Smooth tweening of offset transitions (~0.2s)

Free Camera Mode (Default):

  • Mouse behavior: Enum.MouseBehavior.Default
  • Humanoid.AutoRotate enabled (Roblox default)
  • No camera offset
  • Smooth tween back to zero offset

CameraBoom (Always Active):

  • Raycasts from camera focus/HRP to camera position
  • Detects wall occlusion, dynamically clamps CameraMaxZoomDistance
  • Different max distances for ShiftLock vs Free mode
  • Smooth lerping of zoom distance (no snapping)
  • Respects CanCollide property

Architecture​

Signal Flow Diagram​

┌─ Input (Alt / ButtonL3)
│
├─→ UserInputService → ToggleShiftLock action
│
├─→ Signals.OnShiftLockToggled
│   ├─→ ShiftLockController updates humanoid.CameraOffset (tween)
│   ├─→ ShiftLockController updates humanoid.AutoRotate
│   ├─→ ShiftLockController updates UserInputService.MouseBehavior
│   └─→ CameraBoomController listens & adjusts max zoom
│
└─ Per-RenderStep
    ├─→ ShiftLockController: autorotate player if moving + shift lock active
    └─→ CameraBoomController: raycast & clamp zoom distance

File Structure (Core Only)​

StarterPlayer/
  StarterPlayerScripts/
    ShiftLockController.client.luau     (Input + camera toggle logic)
    CameraBoomController.client.luau    (Occlusion detection)

ReplicatedStorage/
  Shared/
    Configs/
      ShiftLockConfig.luau              (All tunable parameters)
    Signals.luau                        (Must have OnShiftLockToggled signal)

Dependencies (What Must Already Exist)​

  1. Signals module (ReplicatedStorage/Shared/Signals.luau)

    • Must expose: OnShiftLockToggled Signal
    • If using spectator mode: also OnSpectatorModeChanged, OnCrouchToggled

  2. TweenService (Roblox built-in) or MotionMaster equivalent

    • Animate camera offset transitions
    • In spec, uses generic Roblox TweenService — swap with MotionMaster as needed

  3. Services

    • RunService (RenderStep binding)
    • UserInputService (mouse behavior, input detection)
    • ContextActionService (input action binding)
    • Players (local player, character access)

Core System: ShiftLock + CameraBoom​

Config File: ShiftLockConfig.luau​

Location: ReplicatedStorage/Shared/Configs/ShiftLockConfig.luau

--!strict
--!optimize 2
--!native

return {
	-- ShiftLock Toggle Settings
	DefaultShiftLock = true,                  -- Start in dynamic camera mode
	ShiftLockOffset = Vector3.new(0.5, 0.3, 0), -- Right-shoulder offset
	ShiftLockBindsPC = { Enum.KeyCode.LeftAlt },      -- Toggle key (PC)
	ShiftLockBindsConsole = { Enum.KeyCode.ButtonL3 }, -- Toggle key (console)
	CreateMobileButton = true,               -- Show mobile UI button
	
	-- Player Rotation (autorotate when moving)
	RotationLerpSpeed = 0.4,                 -- Lerp alpha per frame (0-1 range)
	
	-- CameraBoom Settings (wall collision)
	CameraMinZoomDistance = 6,               -- Closest camera can get
	DynamicCameraMaxZoomDistance = 9,        -- Max zoom in ShiftLock mode
	DefaultCameraMaxZoomDistance = 9,        -- Max zoom in free camera mode
	BoomEnabled = true,                      -- Toggle boom system on/off
	BoomBuffer = 0.5,                        -- Buffer distance from wall hit
	BoomSmoothingSpeed = 10,                 -- Zoom lerp speed (units/sec)
}

Config Notes:

  • ShiftLockOffset: Position relative to character center. Vector3.new(0.5, 0.3, 0) = 0.5 studs right, 0.3 up, centered depth.
  • RotationLerpSpeed: Higher = snappier rotation. Recommended 0.3–0.5.
  • BoomSmoothingSpeed: Higher = faster zoom transitions. Recommended 8–12.

ShiftLockController.client.luau​

Location: StarterPlayer/StarterPlayerScripts/ShiftLockController.client.luau

--!strict
--!optimize 2
--!native

--[[
	ShiftLockController (Client Script)
	
	Toggles between dynamic camera (locked center, autorotate) and
	free camera (Roblox default). Dynamic camera offsets to right shoulder.
	
	Signals used:
	  - OnShiftLockToggled: Fire when toggling mode
	  - OnSpectatorModeChanged: Skip input if spectating (if using spectator)
	  - OnCrouchToggled: Skip autorotate when crouching (if using crouch)
	
	Dependencies:
	  - TweenService or equivalent tween system
	  - UserInputService, ContextActionService, RunService
	  - ShiftLockConfig
	  - Signals with OnShiftLockToggled
]]

local RunService = game:GetService("RunService")
local UserInputService = game:GetService("UserInputService")
local ContextActionService = game:GetService("ContextActionService")
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Shared = ReplicatedStorage:WaitForChild("Shared")
local ShiftLockConfig = require(Shared.Configs:WaitForChild("ShiftLockConfig"))
local Signals = require(Shared:WaitForChild("Signals"))

local player = Players.LocalPlayer
assert(player, "LocalPlayer is nil")

-- State tracking
local isDynamicCameraActive = ShiftLockConfig.DefaultShiftLock
local currentHumanoid: Humanoid? = nil
local activeTween: any = nil
local isCrouching = false
local isSpectating = false

-- Listen for crouch (if crouch system exists in target project)
if Signals:FindFirstChild("OnCrouchToggled") or pcall(function() return Signals.OnCrouchToggled end) then
	pcall(function()
		Signals.OnCrouchToggled:Connect(function(crouching: boolean)
			isCrouching = crouching
		end)
	end)
end

-- Listen for spectator mode (if spectator system exists)
if pcall(function() return Signals.OnSpectatorModeChanged end) then
	pcall(function()
		Signals.OnSpectatorModeChanged:Connect(function(spectating: boolean, _downed: boolean)
			isSpectating = spectating
		end)
	end)
end

-- Initialize mouse visibility
UserInputService.MouseIconEnabled = not isDynamicCameraActive

-- ============================================================================
-- Toggle ShiftLock Input Handler
-- ============================================================================

local function toggleDynamicCamera(_actionName: string, inputState: Enum.UserInputState, _inputObject: InputObject?)
	if isSpectating then
		return
	end
	if inputState == Enum.UserInputState.Begin then
		isDynamicCameraActive = not isDynamicCameraActive
		Signals.OnShiftLockToggled:Fire(isDynamicCameraActive)
		
		UserInputService.MouseIconEnabled = not isDynamicCameraActive
		
		local character = player.Character
		local humanoid = character and character:FindFirstChildOfClass("Humanoid")
		
		if isDynamicCameraActive then
			-- Entering dynamic camera mode
			UserInputService.MouseBehavior = Enum.MouseBehavior.LockCenter
			
			if humanoid and not isCrouching then
				if activeTween then
					activeTween:Cancel()
				end
				activeTween = game:GetService("TweenService"):Create(
					humanoid,
					TweenInfo.new(0.2, Enum.EasingStyle.Sine, Enum.EasingDirection.Out),
					{ CameraOffset = ShiftLockConfig.ShiftLockOffset }
				)
				if activeTween then
					activeTween:Play()
				end
			end
		else
			-- Exiting dynamic camera mode (free camera)
			UserInputService.MouseBehavior = Enum.MouseBehavior.Default
			
			if humanoid then
				if activeTween then
					activeTween:Cancel()
				end
				activeTween = game:GetService("TweenService"):Create(
					humanoid,
					TweenInfo.new(0.2, Enum.EasingStyle.Sine, Enum.EasingDirection.Out),
					{ CameraOffset = Vector3.zero }
				)
				if activeTween then
					activeTween:Play()
				end
			end
		end
	end
end

-- Bind toggle action to input keys
local binds = {}
for _, bind in ipairs(ShiftLockConfig.ShiftLockBindsPC) do
	table.insert(binds, bind)
end
for _, bind in ipairs(ShiftLockConfig.ShiftLockBindsConsole) do
	table.insert(binds, bind)
end

ContextActionService:BindAction("ToggleShiftLock", toggleDynamicCamera, ShiftLockConfig.CreateMobileButton, unpack(binds))

if ShiftLockConfig.CreateMobileButton then
	ContextActionService:SetTitle("ToggleShiftLock", "Lock")
	task.wait(1)
	ContextActionService:SetPosition("ToggleShiftLock", UDim2.fromScale(0.5, 0.1))
end

-- ============================================================================
-- Per-RenderStep Updates
-- ============================================================================

RunService:BindToRenderStep("ShiftLockUpdate", Enum.RenderPriority.Camera.Value + 1, function()
	if isSpectating then
		return
	end
	
	local character = player.Character
	if not character then
		return
	end
	
	local humanoid = character:FindFirstChildOfClass("Humanoid")
	local hrp = character:FindFirstChild("HumanoidRootPart")
	
	if not humanoid or not hrp or not humanoid:IsA("Humanoid") or not hrp:IsA("BasePart") then
		return
	end
	
	-- Track humanoid changes (respawn detection)
	if currentHumanoid ~= humanoid then
		currentHumanoid = humanoid
		if isDynamicCameraActive and not isCrouching then
			humanoid.CameraOffset = ShiftLockConfig.ShiftLockOffset
		end
	end
	
	if isDynamicCameraActive then
		-- Dynamic camera mode: locked center, autorotate
		humanoid.AutoRotate = false
		UserInputService.MouseBehavior = Enum.MouseBehavior.LockCenter
		
		-- Don't apply offset if crouching (crouch has its own offset)
		if not isCrouching then
			humanoid.CameraOffset = ShiftLockConfig.ShiftLockOffset
		end
		
		-- Autorotate player to face movement direction
		local moveDirection = humanoid.MoveDirection
		local moveMag = moveDirection.Magnitude
		
		if moveMag > 0.1 then
			local targetYaw = math.atan2(-moveDirection.X, -moveDirection.Z)
			local targetCFrame = CFrame.new(hrp.Position) * CFrame.Angles(0, targetYaw, 0)
			hrp.CFrame = hrp.CFrame:Lerp(targetCFrame, ShiftLockConfig.RotationLerpSpeed)
		end
	else
		-- Free camera mode: standard Roblox behavior
		humanoid.AutoRotate = true
		if UserInputService.MouseBehavior == Enum.MouseBehavior.LockCenter then
			UserInputService.MouseBehavior = Enum.MouseBehavior.Default
		end
	end
end)

ShiftLockController Implementation Notes:

  1. Tween System: Uses game:GetService("TweenService"):Create(). For MotionMaster swap, replace the Create/Play calls with your MotionMaster API.

  2. Crouch Integration: Code checks for OnCrouchToggled signal and skips camera offset if crouching. If your target project doesn't have crouch, these checks become no-ops safely.

  3. Spectator Integration: Skips input processing if isSpectating == true. Spectator controller sets this signal.

  4. Autorotate Lerp: RotationLerpSpeed controls how snappy the player rotation is when moving. Uses CFrame:Lerp() which is frame-rate dependent by design (multiplied by speed constant to normalize).

  5. RenderPriority: Binds at Camera.Value + 1 so it runs after default camera but before CameraBoom.

CameraBoomController.client.luau​

Location: StarterPlayer/StarterPlayerScripts/CameraBoomController.client.luau

--!strict
--!optimize 2
--!native

--[[
	CameraBoomController (Client Script)
	
	Prevents camera from clipping through walls by dynamically clamping
	Player.CameraMaxZoomDistance based on raycast occlusion detection.
	Works in both dynamic camera and free camera modes.
	
	Signals used:
	  - OnShiftLockToggled: Adjust max zoom based on current mode
	
	Dependencies:
	  - RunService for RenderStep binding
	  - Raycasting (workspace:Raycast)
	  - ShiftLockConfig
	  - Signals with OnShiftLockToggled
]]

local RunService = game:GetService("RunService")
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Shared = ReplicatedStorage:WaitForChild("Shared")
local ShiftLockConfig = require(Shared.Configs:WaitForChild("ShiftLockConfig"))
local Signals = require(Shared:WaitForChild("Signals"))

local player = Players.LocalPlayer
assert(player, "LocalPlayer is nil")

local camera = workspace.CurrentCamera
assert(camera, "CurrentCamera is nil")

-- State tracking
local isDynamicCamera = ShiftLockConfig.DefaultShiftLock
local currentDistanceTarget: number = ShiftLockConfig.DynamicCameraMaxZoomDistance
local currentDistance: number = ShiftLockConfig.DynamicCameraMaxZoomDistance

-- Listen for ShiftLock toggle
Signals.OnShiftLockToggled:Connect(function(active: boolean)
	isDynamicCamera = active
end)

-- ============================================================================
-- Helper Functions
-- ============================================================================

local function getMaxDistanceForMode(): number
	if isDynamicCamera then
		return ShiftLockConfig.DynamicCameraMaxZoomDistance
	else
		return ShiftLockConfig.DefaultCameraMaxZoomDistance
	end
end

-- ============================================================================
-- Per-RenderStep Boom Update
-- ============================================================================

RunService:BindToRenderStep("CameraBoom", Enum.RenderPriority.Camera.Value, function(dt)
	if not ShiftLockConfig.BoomEnabled then
		return
	end
	
	local character = player.Character
	if not character then
		return
	end
	
	local hrp = character:FindFirstChild("HumanoidRootPart")
	if not hrp or not hrp:IsA("BasePart") then
		return
	end
	
	-- Source point: camera focus if set, otherwise HRP
	local origin: Vector3
	if camera.Focus then
		origin = camera.Focus.Position
	else
		origin = hrp.Position
	end
	
	local cameraPos = camera.CFrame.Position
	local direction = cameraPos - origin
	local camDistance = direction.Magnitude
	
	-- Skip if camera is too close to origin (avoid division by near-zero)
	if camDistance < 0.01 then
		return
	end
	
	direction = direction / camDistance
	
	-- Raycast from origin to camera position, excluding character
	local rayParams = RaycastParams.new()
	rayParams.FilterType = Enum.RaycastFilterType.Exclude
	rayParams.FilterDescendantsInstances = { character }
	rayParams.RespectCanCollide = true
	
	local rayResult = workspace:Raycast(origin, direction * camDistance, rayParams)
	
	if rayResult then
		-- Hit something: clamp zoom to prevent clipping
		local hitDistance = (rayResult.Position - origin).Magnitude
		local clampedDistance = math.max(ShiftLockConfig.CameraMinZoomDistance, hitDistance - ShiftLockConfig.BoomBuffer)
		currentDistanceTarget = math.min(getMaxDistanceForMode(), clampedDistance)
	else
		-- No hit: restore max distance for current mode
		currentDistanceTarget = getMaxDistanceForMode()
	end
	
	-- Smooth lerp to target distance (frame-rate normalized)
	local lerpFactor = math.min(1, dt * ShiftLockConfig.BoomSmoothingSpeed)
	currentDistance = currentDistance + (currentDistanceTarget - currentDistance) * lerpFactor
	
	-- Apply to player's camera zoom settings
	player.CameraMinZoomDistance = ShiftLockConfig.CameraMinZoomDistance
	player.CameraMaxZoomDistance = currentDistance
end)

CameraBoomController Implementation Notes:

  1. Raycast Origin: Uses camera.Focus.Position if available (preferred), falls back to HRP. Camera focus is where the camera is "looking at."

  2. Filter: Excludes the player's own character so it doesn't raycast against itself.

  3. RespectCanCollide: Only hits parts with CanCollide=true, so invisible triggers or CanCollide=false props don't block the camera.

  4. Buffer Distance: BoomBuffer adds a small safety margin so camera doesn't touch the hit surface.

  5. Smooth Lerp: Uses dt (deltaTime) to normalize movement across frame rates. Higher BoomSmoothingSpeed = faster transitions.

  6. RenderPriority: Binds at Camera.Value (same as default camera) so it runs before ShiftLockController. This ensures zoom is clamped before other camera logic.

Optional Layer: Spectator Mode​

Status: Optional, documented for future implementation. Do NOT implement in initial core system.

This section describes the Spectator subsystem for reference. Implement only after core ShiftLock + Boom is working and tested.

Overview​

Spectator mode activates when the local player dies or is downed (ragdoll state). Player can:

  • Watch other alive players with smooth camera tweens
  • Cycle between players with Q/E (or L2/R2 on console)
  • Orbit an idle camera if all players are dead
  • Auto-switch to first alive player after a delay when permanently dead

Files Required​

StarterPlayer/
  StarterPlayerScripts/
    SpectatorController.client.luau

ReplicatedStorage/
  Shared/
    Configs/
      SpectatorConfig.luau
      (also requires RagdollWrapper in Shared/)

Config File: SpectatorConfig.luau​

Location: ReplicatedStorage/Shared/Configs/SpectatorConfig.luau

--!strict
--!optimize 2
--!native

return {
	-- Keys for cycling spectate targets
	SwitchKeysPC = { Enum.KeyCode.Q, Enum.KeyCode.E },
	SwitchKeysConsole = { Enum.KeyCode.ButtonL2, Enum.KeyCode.ButtonR2 },
	SwitchCooldown = 0.5,
	
	-- Camera tween settings when following a player
	CameraTweenDuration = 0.3,
	CameraMinDistance = 2,
	CameraMaxDistance = 20,
	EasingStyle = "Quad",
	EasingDirection = "Out",
	
	-- Seconds after permanent death before auto-switching to another player
	DeadDelayBeforeAutoSwitch = 3.0,
	
	-- WAITING camera (no alive players): slow orbit for visual feedback
	WaitingPanRadius = 6,
	WaitingPanSpeed = 0.05, -- radians/second
	
	-- Backstop polling cadence for alive-player list (safety net)
	ValidationTickInterval = 0.5,
}

Integration Notes​

Signals Required:

  • OnSpectatorModeChanged — Fire(spectating: boolean, downed: boolean)
  • OnSpectatorFocusChanged — Fire(targetName: string)
  • OnHealthChanged — Fire(health, maxHealth, lives)
  • OnDownedStateChanged — Fire(downed: boolean)

Dependencies:

  • RagdollWrapper module (must exist in ReplicatedStorage/Shared/)
  • All core ShiftLock + Boom systems
  • TweenService (same as core)

When to Add:

  1. Only after core camera is fully working
  2. Requires a working ragdoll system (health/downed state)
  3. Should be tested with multiple players

Integration Guide​

Step-by-Step Setup (Core Only)​

1. Create Config File​

Create ReplicatedStorage/Shared/Configs/ShiftLockConfig.luau with the config code from ShiftLockConfig.luau.

2. Create ShiftLockController​

Create StarterPlayer/StarterPlayerScripts/ShiftLockController.client.luau with the code from ShiftLockController.client.luau.

If using MotionMaster instead of TweenService: Replace this block:

activeTween = game:GetService("TweenService"):Create(
	humanoid,
	TweenInfo.new(0.2, Enum.EasingStyle.Sine, Enum.EasingDirection.Out),
	{ CameraOffset = ShiftLockConfig.ShiftLockOffset }
)
if activeTween then
	activeTween:Play()
end

With your MotionMaster equivalent (example):

activeTween = MotionMaster.New(humanoid, 0.2)
	:Property("CameraOffset", ShiftLockConfig.ShiftLockOffset)
	:Easing("Sine", "Out")
	:Start()

3. Create CameraBoomController​

Create StarterPlayer/StarterPlayerScripts/CameraBoomController.client.luau with the code from CameraBoomController.client.luau.

4. Verify Signals Module​

Ensure ReplicatedStorage/Shared/Signals.luau has the OnShiftLockToggled signal. If not, add it:

-- In Signals.luau
local Signal = require(script.Parent:WaitForChild("Signal")) -- or your signal library

return {
	OnShiftLockToggled = Signal.new(),
	-- ... other signals
}

5. Test in Studio​

  1. In Roblox Studio, play the game
  2. Press Alt (PC) or ButtonL3 (console) to toggle dynamic camera
  3. Verify:
    • Mouse locks to center when enabled
    • Player rotates to face movement direction
    • Camera smoothly tweens to/from offset
    • Camera doesn't clip through walls

6. Add to Spectator (Later)​

Only after core is working:

  1. Create SpectatorConfig.luau
  2. Create SpectatorController.client.luau (refer to original Escape codebase)
  3. Wire OnDownedStateChanged signal
  4. Test multi-player death/spectate flow

Troubleshooting​

Camera Jumps When Toggling ShiftLock​

Cause: Humanoid.CameraOffset isn't being set before tween starts.
Fix: In ShiftLockController, ensure humanoid.CameraOffset is set immediately on humanoid change:

if currentHumanoid ~= humanoid then
    currentHumanoid = humanoid
    if isDynamicCameraActive and not isCrouching then
        humanoid.CameraOffset = ShiftLockConfig.ShiftLockOffset  -- Set immediately
    end
end

Tween Doesn't Animate​

Cause: TweenService not available, or MotionMaster swap missing.
Fix: Verify you're using the correct tween API for your project:

  • If Roblox TweenService: game:GetService("TweenService"):Create()
  • If MotionMaster: check library documentation for New() method signature

Player Doesn't Rotate When Moving in ShiftLock​

Cause: RotationLerpSpeed too low, or humanoid.MoveDirection is zero.
Fix:

  • Increase RotationLerpSpeed in ShiftLockConfig (try 0.6–0.8)
  • Verify humanoid.MoveDirection is being read (add debug print)

Camera Still Clips Through Walls​

Cause: BoomEnabled = false, or raycast filter isn't working.
Fix:

  1. Check ShiftLockConfig.BoomEnabled = true
  2. Verify wall parts have CanCollide = true
  3. Check filter instances (should be { character })
  4. Lower BoomBuffer if camera still touches walls (default 0.5)

Mobile Button Doesn't Appear​

Cause: CreateMobileButton = false in config.
Fix: Set to true, or adjust position with ContextActionService:SetPosition().

Spectator Mode Never Activates (Future Issue)​

Cause: RagdollWrapper.OnRagdollApplied signal not firing.
Fix:

  • Verify RagdollWrapper exists and is initialized
  • Check that ragdoll is actually being applied on death
  • Ensure Signals.OnHealthChanged is firing with correct health value
