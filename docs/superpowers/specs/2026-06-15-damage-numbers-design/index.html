DamageNumbers — Design Spec

Date: 2026-06-15 Status: Approved (design phase) Type: Client-only, render-only library

Summary​

A reusable client-side module that spawns floating 3D world-space damage numbers above enemies. Each number is a BillboardGui that pops from small to large, drifts upward, and fades out. The module is render-only and decoupled from combat — any client code calls DamageNumbers.Show(worldPosition, amount, styleName?). Damage remains server-authoritative (see CombatService); wiring a real damage source into Show is out of scope for this spec.

Styling (size, font, color, and more) is configurable through a config module using named style presets. Instances are pooled for performance. The module exposes an enable/disable toggle for a future settings menu.

Goals​

  • Floating damage number rendered as a world-space BillboardGui.
  • Configurable size, font, and color (plus stroke, timing, drift, jitter).
  • Spawn scale tween: small → big (with overshoot pop).
  • Position tween: drift upward over its lifetime.
  • Toggle-able on/off at runtime for a settings menu.
  • Pooled instances; minimal allocation under heavy combat.

Non-Goals (Out of Scope)​

  • No combat wiring, no Packets, no Signals entries (render-only).
  • No settings-menu UI — the menu will simply call SetEnabled.
  • No persistence of the toggle state.
  • No server changes.

Placement​

  • Module: src/ReplicatedStorage/SharedModules/DamageNumbers.luau (alongside MotionMaster / SoundManager; client-reachable shared library).
  • Config: src/ReplicatedStorage/SharedModules/Configs/DamageNumberConfig.luau.

Public API​

-- Spawn a floating damage number at a world position.
-- No-op if disabled or amount <= 0. styleName defaults to Config.DefaultStyle.
-- Unknown style falls back to the default style with a one-time warn.
DamageNumbers.Show(worldPosition: Vector3, amount: number, styleName: string?)

-- Runtime toggle for the future settings menu.
DamageNumbers.SetEnabled(enabled: boolean)
DamageNumbers.IsEnabled(): boolean

-- Optional: pre-warm the pool / build the holder. Idempotent.
-- If not called, the module lazy-initializes on first Show.
DamageNumbers.Init()
  • Displayed text = tostring(math.round(amount)) (rounded integer).
  • SetEnabled(false) stops new spawns; in-flight numbers finish naturally (they are not yanked, which would look jittery).

Components​

1. DamageNumberConfig​

All tuning lives here (prefer config edits over code edits, per project convention). Shape:

  • DefaultStyle: string — e.g. "normal".
  • Styles: { [string]: Style } — named presets. Starter set: normal, crit, heal. Each Style = { Color: Color3, Font: Enum.Font, SizeScale: number, StrokeColor: Color3, StrokeTransparency: number }. SizeScale is a multiplier on Billboard.BaseSize (world studs), so a style controls size by scaling the billboard rather than a screen-pixel TextSize (the label is TextScaled, so it fills the billboard and shrinks with camera distance).
  • Pop: { Duration: number, Easing: string } — scale-in pop (e.g. "EaseOutBack" for overshoot).
  • Rise: { Height: number, Duration: number, Easing: string } — upward drift in studs (Duration typically equals Lifetime; decelerating easing).
  • Fade: { Duration: number } — fade-out window at the end of life.
  • Lifetime: number — total seconds on screen before release.
  • Jitter: { Horizontal: number, Vertical: number } — random stud offset ranges applied at spawn so rapid hits fan out.
  • Pool: { InitialSize: number, MaxSize: number }.
  • Billboard: { Size: UDim2, MaxDistance: number, AlwaysOnTop: boolean }.
  • StartEnabled: boolean — initial toggle state (default true).

2. Pooled Entry​

Built once and reused via the project's GenericPoolInstance pattern (src/ReplicatedStorage/SharedModules/GenericPoolInstance.luau). Each entry:

Part (anchored, transparent, CanCollide=false, Massless, CanQuery=false)
└── BillboardGui (Adornee = the part)
    └── TextLabel
        └── UIScale

The anchor Part lives under a single workspace holder folder (e.g. workspace/DamageNumbers). Acquire on Show, release on finish.

3. Animation (MotionMaster)​

Driven by MotionMaster — the project forbids TweenService for client animation (per CLAUDE.md).

  • Pop: UIScale.Scale from small (e.g. Pop.StartScale) → 1 over Pop.Duration with an overshoot ease passed as a custom Model function (a back-out curve; MotionMaster's built-in AlphaModels has no back-out, and it does not clamp the eased alpha, so a >1 overshoot renders correctly).
  • Rise: BillboardGui.StudsOffsetWorldSpace.Y from 0 → Rise.Height over Rise.Duration with decelerating easing. Uses an offset, not physics, so the anchor part never moves after placement.
  • Fade: TextTransparency / TextStrokeTransparency 0 → 1 during the last Fade.Duration seconds (MotionMaster Delay = Lifetime - Fade.Duration).

4. Lifecycle​

  • Each active number owns a Janitor (per CLAUDE.md; never hand-rolled connection arrays), tracked in an active table.
  • On completion (after Lifetime) the Janitor cancels any live tweens and releases the entry back to the pool.
  • Module teardown / full clear cleans all active Janitors and releases entries.

Data Flow​

Show(pos, amount, styleName)
  └─ enabled? amount > 0? ────────────────── no → return
  └─ resolve style (fallback to default)
  └─ acquire pooled entry
  └─ place anchor part at pos + random jitter (Config.Jitter)
  └─ set text = round(amount); apply style (color/font/size/stroke)
  └─ reset UIScale.Scale to start; transparency to 0
  └─ parent anchor part into workspace holder
  └─ play Pop + Rise + Fade (MotionMaster)
  └─ on done → release entry to pool, clean Janitor

Positioning & Scale Notes​

  • BillboardGui uses world-space (studs) sizing, so numbers stay anchored in 3D and naturally shrink with camera distance; Billboard.MaxDistance culls distant ones.
  • Billboards always face the camera by definition — no manual orientation.

Documentation​

  • Moonwave @class DamageNumbers doc-comment in the module.
  • A short system page under docs/.
  • No networking-map or signals-map changes (render-only; no Packets/Signals).

Verification​

No automated test suite in this project; verify in Studio:

  • Call DamageNumbers.Show at a test position; confirm pop + rise + fade.
  • Rapid repeated calls fan out via jitter and reuse the pool (no leak).
  • SetEnabled(false) halts new numbers; in-flight ones finish.
  • Each named style (normal/crit/heal) renders with distinct color/size.
  • Numbers shrink with distance and cull past MaxDistance.
