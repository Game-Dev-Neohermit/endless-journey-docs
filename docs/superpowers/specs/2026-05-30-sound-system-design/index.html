Sound System — Unified SoundManager (Design Spec)

Date: 2026-05-30 Status: Design approved (brainstorming); implementation plan pending.

Context & Problem​

Sound playback is scattered and inconsistent across the codebase, with config spread across feature configs and no shared abstraction:

  • SoundController.client.luau — pooled positional playback, but only for sounds replicated via Packets.ReplicateSoundAtLocation. Carries a -- TODO: Add Sound Group.
  • ReplicatedSoundService.server.luau — server relay with a hardcoded allowlist (only GrabHook IDs) plus a per-player rate limit.
  • PlacementClient.client.luau and PlaceableActions.luau — each define their own duplicated playSound2D / playSoundAtPosition helpers (create-and-destroy a Sound).
  • GrabHook.client.luau — persistent tool Sound instances with bespoke fade/pitch/replication logic.
  • ProximityPickupController.client.luau — its own SoundService-parented sound with an anti-spam buffer + pitch randomization.
  • Config — sound asset IDs/volumes/pitches live in GrabHookConfig.Sounds, PlacementConfig.Sounds, and ProximityPickupConfig (PICKUP_SOUND_*). No SoundGroups, no BGM, and no ambience exist at all.

Goal: one easy-to-use, easy-to-maintain system for all audio (SFX, BGM, ambience), driven by a central config. Replace every scattered call site (full consolidation), add playlist/shuffle BGM and global 2D ambience beds, and introduce Master→SFX/BGM/Ambience volume buses (resolving the existing TODO).

Decisions (from brainstorming)​

  • Migration scope: Full consolidation — migrate every call site, delete duplicate helpers.
  • BGM model: Playlist / shuffle — a queue of tracks that auto-advance, optional shuffle, per-track gap.
  • Ambience model: Global 2D bed(s) — looped non-positional layers, fade in/out on demand.
  • Architecture: Foldered package — SharedModules/SoundManager/ with an init facade + focused SFX / Music / Ambience / Groups / Pool submodules.

Architecture & File Structure​

New package (client-driven; required by client controllers and the GrabHook tool):

src/ReplicatedStorage/SharedModules/SoundManager/
  init.luau        -- public facade + SoundManager.Init()
  Groups.luau      -- create/own the SoundGroup buses + volume control
  Pool.luau        -- wraps GenericPool: StaticPart + Sound + PitchShiftSoundEffect (moved from SoundController)
  SFX.luau         -- 2D one-shots, pooled positional one-shots, looped handles, receive replicated sounds
  Music.luau       -- playlist/shuffle BGM with crossfade
  Ambience.luau    -- global 2D looped beds with fade in/out
src/ReplicatedStorage/SharedModules/Configs/SoundConfig.luau  -- all sound defs + group volumes + playlists + beds

Playback is client-only; the facade is a singleton module. A thin client bootstrap calls SoundManager.Init() once. Fades use MotionMaster (per CLAUDE.md, never TweenService). An empty-string Id is a no-op (preserves the existing "leave blank to disable" convention).

Config: Configs/SoundConfig.luau​

Single source of truth for audio. Shape (illustrative — IDs migrated from existing configs):

export type SoundDef = {
    Id: string,                 -- rbxassetid; "" disables (no-op)
    Volume: number?,            -- default 0.5
    Pitch: number?,             -- default 1.0 (fixed)
    PitchRange: { number }?,    -- {min, max} random pitch per play (overrides Pitch)
    Looped: boolean?,
    Group: ("SFX" | "BGM" | "Ambience")?,  -- default "SFX"
    Replicate: boolean?,        -- positional broadcast to other clients allowed
    Debounce: number?,          -- min seconds between plays of this name (anti-spam)
}

local SoundConfig = {
    -- Effective volume per bus; multiplies through Master. 0..1 (engine allows up to 10).
    GroupVolumes = { Master = 1, SFX = 1, BGM = 0.6, Ambience = 0.5 },

    Sfx = {
        PlacementPlace   = { Id = "rbxassetid://116021254194480" },
        PlacementRotate  = { Id = "" },
        PlacementStash   = { Id = "" },
        PlaceableMove    = { Id = "" },
        PlaceableStash   = { Id = "" },
        ProximityPickup  = { Id = "rbxassetid://91026773425948", Volume = 0.2, PitchRange = { 0.92, 1.06 }, Debounce = 0.1 },
        GrabHookFire     = { Id = "rbxassetid://70375067578450", Volume = 0.5, PitchRange = { 1.0, 1.0 }, Replicate = true },
        GrabHookLoop     = { Id = "rbxassetid://83230748776604", Volume = 0.5, Looped = true, Replicate = true },
        GrabHookCooldown = { Id = "rbxassetid://93475294170115", Volume = 1.0 },
    },

    Music = {
        Playlists = {
            -- Tracks empty for now -> PlayMusic no-ops until IDs are added.
            Default = { Tracks = {}, Shuffle = true, Gap = 1.0, Volume = 0.6, Crossfade = 1.5 },
        },
    },

    Ambience = {
        Beds = {
            -- TrainHum = { Id = "", Volume = 0.4 },
        },
        Autostart = {},  -- bed names to fade in on Init
    },
}

Helpers on the config module:

  • SoundConfig.GetReplicatedIds() → set of Sfx IDs flagged Replicate = true (consumed by the server relay).
  • SoundConfig.GetPreloadIds() → all non-empty IDs (consumed by GrabHook's existing preloader).

Public API (facade init.luau)​

SoundManager.Init()                                   -- create buses+pool, hook replication receive, autostart ambience/music

-- SFX
SoundManager.PlaySFX(name, opts?)                     -- 2D one-shot (routed to its bus)
SoundManager.PlaySFXAt(name, position, opts?)         -- pooled positional one-shot played locally; opts.Replicate ALSO broadcasts to other clients
SoundManager.PlayLooped(name, opts?) -> LoopHandle    -- looped handle: :FadeTo(vol,dur), :Stop(fadeDur), :Destroy()

-- Music (playlist/shuffle)
SoundManager.PlayMusic(playlistName?)                 -- start/replace current playlist (default "Default")
SoundManager.SkipMusic()                              -- advance to next track
SoundManager.StopMusic(fade?)

-- Ambience (global 2D beds)
SoundManager.SetAmbience(names)                        -- crossfade to exactly this set of beds
SoundManager.AddAmbience(name) / RemoveAmbience(name)
SoundManager.StopAmbience(fade?)

-- Volume buses
SoundManager.SetVolume(group, v)                      -- group: "Master"|"SFX"|"BGM"|"Ambience"
SoundManager.GetVolume(group)

opts: PlayOptions = { Volume?, Pitch?, PitchRange?, Replicate?, Debounce?, Position? } — overrides the config def per call.

SoundGroups / Volume Buses​

Verified against the Roblox Engine API: "A Sound can only belong to one SoundGroup at a time, but SoundGroups can be nested," and SoundGroup.Volume is a multiplier applied to member sounds.

On Init, Groups creates a Master SoundGroup under SoundService, plus SFX/BGM/Ambience groups nested into Master (via each group's .SoundGroup property). Every played Sound sets its .SoundGroup to the relevant bus. SetVolume("Master", v) scales everything; per-bus volumes multiply through. This resolves the existing -- TODO: Add Sound Group.

Replication (generalized)​

  • ReplicatedSoundService.server.luau builds its allowlist from SoundConfig.GetReplicatedIds() instead of hardcoded GrabHook IDs — adding a replicated sound becomes a config-only change. Rate limit and payload validation are preserved.
  • Packet ReplicateSoundAtLocation and CustomTypes.SoundData / SoundConfig are unchanged (no protocol change → low risk). Replication remains fire-and-forget positional, matching current behavior (including GrabHook's loop firing a single positional play on receivers).

Config cleanup: migrate the sound-asset fields (Id/Volume/Pitch/pitch-range) out of GrabHookConfig.Sounds, PlacementConfig.Sounds, and ProximityPickupConfig into SoundConfig. Keep behavior-tuning that isn't a sound asset — notably GrabHook's loop fade timings (LoopStartDelay, LoopFadeInDuration, LoopFadeOutDuration) stay in GrabHookConfig; GrabHook reads the loop's volume/Id from SoundConfig and drives the fade timing locally via the LoopHandle. Update GrabHook's preloader to source IDs from SoundConfig.GetPreloadIds().

Out of Scope (future)​

  • Settings-menu UI for the volume buses (the SetVolume/GetVolume API is provided; persistence/UI later).
  • Zone-based positional ambience (the vendored Zone module) — chose global beds for now.
  • Actual BGM/ambience asset IDs (config ships with empty placeholders that no-op until filled in).

Verification​

No rojo build / selene (per user workflow). Verify in Studio:

  1. Buses exist: after sync, the bootstrap runs SoundManager.Init(); via MCP execute_luau, confirm SoundService has Master/SFX/BGM/Ambience SoundGroups and that SetVolume("SFX", 0) mutes SFX only.
  2. SFX spot-check: execute_luau calling SoundManager.PlaySFX("ProximityPickup") and PlaySFXAt("PlacementPlace", <pos>); confirm audible + pooled parts return.
  3. In playtest: place/rotate/stash a placeable, pick up junk, fire the GrabHook (fire + loop fade + cooldown) — confirm each plays once, no errors, and pooled StaticPart/Sound counts stay bounded.
  4. Replication: with the config-driven allowlist, confirm a second client hears GrabHook fire; confirm a non-allowlisted ID is rejected server-side.
  5. BGM/ambience plumbing: with a temporary test ID in SoundConfig, confirm PlayMusic() advances tracks (Ended → Gap → next, shuffle order) and SetAmbience({...}) fades a bed in/out. Console clean (get_console_output).
