Proximity Pickup System — Design Spec

Date: 2026-05-14 Branch: Proximity-Pickup Status: Approved

Overview​

A generic, server-authoritative proximity pickup module for Roblox (Luau/Rojo). When a player walks near a registered item, the item floats toward them via MotionMaster and enters their inventory. The module is consumer-agnostic: it carries arbitrary Metadata and delegates inventory logic to a caller-supplied callback. The initial consumer is craftable materials on the ground; future consumers (weapons, puzzle keys, etc.) require no changes to the module.

Architecture​

Four files plus one new packet:

FileContextRole

New packet in ReplicatedStorage/SharedModules/Packets/init.luau:

PickupItemClaimed (S→C broadcast): { itemId: string, claimer: Player }

No C→S packet is needed — the server detects proximity via its own Touched event.

Config (ProximityPickupConfig.luau)​

return {
    DEFAULT_RADIUS    = 5,   -- studs; radius of the sphere detection zone
    FLOAT_DURATION    = 0.6, -- seconds for item to reach player hand
    PICKUP_SOUND_ID   = nil, -- set to an rbxassetid:// string to play a sound on pickup; nil = silent
}

Item Lifecycle​

Spawned (Studio-placed or runtime) → RegisterItem() called
  → server creates welded sphere zone (CanTouch=true, CanCollide=false)
  → item State = "Unclaimed"

Player walks in range → Touched fires on server
  → if State == "Unclaimed" and toucher is a Player character:
      State = "Claimed", Claimer = player
      sphere destroyed (eliminates race window)
      broadcast PickupItemClaimed(itemId, player)
      callback(player, metadata) — grants inventory item

Client receives PickupItemClaimed:
  → if localPlayer == claimer: run MotionMaster float animation, play sound (if PICKUP_SOUND_ID configured), then destroy model
  → if localPlayer != claimer: destroy model immediately

Item is gone until server restart (no respawn).

Server: ProximityPickupServer​

Registry​

type ItemRecord = {
    Model    : Model,
    Metadata : { [string]: any },
    State    : "Unclaimed" | "Claimed",
    Claimer  : Player?,
    Zone     : BasePart,
    Callback : (player: Player, metadata: { [string]: any }) -> (),
}
local activeItems: { [string]: ItemRecord } = {}  -- keyed by GUID itemId

RegisterItem(model, metadata, callback)​

  1. Assert model.PrimaryPart is set.
  2. Generate a GUID itemId; store it as a string attribute on the model (model:SetAttribute("PickupItemId", itemId)).
  3. Add "PickupItem" CollectionService tag to the model (CollectionService:AddTag(model, "PickupItem")). This is what the client uses to discover and track the model — consumers do not need to apply this tag manually.
  4. Create sphere zone Part:
    • Shape = Enum.PartType.Ball
    • Size = Vector3.new(r*2, r*2, r*2) where r = ProximityPickupConfig.DEFAULT_RADIUS
    • CanCollide = false, CanTouch = true, Transparency = 1, CastShadow = false, Massless = true, Anchored = false
    • Parent = model (so it moves with the model if the model is moved)
  5. WeldConstraint from zone to model.PrimaryPart (zero offset).
  6. Connect zone.Touched:
zone.Touched:Connect(function(hit)
    local record = activeItems[itemId]
    if not record or record.State ~= "Unclaimed" then return end

    local character = hit.Parent
    local player = Players:GetPlayerFromCharacter(character)
    if not player then return end
    local hrp = character:FindFirstChild("HumanoidRootPart")
    if not hrp then return end

    -- Atomic claim
    record.State = "Claimed"
    record.Claimer = player
    record.Zone:Destroy()

    -- Broadcast to all clients
    Packets.PickupItemClaimed:Fire({ itemId = itemId, claimer = player })

    -- Fulfil inventory via consumer callback (after small delay for float animation)
    task.delay(ProximityPickupConfig.FLOAT_DURATION, function()
        record.Callback(player, record.Metadata)
        record.Model:Destroy()
        activeItems[itemId] = nil
    end)
end)
  1. Store record in activeItems[itemId].

Cleanup​

Players.PlayerRemoving — if a player had claimed an item but the server callback hasn't fired yet (extremely rare edge case: disconnect during FLOAT_DURATION delay), the item model is destroyed and record removed to prevent a dangling reference.

Client: ProximityPickupController​

Registry​

local trackedItems: { [string]: Model } = {}  -- itemId → Model

On init, scan CollectionService:GetTagged("PickupItem") and register existing models; listen to CollectionService:GetInstanceAddedSignal("PickupItem") for runtime-spawned items. Store model:GetAttribute("PickupItemId") as the key.

PickupItemClaimed handler​

Packets.PickupItemClaimed.OnClientEvent:Connect(function(data)
    local model = trackedItems[data.itemId]
    if not model then return end
    trackedItems[data.itemId] = nil

    if data.claimer == LocalPlayer then
        -- Float to player hand
        local hrp = LocalPlayer.Character and LocalPlayer.Character:FindFirstChild("HumanoidRootPart")
        if hrp and model.PrimaryPart then
            MotionMaster.Play(model.PrimaryPart, {
                CFrame = hrp.CFrame * CFrame.new(0, 1, -1.5)
            }, {
                Duration = ProximityPickupConfig.FLOAT_DURATION,
                Model    = "EaseInOutQuad",
            })
        end

        if ProximityPickupConfig.PICKUP_SOUND_ID then
            local sound = Instance.new("Sound")
            sound.SoundId = ProximityPickupConfig.PICKUP_SOUND_ID
            sound.Parent = game:GetService("SoundService")
            sound:Play()
            game:GetService("Debris"):AddItem(sound, 5)
        end

        task.delay(ProximityPickupConfig.FLOAT_DURATION, function()
            if model and model.Parent then model:Destroy() end
        end)
    else
        model:Destroy()
    end
end)

Consumer: MaterialPickupService​

Runs once on server startup:

  1. CollectionService:GetTagged("CraftMaterial") — iterate all Studio-tagged material models.
  2. For each model, call:
ProximityPickupServer.RegisterItem(model, {
    ItemType = model:GetAttribute("ItemType"),
    ItemTier = model:GetAttribute("ItemTier"),
}, function(player, metadata)
    local tool = JunkToolManager.GetToolFromJunk(
        metadata.ItemType,
        metadata.ItemTier,
        "Material"
    )
    if tool then
        tool.Parent = player.Backpack
    end
end)
  1. Also listen to CollectionService:GetInstanceAddedSignal("CraftMaterial") for runtime-spawned materials and register them the same way.

Multiplayer Safety​

ConcernSolution
Two players claim same itemState checked atomically on server; first Touched wins, sphere destroyed immediately after — subsequent touches find State == "Claimed" and return
Item floats to multiple playersPickupItemClaimed broadcast is single-target; non-claimers destroy model immediately
Touched fires multiple times per body partNatural debounce: state is "Claimed" after first valid touch; all repeat fires are no-ops
Client shows item after server destroys itClients remove model on PickupItemClaimed; server destroys model after FLOAT_DURATION

Out of Scope​

  • Per-item pickup radii (use DEFAULT_RADIUS for all items; add to metadata if needed later)
  • Item respawning (gone until server restart)
  • Visual proximity indicator / UI prompt
  • Per-item sound customization (single global PICKUP_SOUND_ID in Config; no per-consumer overrides, randomized pools, or volume per tier)
