Default Camera Mode Toggle — Design Spec

Goal​

Add a second player-selectable camera mode — Default camera (free Roblox mouse, shoulder offset, camera boom, zoom limits) — toggled from the existing ThirdPerson camera (mouse locked, custom rotation lerp) via Left-Alt. ShootingCamera remains programmatic-only.

Architecture​

All changes are confined to ThirdPersonCameraController.client.luau. A single boolean flag (isDefaultCameraMode) gates which mode is active. No new files, no new signals, no new config fields are required.

Modes​

ModeEntered byMouseAutoRotateCharacter rotation

Camera boom (occlusion raycast + zoom clamp) runs in CameraBoomController and is unchanged — it applies identically to both player modes.

ThirdPersonCameraController changes​

New state​

local isDefaultCameraMode = false   -- persists across respawns; defaults to ThirdPerson

engage() — mode-aware restore​

Called on: character spawn (if not suspended), ShootingCamera disengage, Alt toggle → ThirdPerson.

engage():
  cancel releaseTween
  humanoid.CameraOffset = CameraConfig.ThirdPersonOffset
  if isDefaultCameraMode:
    humanoid.AutoRotate = true
    UserInputService.MouseBehavior = Enum.MouseBehavior.Default
    UserInputService.MouseIconEnabled = true   -- always show in Default mode
  else:
    humanoid.AutoRotate = false
    if not guiRequestsMouse: MouseIconEnabled = false

release() is unchanged — used when ShootingCamera engages; tweens CameraOffset to zero and restores AutoRotate=true regardless of mode.

RenderStep — early exit for Default mode​

BindToRenderStep("ThirdPersonCameraUpdate", Camera.Value + 1):
  early-exit if isSuspended / no humanoid / no hrp / humanoid.Sit
  humanoid.CameraOffset = CameraConfig.ThirdPersonOffset   -- applied in both modes
  if isDefaultCameraMode: return                           -- Roblox handles the rest
  -- ThirdPerson assertions (unchanged):
  humanoid.AutoRotate = false
  force MouseBehavior = LockCenter
  if not guiRequestsMouse: force MouseIconEnabled = false
  rotate hrp CFrame toward MoveDirection via RotationLerpSpeed lerp

Left-Alt binding​

ContextActionService:BindAction("ToggleCameraMode", ..., Enum.KeyCode.LeftAlt):
  if UserInputState.Begin:
    if isSuspended: return Sink   -- no-op while ShootingCamera is active
    isDefaultCameraMode = not isDefaultCameraMode
    if isDefaultCameraMode:
      humanoid.AutoRotate = true
      UserInputService.MouseBehavior = Enum.MouseBehavior.Default
      UserInputService.MouseIconEnabled = true
    else:
      engage()
  return Sink

RequestMouseIcon listener update​

Signals.RequestMouseIcon:Connect(function(visible):
  guiRequestsMouse = visible
  if visible:
    MouseIconEnabled = true           -- show regardless of mode
  elseif not isDefaultCameraMode:
    MouseIconEnabled = false          -- only hide in ThirdPerson mode
  -- Default mode: GUI closing does not hide the mouse

OnShootingCameraToggled handler​

Unchanged in structure. When ShootingCamera disengages, engage() is called, which is now mode-aware and restores the correct state (Default or ThirdPerson) based on isDefaultCameraMode.

Verification​

  1. Build: rojo build -o "Game Instance.rbxlx" succeeds.
  2. ThirdPerson (default): spawn in — mouse hidden, locked to centre, character faces movement direction via lerp. Camera boom clamps zoom/occlusion.
  3. Press Left-Alt: mouse appears, camera orbits freely, Roblox stock rotation, shoulder offset still applied, boom still active.
  4. Press Left-Alt again: returns to ThirdPerson mode — mouse hidden, LockCenter restored.
  5. Alt is no-op during ShootingCamera: programmatically fire Signals.RequestShootingCamera:Fire(true), press Alt — nothing changes. Disengage ShootingCamera — returns to whichever mode was active before.
  6. GUI mouse override: fire Signals.RequestMouseIcon:Fire(true) in ThirdPerson mode — mouse appears. Fire false — mouse hides. In Default mode, false does not hide the mouse.
  7. Respawn: character respawns in the same mode that was active (flag persists).
