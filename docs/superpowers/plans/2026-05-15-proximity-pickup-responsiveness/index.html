Proximity Pickup Responsiveness Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Replace Heartbeat-based item animation with MotionMaster for deterministic timing and reduce float duration from 0.9s to 0.25s for instant-feeling pickup.

Architecture: Two-file change: (1) Config reduces FLOAT_DURATION to 0.25s, (2) Client controller replaces unpredictable Heartbeat+Lerp loop with MotionMaster.Play() for guaranteed frame-independent animation. Server requires no changes — existing task.delay() already aligns with new duration.

Tech Stack: Luau, MotionMaster (existing animation library in SharedModules), Rojo/Selene for build/lint.

Task 2: Replace Heartbeat Animation with MotionMaster​

Files:

  • Modify: src/StarterPlayer/StarterPlayerScripts/ProximityPickupController.client.luau:41–76

  • Step 1: Open ProximityPickupController and locate the PickupItemClaimed handler

File: src/StarterPlayer/StarterPlayerScripts/ProximityPickupController.client.luau

Find the section starting at line 41:

Packets.PickupItemClaimed.OnClientEvent:Connect(function(itemId: string, claimer: Player)

This handler currently contains a Heartbeat loop (lines 48–66) with a Lerp-based animation.

  • Step 2: Replace the entire handler with MotionMaster-based animation

Replace lines 41–76 with:

Packets.PickupItemClaimed.OnClientEvent:Connect(function(itemId: string, claimer: Player)
	local model = trackedItems[itemId]
	if not model then
		return
	end
	trackedItems[itemId] = nil

	if claimer == LocalPlayer then
		local character = LocalPlayer.Character
		local hrp = character and character:FindFirstChild("HumanoidRootPart") :: BasePart?
		if hrp and model.PrimaryPart then
			MotionMaster.Play(model.PrimaryPart, {
				CFrame = hrp.CFrame * CFrame.new(0, 1, -1.5)
			}, {
				Duration = ProximityPickupConfig.FLOAT_DURATION,
				Model = "Linear",
			})
		end
	else
		model:Destroy()
	end
end)

Changes:

  • Removed: local heartbeatConn: RBXScriptConnection and Heartbeat loop (no manual connection management)
  • Removed: task.delay(ProximityPickupConfig.FLOAT_DURATION, function() heartbeatConn:Disconnect() end)
  • Added: MotionMaster.Play() call with Duration = ProximityPickupConfig.FLOAT_DURATION and Model = "Linear" easing
  • Kept: All safety checks (model existence, character state, HumanoidRootPart lookup)

Why:

  • MotionMaster guarantees animation completes in exactly FLOAT_DURATION seconds (frame-rate independent)

  • Linear easing = smooth constant-speed motion

  • Simpler code: no connection management, no Heartbeat overhead

  • Animation timing aligns perfectly with server callback delay
