Train Notifications Migration Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Replace TrainClient's hand-rolled toast UI with Signals.RequestNotification, keeping only two "missing something" notifications (no energy item; tank full) and dropping all success/exploit/distance toasts.

Architecture: Single-file change to TrainClient.client.luau. Delete the local ScreenGui toast system and its showToast function; route the two surviving cases through the shared notification signal. The lever (brake) and engine (refuel) Triggered handlers still fire their Packets — only the toast display is removed.

Tech Stack: Luau, Roblox, Signals event bus (RequestNotification), TrainResultCodes.

Notes on verification​

This project has no automated test suite — verification happens in Studio, which the user drives via live Rojo sync. Per project conventions, do not run rojo build, selene, or MCP playtesting as plan steps. Each task ends with a self-contained, reviewable edit; correctness is confirmed by reading the diff and (by the user) syncing in Studio.

All edits are to one file: src/StarterPlayer/StarterPlayerScripts/TrainClient.client.luau

local FAILURE_COLOR = Color3.fromRGB(255, 210, 210)
local TOAST_TIME = 2.5

local toastSerial = 0
local toastTween: any = nil

local function showToast(message: string, success: boolean)
	toastLabel.Text = message
	toastLabel.TextColor3 = success and SUCCESS_COLOR or FAILURE_COLOR
	toastFrame.Visible = true
	toastFrame.BackgroundTransparency = 0.2
	if toastTween then
		toastTween:Cancel()
		toastTween:Destroy()
		toastTween = nil
	end
	toastSerial += 1
	local mySerial = toastSerial
	task.delay(TOAST_TIME, function()
		if mySerial ~= toastSerial then
			return
		end
		local tw = MotionMaster.Create(toastFrame, { BackgroundTransparency = 1 }, {
			Duration = 0.4,
			Model = "EaseOutQuad",
		})
		toastTween = tw
		tw:OnComplete(function()
			tw:Destroy()
			if toastTween == tw then
				toastTween = nil
			end
			if mySerial == toastSerial then
				toastFrame.Visible = false
			end
		end)
		tw:Play()
	end)
end

Task 4: Rewire the refuel (engine) handlers​

Files:

  • Modify: src/StarterPlayer/StarterPlayerScripts/TrainClient.client.luau

  • Step 1: Replace the hold-began handler body

Inside registerEngine, find this handler (currently ~lines 179–188):

	local holdConn: RBXScriptConnection = prompt.PromptButtonHoldBegan:Connect(function()
		if not playerHasEnergyTool() then
			-- TODO: notify player (no energy tools) via custom notification module
			warn("You must hold energy item to refuel the engine")
			prompt.Enabled = false
			task.delay(1, function()
				prompt.Enabled = true
			end)
		end
	end)

Replace it with:

	local holdConn: RBXScriptConnection = prompt.PromptButtonHoldBegan:Connect(function()
		if not playerHasEnergyTool() then
			Signals.RequestNotification:Fire("warn", NO_ENERGY_MESSAGE, REFUEL_NOTIF_DURATION)
			prompt.Enabled = false
			task.delay(1, function()
				prompt.Enabled = true
			end)
		end
	end)
  • Step 2: Replace the refuel Triggered result handler

Find this handler (currently ~lines 189–200):

	local triggerConn = prompt.Triggered:Connect(function()
		task.spawn(function()
			local success, fuelAdded, reason = Packets.ReqRefuelTrain:Fire(engine)
			if success then
				showToast(("Refueled +%d"):format(math.floor(fuelAdded + 0.5)), true)
			elseif reason == TrainResultCodes.NO_ENERGY then
				-- TODO: notify player (no energy tools) via custom notification module
			else
				showToast(REFUEL_FAIL[reason] or "Refuel failed.", false)
			end
		end)
	end)

Replace it with:

	local triggerConn = prompt.Triggered:Connect(function()
		task.spawn(function()
			local success, _fuelAdded, reason = Packets.ReqRefuelTrain:Fire(engine)
			if not success then
				if reason == TrainResultCodes.NO_ENERGY then
					Signals.RequestNotification:Fire("warn", NO_ENERGY_MESSAGE, REFUEL_NOTIF_DURATION)
				elseif reason == TrainResultCodes.FUEL_FULL then
					Signals.RequestNotification:Fire("info", FUEL_FULL_MESSAGE, REFUEL_NOTIF_DURATION)
				end
			end
		end)
	end)

Note: the Packets.ReqRefuelTrain:Fire(engine) call is preserved — only the toast display changes. Success and all other reasons (TOO_FAR, INVALID_ENGINE) now show nothing.
