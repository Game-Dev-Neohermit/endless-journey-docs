Default Camera Mode Toggle — Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Add a second player-selectable camera mode (free-mouse Roblox default camera with shoulder offset) toggled from the existing mouse-locked ThirdPerson mode via Left-Alt, without changing any other file.

Architecture: All changes are confined to ThirdPersonCameraController.client.luau. A boolean flag (isDefaultCameraMode) gates which mode is active; engage() becomes mode-aware; the RenderStep applies the offset in both modes but only asserts mouse-lock overrides in ThirdPerson mode; a ContextActionService binding wires Left-Alt to the toggle. No new signals, config fields, or files.

Tech Stack: Luau, Roblox ContextActionService, UserInputService, RunService, project MotionMaster, project Signals.

Task 1: Rewrite ThirdPersonCameraController with two-mode support​

There is no automated test suite; verification is a successful rojo build (confirms no Luau parse/type errors in the compiled output).

Files:

  • Modify: src/StarterPlayer/StarterPlayerScripts/ThirdPersonCameraController.client.luau
  • Step 1: Replace the entire file with the two-mode implementation

The diff from the current file is:

  1. Add ContextActionService to the services block.
  2. Add local isDefaultCameraMode = false after local releaseTween.
  3. Rewrite engage() to branch on isDefaultCameraMode.
  4. Update the Signals.RequestMouseIcon listener to not hide the mouse when in Default mode.
  5. Add a ContextActionService:BindAction block for "ToggleCameraMode" bound to Enum.KeyCode.LeftAlt.
  6. In the RunService:BindToRenderStep callback, apply CameraOffset first, then return early when isDefaultCameraMode, and keep the ThirdPerson assertions below.

Write the complete file as follows:

--!strict
--!optimize 2
--!native

local ContextActionService = game:GetService("ContextActionService")
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")
local UserInputService = game:GetService("UserInputService")

local SharedModules = ReplicatedStorage:WaitForChild("SharedModules")
local CameraConfig = require(SharedModules.Configs.CameraConfig)
local MotionMaster = require(SharedModules.MotionMaster)
local Signals = require(SharedModules.Signals)

local player = Players.LocalPlayer
assert(player, "LocalPlayer is nil")

local isSuspended = false
local isDefaultCameraMode = false
local guiRequestsMouse = false
local humanoid: Humanoid? = nil
local hrp: BasePart? = nil
local releaseTween: any = nil

local function engage()
	if not humanoid then
		return
	end
	if releaseTween then
		releaseTween:Cancel()
		releaseTween = nil
	end
	humanoid.CameraOffset = CameraConfig.ThirdPersonOffset
	if isDefaultCameraMode then
		humanoid.AutoRotate = true
		UserInputService.MouseBehavior = Enum.MouseBehavior.Default
		UserInputService.MouseIconEnabled = true
	else
		humanoid.AutoRotate = false
		if not guiRequestsMouse then
			UserInputService.MouseIconEnabled = false
		end
	end
end

local function release()
	if not humanoid then
		return
	end
	humanoid.AutoRotate = true
	if releaseTween then
		releaseTween:Cancel()
	end
	releaseTween = MotionMaster.Create(
		humanoid,
		{ CameraOffset = Vector3.zero },
		{ Duration = CameraConfig.OffsetTweenDuration, Model = "EaseOutSine" }
	)
	if releaseTween then
		releaseTween:Play()
	end
end

local function onCharacterAdded(character: Model)
	humanoid = character:WaitForChild("Humanoid") :: Humanoid
	hrp = character:WaitForChild("HumanoidRootPart") :: BasePart
	if not isSuspended then
		engage()
	end
end

if player.Character then
	task.spawn(onCharacterAdded, player.Character)
end
player.CharacterAdded:Connect(onCharacterAdded)
player.CharacterRemoving:Connect(function()
	humanoid = nil
	hrp = nil
end)

Signals.OnShootingCameraToggled:Connect(function(active: boolean)
	isSuspended = active
	if active then
		release()
	else
		engage()
	end
end)

Signals.RequestMouseIcon:Connect(function(visible: boolean)
	guiRequestsMouse = visible
	if visible then
		UserInputService.MouseIconEnabled = true
	elseif not isDefaultCameraMode then
		UserInputService.MouseIconEnabled = false
	end
end)

ContextActionService:BindAction("ToggleCameraMode", function(_, inputState, _)
	if inputState ~= Enum.UserInputState.Begin then
		return Enum.ContextActionResult.Sink
	end
	if isSuspended then
		return Enum.ContextActionResult.Sink
	end
	isDefaultCameraMode = not isDefaultCameraMode
	if isDefaultCameraMode then
		if humanoid then
			humanoid.AutoRotate = true
		end
		UserInputService.MouseBehavior = Enum.MouseBehavior.Default
		UserInputService.MouseIconEnabled = true
	else
		engage()
	end
	return Enum.ContextActionResult.Sink
end, false, Enum.KeyCode.LeftAlt)

RunService:BindToRenderStep("ThirdPersonCameraUpdate", Enum.RenderPriority.Camera.Value + 1, function()
	if isSuspended then
		return
	end
	if not humanoid or not hrp then
		return
	end
	if humanoid.Sit then
		return
	end

	humanoid.CameraOffset = CameraConfig.ThirdPersonOffset

	if isDefaultCameraMode then
		return
	end

	-- ThirdPerson mode: defensive re-assert
	humanoid.AutoRotate = false
	if UserInputService.MouseBehavior ~= Enum.MouseBehavior.LockCenter then
		UserInputService.MouseBehavior = Enum.MouseBehavior.LockCenter
	end
	if not guiRequestsMouse and UserInputService.MouseIconEnabled then
		UserInputService.MouseIconEnabled = false
	end

	-- Rotate character to face movement direction
	local moveDir = humanoid.MoveDirection
	if moveDir.Magnitude > 0.1 then
		local targetYaw = math.atan2(-moveDir.X, -moveDir.Z)
		local targetCFrame = CFrame.new(hrp.Position) * CFrame.Angles(0, targetYaw, 0)
		hrp.CFrame = hrp.CFrame:Lerp(targetCFrame, CameraConfig.RotationLerpSpeed)
	end
end)

Task 2: Studio verification checklist​

No code changes — this task is manual verification in Roblox Studio. Build the place file (already done in Task 1 Step 2) and playtest.

Files: none

  • Step 1: Verify ThirdPerson mode (default on spawn)

Open Studio, playtest. On spawn:

  • Mouse cursor is hidden, mouse is locked to centre.
  • Moving with WASD: character rotates smoothly to face movement direction (custom lerp).
  • Camera orbits around character with the shoulder offset (slightly right of centre).
  • Camera boom clamps zoom — scroll out past ~9 studs and confirm it stops. Walk into a wall and confirm the camera pulls in rather than clipping.
  • Step 2: Verify Default camera mode (press Left-Alt)

Press Left-Alt once:

  • Mouse cursor appears immediately.
  • Mouse is free — moving the mouse orbits the camera without locking.
  • Character still has the shoulder offset (same side offset as ThirdPerson).
  • Moving with WASD: character faces movement direction (Roblox stock AutoRotate).
  • Camera boom still active — zoom clamp and wall occlusion still work.
  • Step 3: Verify toggle back to ThirdPerson (press Left-Alt again)

Press Left-Alt a second time:

  • Mouse cursor disappears, mouse locks back to centre.
  • Character rotation lerp resumes.
  • All ThirdPerson behaviour restored.
  • Step 4: Verify Alt is no-op during ShootingCamera

In the Studio command bar, run:

require(game.ReplicatedStorage.SharedModules.Signals).RequestShootingCamera:Fire(true)
  • Reticle appears, ShootingCamera is active.
  • Press Left-Alt — nothing changes (camera stays in ShootingCamera mode).
  • Disengage via command bar:
require(game.ReplicatedStorage.SharedModules.Signals).RequestShootingCamera:Fire(false)
  • Returns to whichever mode was active before (ThirdPerson or Default).
  • Step 5: Verify GUI mouse override in ThirdPerson mode

In ThirdPerson mode, run in command bar:

require(game.ReplicatedStorage.SharedModules.Signals).RequestMouseIcon:Fire(true)
  • Mouse cursor appears (GUI override).
require(game.ReplicatedStorage.SharedModules.Signals).RequestMouseIcon:Fire(false)
  • Mouse cursor hides again.
  • Step 6: Verify GUI mouse override does NOT hide mouse in Default mode

Switch to Default mode (Left-Alt), then run:

require(game.ReplicatedStorage.SharedModules.Signals).RequestMouseIcon:Fire(true)
-- mouse already visible
require(game.ReplicatedStorage.SharedModules.Signals).RequestMouseIcon:Fire(false)
-- mouse should STAY visible (Default mode always shows mouse)
  • Step 7: Verify mode persists across respawn

Switch to Default mode. Open Studio's "Kill" tool or run player.Character.Humanoid.Health = 0 in the command bar. After respawn, the mouse should still be free and visible (Default mode persisted).
