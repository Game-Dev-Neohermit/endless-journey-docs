Camera System Refactor Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Make a new ThirdPersonCamera (movement-direction rotation) the default camera, keep the existing SmoothShiftLock as a programmatic-only ShootingCamera, and share a CameraBoom + zoom-clamp layer across both.

Architecture: Two new client controllers (ThirdPersonCameraController, CameraBoomController) plus a renamed glue script (CustomShiftLock → ShootingCameraController). The vendored SmoothShiftLock package is the engine for ShootingCamera; its Alt/L3 context action is unbound from the outside. Mode source-of-truth is Signals.OnShootingCameraToggled (renamed from OnShiftLockToggled); programmatic entry is Signals.RequestShootingCamera (renamed from RequestShiftLockState), already wired by GrabHook and PlacementClient.

Tech Stack: Luau, Rojo, MotionMaster (animation), Roblox RunService / UserInputService / ContextActionService / RaycastParams.

Spec: docs/superpowers/specs/2026-05-25-open-world-camera-design.md

Task 4: Create ThirdPersonCameraController​

Files:

  • Create: src/StarterPlayer/StarterPlayerScripts/ThirdPersonCameraController.client.luau

  • Step 1: Write the file

Create src/StarterPlayer/StarterPlayerScripts/ThirdPersonCameraController.client.luau with:

--!strict
--!optimize 2
--!native

--[[
	ThirdPersonCameraController (Client Script)

	The project's default camera. Mouse locked to centre, Humanoid.AutoRotate
	disabled, shoulder offset applied, character rotates to face
	Humanoid.MoveDirection (open-world style).

	Suspends itself when ShootingCamera (SmoothShiftLock) engages, via
	Signals.OnShootingCameraToggled. Re-engages when it disengages.
]]

local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")
local UserInputService = game:GetService("UserInputService")

local SharedModules = ReplicatedStorage:WaitForChild("SharedModules")
local CameraConfig = require(SharedModules.Configs.CameraConfig)
local MotionMaster = require(SharedModules.MotionMaster)
local Signals = require(SharedModules.Signals)

local player = Players.LocalPlayer
assert(player, "LocalPlayer is nil")

local isSuspended = false
local humanoid: Humanoid? = nil
local hrp: BasePart? = nil
local releaseTween: any = nil

local function engage()
	if not humanoid then
		return
	end
	if releaseTween then
		releaseTween:Cancel()
		releaseTween = nil
	end
	humanoid.AutoRotate = false
	humanoid.CameraOffset = CameraConfig.ThirdPersonOffset
end

local function release()
	if not humanoid then
		return
	end
	humanoid.AutoRotate = true
	if releaseTween then
		releaseTween:Cancel()
	end
	releaseTween = MotionMaster.Create(
		humanoid,
		{ CameraOffset = Vector3.zero },
		{ Duration = CameraConfig.OffsetTweenDuration, Model = "EaseOutSine" }
	)
	if releaseTween then
		releaseTween:Play()
	end
end

local function onCharacterAdded(character: Model)
	humanoid = character:WaitForChild("Humanoid") :: Humanoid
	hrp = character:WaitForChild("HumanoidRootPart") :: BasePart
	if not isSuspended then
		engage()
	end
end

if player.Character then
	onCharacterAdded(player.Character)
end
player.CharacterAdded:Connect(onCharacterAdded)

Signals.OnShootingCameraToggled:Connect(function(active: boolean)
	isSuspended = active
	if active then
		release()
	else
		engage()
	end
end)

RunService:BindToRenderStep("ThirdPersonCameraUpdate", Enum.RenderPriority.Camera.Value + 1, function()
	if isSuspended then
		return
	end
	if not humanoid or not hrp then
		return
	end
	if humanoid.Sit then
		return
	end

	-- Defensive re-assert (cheap; other systems may have toggled these)
	humanoid.AutoRotate = false
	if UserInputService.MouseBehavior ~= Enum.MouseBehavior.LockCenter then
		UserInputService.MouseBehavior = Enum.MouseBehavior.LockCenter
	end
	humanoid.CameraOffset = CameraConfig.ThirdPersonOffset

	-- Rotate character to face movement direction
	local moveDir = humanoid.MoveDirection
	if moveDir.Magnitude > 0.1 then
		local targetYaw = math.atan2(-moveDir.X, -moveDir.Z)
		local targetCFrame = CFrame.new(hrp.Position) * CFrame.Angles(0, targetYaw, 0)
		hrp.CFrame = hrp.CFrame:Lerp(targetCFrame, CameraConfig.RotationLerpSpeed)
	end
end)

Task 5: Create CameraBoomController​

Files:

  • Create: src/StarterPlayer/StarterPlayerScripts/CameraBoomController.client.luau

  • Step 1: Write the file

Create src/StarterPlayer/StarterPlayerScripts/CameraBoomController.client.luau with:

--!strict
--!optimize 2
--!native

--[[
	CameraBoomController (Client Script)

	Shared occlusion + zoom-clamp layer. Raycasts from camera focus toward
	camera position; clamps Player.CameraMaxZoomDistance to the hit distance
	(minus a small buffer) so the camera never clips through walls. Uses a
	different max-distance ceiling depending on the active camera mode.

	Listens to Signals.OnShootingCameraToggled to swap between
	ShootingCameraMaxZoomDistance (true) and ThirdPersonCameraMaxZoomDistance
	(false).
]]

local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")
local Workspace = game:GetService("Workspace")

local SharedModules = ReplicatedStorage:WaitForChild("SharedModules")
local CameraConfig = require(SharedModules.Configs.CameraConfig)
local Signals = require(SharedModules.Signals)

local player = Players.LocalPlayer
assert(player, "LocalPlayer is nil")

local camera = Workspace.CurrentCamera
assert(camera, "CurrentCamera is nil")

local isShooting = false

local function getMaxDistanceForMode(): number
	if isShooting then
		return CameraConfig.ShootingCameraMaxZoomDistance
	else
		return CameraConfig.ThirdPersonCameraMaxZoomDistance
	end
end

local currentDistance: number = getMaxDistanceForMode()

Signals.OnShootingCameraToggled:Connect(function(active: boolean)
	isShooting = active
end)

RunService:BindToRenderStep("CameraBoom", Enum.RenderPriority.Camera.Value, function(dt)
	if not CameraConfig.BoomEnabled then
		return
	end

	local character = player.Character
	if not character then
		return
	end

	local hrp = character:FindFirstChild("HumanoidRootPart")
	if not hrp or not hrp:IsA("BasePart") then
		return
	end

	local origin = camera.Focus.Position
	local cameraPos = camera.CFrame.Position
	local delta = cameraPos - origin
	local camDistance = delta.Magnitude
	if camDistance < 0.01 then
		return
	end
	local direction = delta / camDistance

	local rayParams = RaycastParams.new()
	rayParams.FilterType = Enum.RaycastFilterType.Exclude
	rayParams.FilterDescendantsInstances = { character }
	rayParams.RespectCanCollide = true

	local rayResult = Workspace:Raycast(origin, direction * camDistance, rayParams)

	local maxForMode = getMaxDistanceForMode()
	local targetDistance: number
	if rayResult then
		local hitDistance = (rayResult.Position - origin).Magnitude
		local clamped = math.max(CameraConfig.CameraMinZoomDistance, hitDistance - CameraConfig.BoomBuffer)
		targetDistance = math.min(maxForMode, clamped)
	else
		targetDistance = maxForMode
	end

	local lerpFactor = math.min(1, dt * CameraConfig.BoomSmoothingSpeed)
	currentDistance = currentDistance + (targetDistance - currentDistance) * lerpFactor

	player.CameraMinZoomDistance = CameraConfig.CameraMinZoomDistance
	player.CameraMaxZoomDistance = currentDistance
end)

### Camera System

Three client controllers under `src/StarterPlayer/StarterPlayerScripts/`:

- **ThirdPersonCameraController** — Default camera at spawn. Mouse locked centre, AutoRotate off, shoulder offset, character rotates to `Humanoid.MoveDirection`. Suspends on `Signals.OnShootingCameraToggled(true)`.
- **ShootingCameraController** — Glue for the vendored `SmoothShiftLock` package. Engaged only via `Signals.RequestShootingCamera` (called by GrabHook on equip, PlacementClient on build mode entry). Player cannot toggle manually — the Alt/L3 action SmoothShiftLock binds is unbound at startup.
- **CameraBoomController** — Raycast occlusion + zoom clamp shared by both modes. Per-mode max distance: `ShootingCameraMaxZoomDistance` when ShootingCamera is active, `ThirdPersonCameraMaxZoomDistance` otherwise.

All tuning lives in `src/ReplicatedStorage/SharedModules/Configs/CameraConfig.luau`. To change shoulder offset, zoom range, or boom smoothing, edit that file — no code changes needed.
