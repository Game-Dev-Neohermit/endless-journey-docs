Shredder Output Arc → Proximity Pickup Fix — Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Remove the post-arc CanCollide = true / Anchored = false race in ShredderServer so ejected material items are always non-collidable and anchored until proximity pickup claims them.

Architecture: Collapse the two concurrent post-arc paths (tw:OnComplete and task.delay) into a single OnComplete handler. The item is permanently CanCollide = false, Anchored = true from spawn through landing. ProximityPickupServer.RegisterItem is called directly inside OnComplete, which fires PickupItemReady to clients, triggering HoverEffect + spin. The arc animation stays server-side so all clients see it via Roblox part replication.

Tech Stack: Luau, Roblox engine, MotionMaster (SplineMove), ProximityPickupServer, CollectionService

Task 1: Rewrite arc completion in ejectMaterials​

Files:

  • Modify: src/ServerScriptService/ShredderServer.server.luau:354-410

Context for the engineer:

The function ejectMaterials (line 268) loops over each material name and for each one:

  1. Clones a template tool, places it at the spawn point with CanCollide = false, Anchored = true.
  2. Calls MotionMaster.SplineMove and starts a tween arc.
  3. tw:OnComplete (lines 358–364): sets CanCollide = true, Anchored = false — this is the bug.
  4. task.delay(ARC_DURATION, ...) (lines 377–410): calls RegisterItem, AddTag, connects AncestryChanged.

Steps 3 and 4 fire at roughly the same time. Step 3 enables collision before step 4 can re-anchor. The fix collapses 3 and 4 into one OnComplete handler; the separate task.delay is deleted.

  • Step 1: Replace lines 354–410 with the merged OnComplete block

In src/ServerScriptService/ShredderServer.server.luau, replace everything from line 354 (local tw = MotionMaster.SplineMove) through line 410 (closing end) of the task.delay block) with the following. The table.insert(droppedMaterials, ...) block (lines 366–371) moves to just before the SplineMove call so SpawnTime is stamped at spawn, not after the arc.

		-- Track for auto-collect timer (prevents materials piling up indefinitely).
		table.insert(droppedMaterials, {
			Tool = mat,
			Owner = owner,
			SpawnTime = tick(),
		})

		local capturedMaterialName = materialName

		local tw = MotionMaster.SplineMove(handle, { P0, arcPeak, landingPos }, {
			Duration = ShredderConfig.ARC_DURATION,
			Model = "EaseInOutSine",
		})
		tw:OnComplete(function()
			tw:Destroy()
			if not handle.Parent then
				return
			end

			-- Item stays non-collidable and anchored for its entire pickup lifetime.
			-- ProximityPickupServer.RegisterItem will re-assert Anchored = true.
			handle.CanCollide = false
			handle.Anchored = true

			local function pickupCallback(claimedPlayer: Player, meta: { [string]: any })
				mat.Parent = claimedPlayer.Backpack
				local qty = (meta.Quantity or 1) :: number
				for _ = 2, qty do
					local extra = mat:Clone()
					CollectionService:RemoveTag(extra, "PickupItem")
					extra:SetAttribute("PickupItemId", nil)
					extra.Parent = claimedPlayer.Backpack
				end
			end

			ProximityPickupServer.RegisterItem(
				mat :: Model,
				{ MaterialType = capturedMaterialName, ItemType = capturedMaterialName, Quantity = 1 },
				pickupCallback,
				true
			)

			-- Add the CraftMaterial tag AFTER RegisterItem so MaterialPickupService sees
			-- the "PickupItem" tag already present and skips double-registration.
			CollectionService:AddTag(mat, "CraftMaterial")

			-- Re-register when dropped from a Backpack back into the world so any
			-- player can walk over it and pick it up again.
			mat.AncestryChanged:Connect(function()
				local parent = mat.Parent
				if not parent then return end
				-- Skip equipped state: Character has a Humanoid child.
				if parent:FindFirstChildWhichIsA("Humanoid") then return end
				if not mat:IsDescendantOf(workspace) then return end
				if CollectionService:HasTag(mat, "PickupItem") then return end
				ProximityPickupServer.RegisterItem(
					mat :: Model,
					{ MaterialType = capturedMaterialName, ItemType = capturedMaterialName, Quantity = 1 },
					pickupCallback,
					true
				)
			end)
		end):Play()

  • Step 3: Studio play-test — basic arc and pickup

Open Roblox Studio, start Play Solo. Place a Workbench. Put junk items in your backpack. Hold E on the workbench until shredding completes. Verify:

  • Materials visibly arc out of the workbench slot.

  • After landing, materials hover and spin (HoverEffect active — confirms PickupItemReady was received).

  • Standing on the landing spot during or after the arc causes no collision (character walks through the item freely).

  • Walking into a hovering item picks it up (float animation plays, item goes to backpack).

  • Step 4: Studio play-test — immediate pickup on landing

Repeat the shred. Stand exactly at the landing spot while the arc is in-flight. Confirm the item registers for pickup the moment it lands (hover starts, walking there picks it up immediately). Previously the collision would block this.

  • Step 5: Studio play-test — auto-collect

Shred and do not walk over the material. Wait for ShredderConfig.AUTO_COLLECT_DELAY seconds (default 45s). Confirm the item is automatically moved to your backpack and the hover effect stops.

  • Step 6: Studio play-test — drop-and-re-pickup

Pick up a material from a shred. Open your backpack and drop the item (press Backspace with the item equipped). Confirm the dropped item lands, starts hovering, and is proximity-pickupable again (the AncestryChanged re-register path).
