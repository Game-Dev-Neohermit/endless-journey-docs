Camera Consolidation Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Replace the two near-duplicate client camera controllers (ThirdPersonCameraController + ShootingCameraController/SmoothShiftLock) with one mode-aware CameraController, retiring the vendored module and its monkey-patching.

Architecture: A single client LocalScript holds two orthogonal booleans — aimMode (driven by Signals.RequestShootingCamera) and freeLookMode (LeftAlt toggle). A MotionMaster.Spring SpringDriver drives humanoid.CameraOffset toward the active mode's offset; a single BindToRenderStep loop handles character facing (camera-yaw in aim, movement-direction otherwise) and defensive mouse/AutoRotate re-assert. The external signal API (RequestShootingCamera, OnShootingCameraToggled, RequestMouseIcon) is unchanged, so GrabHook, PlacementClient, and CameraBoomController need no edits.

Tech Stack: Luau, Rojo, MotionMaster (project animation lib), Signals bus.

Testing note: This project has no automated test suite — verification happens live in Studio, and per project preference the implementer does not run selene, rojo build, or manual playtests as plan steps. Each task therefore ends with a focused logic review + commit; the human runs the Studio verification checklist (Task 5) at the end. Do not add automated-test steps — there is no runner.

Create src/StarterPlayer/StarterPlayerScripts/CameraController.client.luau with this exact content:

--!strict
--!optimize 2
--!native

local ContextActionService = game:GetService("ContextActionService")
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")
local UserInputService = game:GetService("UserInputService")
local Workspace = game:GetService("Workspace")

local SharedModules = ReplicatedStorage:WaitForChild("SharedModules")
local CameraConfig = require(SharedModules.Configs.CameraConfig)
local MotionMaster = require(SharedModules.MotionMaster)
local Signals = require(SharedModules.Signals)

local player = Players.LocalPlayer
assert(player, "LocalPlayer is nil")
local playerGui = player:WaitForChild("PlayerGui") :: PlayerGui
local camera = Workspace.CurrentCamera
assert(camera, "CurrentCamera is nil")

-- ── Reticle (shown only in aim mode; replaces the locked cursor icon) ─────────
local reticleGui = Instance.new("ScreenGui")
reticleGui.Name = "AimReticle"
reticleGui.ResetOnSpawn = false
reticleGui.Parent = playerGui

local reticleImage = Instance.new("ImageLabel")
reticleImage.BackgroundTransparency = 1
reticleImage.Image = CameraConfig.ReticleImage
reticleImage.Size = UDim2.fromScale(CameraConfig.ReticleScale, CameraConfig.ReticleScale)
reticleImage.Position = UDim2.fromScale(0.5, 0.5)
reticleImage.AnchorPoint = Vector2.new(0.5, 0.5)
reticleImage.Visible = false
reticleImage.Parent = reticleGui

local aspectRatio = Instance.new("UIAspectRatioConstraint")
aspectRatio.AspectRatio = 1
aspectRatio.DominantAxis = Enum.DominantAxis.Height
aspectRatio.Parent = reticleImage

-- ── State ─────────────────────────────────────────────────────────────────────
-- Two orthogonal booleans. aim wins: while aimMode is true, freeLookMode is inert.
local aimMode = false -- driven by Signals.RequestShootingCamera (tools / systems)
local freeLookMode = false -- LeftAlt toggle: free mouse + AutoRotate (non-aim only)
local guiRequestsMouse = false -- cursor-reveal request from a GUI (non-aim only)

local humanoid: Humanoid? = nil
local hrp: BasePart? = nil
local offsetSpring: any = nil -- MotionMaster SpringDriver bound to humanoid.CameraOffset

local function targetOffset(): Vector3
	if aimMode then
		return CameraConfig.ShootingOffset
	end
	return CameraConfig.ThirdPersonOffset
end

-- Centralizes spring target, reticle, mouse behaviour, cursor, and AutoRotate
-- for the current (aimMode, freeLookMode) state. Called on every state change.
local function applyState()
	reticleImage.Visible = aimMode

	if offsetSpring then
		offsetSpring:SetTarget(targetOffset())
	end

	if not humanoid then
		return
	end

	if aimMode then
		humanoid.AutoRotate = false
		UserInputService.MouseBehavior = Enum.MouseBehavior.LockCenter
		UserInputService.MouseIconEnabled = false
	elseif freeLookMode then
		humanoid.AutoRotate = true
		UserInputService.MouseBehavior = Enum.MouseBehavior.Default
		UserInputService.MouseIconEnabled = true
	else
		humanoid.AutoRotate = false
		UserInputService.MouseBehavior = Enum.MouseBehavior.LockCenter
		UserInputService.MouseIconEnabled = guiRequestsMouse
	end
end

-- ── Character lifecycle ─────────────────────────────────────────────────────
local function onCharacterAdded(character: Model)
	humanoid = character:WaitForChild("Humanoid") :: Humanoid
	hrp = character:WaitForChild("HumanoidRootPart") :: BasePart

	-- SpringDriver binds to a specific humanoid; recreate per character.
	offsetSpring = MotionMaster.Spring(humanoid, "CameraOffset", {
		Omega = CameraConfig.OffsetSpringOmega,
		Zeta = CameraConfig.OffsetSpringZeta,
	})

	applyState()
end

if player.Character then
	task.spawn(onCharacterAdded, player.Character)
end
player.CharacterAdded:Connect(onCharacterAdded)
player.CharacterRemoving:Connect(function()
	if offsetSpring then
		offsetSpring:Destroy()
		offsetSpring = nil
	end
	humanoid = nil
	hrp = nil
end)

-- ── Signal wiring ───────────────────────────────────────────────────────────
-- Programmatic aim entry/exit (GrabHook on equip, PlacementClient on build entry).
Signals.RequestShootingCamera:Connect(function(state: boolean?)
	local enable = if type(state) == "boolean" then state else not aimMode
	if enable == aimMode then
		return
	end
	aimMode = enable
	applyState()
	-- Broadcast for CameraBoomController (switches its max-zoom mode).
	Signals.OnShootingCameraToggled:Fire(aimMode)
end)

-- Cursor-reveal request from a future cursor-needing GUI (ignored while aiming).
Signals.RequestMouseIcon:Connect(function(visible: boolean)
	guiRequestsMouse = visible
	applyState()
end)

-- LeftAlt toggles free-mouse vs locked third-person; no-op while aiming.
ContextActionService:BindAction("ToggleCameraMode", function(_, inputState, _)
	if inputState ~= Enum.UserInputState.Begin then
		return Enum.ContextActionResult.Sink
	end
	if aimMode then
		return Enum.ContextActionResult.Sink
	end
	freeLookMode = not freeLookMode
	applyState()
	return Enum.ContextActionResult.Sink
end, false, Enum.KeyCode.LeftAlt)

-- ── Per-frame: character facing + defensive re-assert ───────────────────────
RunService:BindToRenderStep("CameraUpdate", Enum.RenderPriority.Camera.Value + 1, function(dt)
	if not humanoid or not hrp then
		return
	end

	-- Free-mouse default mode: Roblox default camera + AutoRotate handle everything;
	-- the spring keeps driving CameraOffset on its own connection.
	if not aimMode and freeLookMode then
		return
	end

	-- Aim and locked third-person both lock the mouse to centre and disable AutoRotate.
	-- Cursor stays hidden unless a GUI requested it in locked (non-aim) mode.
	humanoid.AutoRotate = false
	if UserInputService.MouseBehavior ~= Enum.MouseBehavior.LockCenter then
		UserInputService.MouseBehavior = Enum.MouseBehavior.LockCenter
	end
	local cursorShouldShow = (not aimMode) and guiRequestsMouse
	if UserInputService.MouseIconEnabled ~= cursorShouldShow then
		UserInputService.MouseIconEnabled = cursorShouldShow
	end

	if humanoid.Sit then
		return
	end

	local alpha = 1 - math.exp(-CameraConfig.RotationLerpSpeed * dt)
	if aimMode then
		-- Face camera yaw (shoulder / aim).
		local _, yaw = camera.CFrame:ToOrientation()
		local goal = CFrame.new(hrp.Position) * CFrame.Angles(0, yaw, 0)
		hrp.CFrame = hrp.CFrame:Lerp(goal, alpha)
	else
		-- Face movement direction (locked third person).
		local moveDir = humanoid.MoveDirection
		if moveDir.Magnitude > 0.1 then
			local yaw = math.atan2(-moveDir.X, -moveDir.Z)
			local goal = CFrame.new(hrp.Position) * CFrame.Angles(0, yaw, 0)
			hrp.CFrame = hrp.CFrame:Lerp(goal, alpha)
		end
	end
end)

Task 5: Studio verification (human-run)​

No automated runner exists; the human syncs via rojo serve and checks in Studio. Run through the spec's checklist:

  • Default spawn → third-person offset; character faces movement direction; mouse locked centre.
  • LeftAlt → free mouse + cursor + AutoRotate; LeftAlt again → locked third-person.
  • Equip GrabHook / aim → reticle appears, shoulder offset eases in (no snap), character faces camera yaw, cursor hidden.
  • Release aim → offset eases back to third-person, reticle hides, prior LeftAlt state restored.
  • Enter build mode (PlacementClient) → aim disengages cleanly.
  • Respawn while aiming and while in third-person → no errors, offset spring resumes (driver recreated).
  • CameraBoom still clamps zoom against walls in both modes (OnShootingCameraToggled still drives it).
