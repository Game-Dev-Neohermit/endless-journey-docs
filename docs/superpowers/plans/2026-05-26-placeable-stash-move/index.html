Placeable Stash / Move Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Add Stash (destroy placed model → return Tool to Backpack) and Move (same + auto-equip) actions, triggered by invisible ImageButtons named MoveButton / StashButton inside any placeable's GUI.

Architecture: A new PlaceableActionsServer script validates and executes requests. A new shared PlaceableActions client module exposes bind(model, gui) for placeable GUI controllers and also runs the poof visual+sound broadcast handler. Three new Packets, two new Signals, two new sound IDs, one new config table. Single one-line edit to PlacementServer so placed models carry a PlaceableName attribute. Studio author must add a sibling ReplicatedStorage/PlaceableTools folder with one Tool per placeable.

Tech Stack: Luau, Rojo, Packets (custom serializer with :Response/OnServerInvoke), Signals (SignalPlus), MotionMaster (animation). No automated test suite — verification is manual in Roblox Studio.

Spec: docs/superpowers/specs/2026-05-26-placeable-stash-move-design.md

Task 5: Implement PlaceableActionsServer​

Files:

  • Create: src/ServerScriptService/PlaceableActionsServer.server.luau

  • Step 1: Create the server script

Create the new file with the following content:

--!strict
--!native
--!optimize 2

-- ┌─────────────────────────────────────────────────────────────────────────┐
-- │  PlaceableActionsServer  (Script — ServerScriptService)                 │
-- │                                                                         │
-- │  Validates and executes Stash / Move requests for placed items.         │
-- │                                                                         │
-- │  Stash: destroy the placed Model + give the matching Tool to the        │
-- │         requesting player's Backpack.                                   │
-- │  Move : same as Stash, plus Humanoid:EquipTool(newTool) if possible.    │
-- │                                                                         │
-- │  Validation:                                                            │
-- │  • Per-player cooldown (PlacementConfig.PlaceableActions.Cooldown).     │
-- │  • Target must be a Model child of workspace.PlacedObjects.             │
-- │  • Target must carry a non-empty PlaceableName attribute.               │
-- │  • Matching Tool must exist in ReplicatedStorage.PlaceableTools.        │
-- │  • Atomic ancestry re-check + immediate reparent to nil prevents        │
-- │    two players double-claiming the same model in the same frame.       │
-- │                                                                         │
-- │  No distance check — locality is enforced by the per-placeable          │
-- │  ProximityPrompt that opens the GUI in the first place.                 │
-- └─────────────────────────────────────────────────────────────────────────┘

local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local SharedModules = ReplicatedStorage:WaitForChild("SharedModules")
local Packets = require(SharedModules:WaitForChild("Packets"))
local PlacementConfig = require(SharedModules.Configs:WaitForChild("PlacementConfig"))

local ReqStashPlaceable = Packets.ReqStashPlaceable
local ReqMovePlaceable = Packets.ReqMovePlaceable
local BroadcastPlaceablePoof = Packets.BroadcastPlaceablePoof

-- ─────────────────────────────────────────────────────────────────
-- Folders
-- ─────────────────────────────────────────────────────────────────

-- Resolve PlaceableTools to a concrete Folder. Lazily create if missing so
-- this script never errors at startup, but warn so the Studio author knows
-- tools must be authored before stash/move can work.
-- Split into a separate block + explicit annotation so Luau's --!strict
-- narrows the optional from FindFirstChild correctly.
local placeableTools: Folder
do
	local existing = ReplicatedStorage:FindFirstChild("PlaceableTools")
	if existing and existing:IsA("Folder") then
		placeableTools = existing
	else
		local folder = Instance.new("Folder")
		folder.Name = "PlaceableTools"
		folder.Parent = ReplicatedStorage
		placeableTools = folder
		warn(
			"[PlaceableActionsServer] Created empty ReplicatedStorage.PlaceableTools — add Tool templates before using Stash/Move."
		)
	end
end

-- workspace.PlacedObjects is created by PlacementServer at startup; FindFirstChild is sufficient.
local function getPlacedObjectsFolder(): Folder?
	local f = workspace:FindFirstChild("PlacedObjects")
	if f and f:IsA("Folder") then
		return f
	end
	return nil
end

-- ─────────────────────────────────────────────────────────────────
-- Per-player cooldown
-- ─────────────────────────────────────────────────────────────────

local lastActionTime: { [Player]: number } = {}

local function isOnCooldown(player: Player): boolean
	local last = lastActionTime[player]
	if not last then
		return false
	end
	return (os.clock() - last) < PlacementConfig.PlaceableActions.Cooldown
end

-- ─────────────────────────────────────────────────────────────────
-- Core handler — shared by Stash and Move
-- ─────────────────────────────────────────────────────────────────

local function handleAction(player: Player, target: Instance, isMove: boolean): boolean
	-- 1. Cooldown
	if isOnCooldown(player) then
		return false
	end

	-- 2. Type
	if typeof(target) ~= "Instance" or not target:IsA("Model") then
		return false
	end
	local model = target :: Model

	-- 3. Ancestry
	local placedFolder = getPlacedObjectsFolder()
	if not placedFolder or model.Parent ~= placedFolder then
		return false
	end

	-- 4. Attribute
	local placeableName = model:GetAttribute("PlaceableName")
	if type(placeableName) ~= "string" or placeableName == "" then
		return false
	end

	-- 5. Template exists
	local toolTemplate = placeableTools:FindFirstChild(placeableName)
	if not toolTemplate or not toolTemplate:IsA("Tool") then
		warn(
			("[PlaceableActionsServer] No Tool '%s' in ReplicatedStorage.PlaceableTools — request denied."):format(
				placeableName
			)
		)
		return false
	end

	-- 6. Atomic claim — re-check parent, then immediately unparent to win the race.
	if model.Parent ~= placedFolder then
		return false
	end
	local cframe = model:GetPivot()
	model.Parent = nil
	if model.Parent ~= nil then
		-- Race: another handler beat us between the check and the assignment.
		return false
	end

	-- 7. Grant Tool to Backpack.
	local newTool = (toolTemplate :: Tool):Clone()
	newTool.Parent = player.Backpack

	-- 8. Move: try to auto-equip. Falls back to Stash behavior if no Humanoid.
	if isMove then
		local character = player.Character
		local humanoid = character and character:FindFirstChildWhichIsA("Humanoid") :: Humanoid?
		if humanoid then
			-- EquipTool auto-unequips any current tool back into Backpack.
			humanoid:EquipTool(newTool)
		else
			warn(("[PlaceableActionsServer] Move for '%s': no Humanoid, tool stays in Backpack."):format(player.Name))
		end
	end

	-- 9. Broadcast poof to all clients.
	BroadcastPlaceablePoof:Fire(cframe, placeableName, isMove)

	-- 10. Destroy the now-orphaned model.
	model:Destroy()

	-- 11. Record cooldown.
	lastActionTime[player] = os.clock()

	return true
end

-- ─────────────────────────────────────────────────────────────────
-- Packet handlers
-- ─────────────────────────────────────────────────────────────────

ReqStashPlaceable.OnServerInvoke = function(player: Player, target: Instance): boolean
	return handleAction(player, target, false)
end

ReqMovePlaceable.OnServerInvoke = function(player: Player, target: Instance): boolean
	return handleAction(player, target, true)
end

-- ─────────────────────────────────────────────────────────────────
-- Cleanup on player leaving
-- ─────────────────────────────────────────────────────────────────

Players.PlayerRemoving:Connect(function(player: Player)
	lastActionTime[player] = nil
end)

Files:

  • Step 1: Create the module

Create the new file with the following content:

--!strict
--!optimize 2

-- ┌─────────────────────────────────────────────────────────────────────────┐
-- │  PlaceableActions  (ModuleScript — ReplicatedStorage/SharedModules)     │
-- │                                                                         │
-- │  Client-only helper for wiring a placeable's GUI Stash/Move buttons     │
-- │  to the server, and for playing the broadcast poof visual+sound.        │
-- │                                                                         │
-- │  Usage in a placeable's GUI controller:                                 │
-- │    local PlaceableActions = require(SharedModules.PlaceableActions)     │
-- │    local binding = PlaceableActions.bind(placedModel, guiRoot)          │
-- │    -- ... when the GUI closes:                                          │
-- │    binding:Unbind()                                                     │
-- │                                                                         │
-- │  GUI requirement: somewhere inside guiRoot's descendants,               │
-- │  ImageButtons named exactly "MoveButton" and "StashButton".             │
-- │  Either may be omitted; missing one logs a warn.                        │
-- └─────────────────────────────────────────────────────────────────────────┘

local CollectionService = game:GetService("CollectionService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")
local SoundService = game:GetService("SoundService")

local IS_CLIENT = RunService:IsClient()

local SharedModules = ReplicatedStorage:WaitForChild("SharedModules")
local Packets = require(SharedModules:WaitForChild("Packets"))
local PlacementConfig = require(SharedModules.Configs:WaitForChild("PlacementConfig"))
local Signals = require(SharedModules:WaitForChild("Signals"))
local MotionMaster = require(SharedModules:WaitForChild("MotionMaster"))

local ReqStashPlaceable = Packets.ReqStashPlaceable
local ReqMovePlaceable = Packets.ReqMovePlaceable
local BroadcastPlaceablePoof = Packets.BroadcastPlaceablePoof

local PLACEMENT_IGNORE_TAG = "PlacementIgnore"

-- ─────────────────────────────────────────────────────────────────
-- Module
-- ─────────────────────────────────────────────────────────────────

local PlaceableActions = {}

export type Binding = {
	Unbind: (Binding) -> (),
}

-- ─────────────────────────────────────────────────────────────────
-- Helpers
-- ─────────────────────────────────────────────────────────────────

local function findButton(root: Instance, name: string): ImageButton?
	for _, desc in root:GetDescendants() do
		if desc:IsA("ImageButton") and desc.Name == name then
			return desc :: ImageButton
		end
	end
	return nil
end

local function playSoundAtPosition(soundId: string, position: Vector3)
	if soundId == "" then
		return
	end
	local sound = Instance.new("Sound")
	sound.SoundId = soundId

	local part = Instance.new("Part")
	part.Anchored = true
	part.CanCollide = false
	part.CanQuery = false
	part.CanTouch = false
	part.Transparency = 1
	part.Size = Vector3.one
	part.Position = position
	part.Parent = workspace

	sound.Parent = part
	sound:Play()
	sound.Ended:Once(function()
		part:Destroy()
	end)

	task.delay(10, function()
		if part.Parent then
			part:Destroy()
		end
	end)
end

-- ─────────────────────────────────────────────────────────────────
-- bind() — wire buttons to packets
-- ─────────────────────────────────────────────────────────────────

function PlaceableActions.bind(model: Model, gui: Instance): Binding
	assert(typeof(model) == "Instance" and model:IsA("Model"), "PlaceableActions.bind: model must be a Model")
	assert(typeof(gui) == "Instance", "PlaceableActions.bind: gui must be an Instance")

	local moveButton = findButton(gui, "MoveButton")
	local stashButton = findButton(gui, "StashButton")

	if not moveButton then
		warn(("[PlaceableActions] No ImageButton named 'MoveButton' inside %s"):format(gui:GetFullName()))
	end
	if not stashButton then
		warn(("[PlaceableActions] No ImageButton named 'StashButton' inside %s"):format(gui:GetFullName()))
	end

	-- Two distinct states:
	--   buttonsDisabled — set when the model is destroyed OR when Unbind() is
	--                     called. Stops dead buttons from being re-clicked.
	--   explicitUnbind  — set ONLY by Unbind(). This is what suppresses the
	--                     success signal. We MUST NOT gate the signal on model
	--                     destruction, because the server always destroys the
	--                     model BEFORE returning success — if we suppressed on
	--                     destruction, the signal would never fire on success.
	local buttonsDisabled = false
	local explicitUnbind = false
	local inFlight = false
	local buttonConnections: { RBXScriptConnection } = {}
	local ancestryConnection: RBXScriptConnection? = nil

	local function disconnectButtons()
		for _, conn in buttonConnections do
			conn:Disconnect()
		end
		table.clear(buttonConnections)
		buttonsDisabled = true
	end

	local function fireAction(packet: any, signal: any)
		if buttonsDisabled or inFlight then
			return
		end
		inFlight = true
		task.spawn(function()
			local success = packet:Fire(model)
			inFlight = false
			if success and not explicitUnbind then
				signal:Fire(model)
			end
		end)
	end

	if moveButton then
		table.insert(
			buttonConnections,
			moveButton.Activated:Connect(function()
				fireAction(ReqMovePlaceable, Signals.OnPlaceableMoved)
			end)
		)
	end
	if stashButton then
		table.insert(
			buttonConnections,
			stashButton.Activated:Connect(function()
				fireAction(ReqStashPlaceable, Signals.OnPlaceableStashed)
			end)
		)
	end

	-- When the model is destroyed (by stash/move success or by anything else),
	-- disconnect the now-useless button listeners. Do NOT mark explicitUnbind:
	-- the in-flight handler still needs to fire the success signal.
	ancestryConnection = model.AncestryChanged:Connect(function(_, parent)
		if parent == nil then
			disconnectButtons()
		end
	end)

	local binding = {} :: Binding
	function binding:Unbind()
		if explicitUnbind then
			return
		end
		explicitUnbind = true
		disconnectButtons()
		if ancestryConnection then
			ancestryConnection:Disconnect()
			ancestryConnection = nil
		end
	end

	return binding
end

-- ─────────────────────────────────────────────────────────────────
-- Poof handler (auto-init on client)
-- ─────────────────────────────────────────────────────────────────

local POOF_FOLDER_NAME = "PlaceablePoofs"

local function getPoofFolder(): Folder
	local existing = workspace:FindFirstChild(POOF_FOLDER_NAME)
	if existing and existing:IsA("Folder") then
		return existing
	end
	local folder = Instance.new("Folder")
	folder.Name = POOF_FOLDER_NAME
	folder.Parent = workspace
	return folder
end

local function strip(model: Model)
	for _, tag in CollectionService:GetTags(model) do
		CollectionService:RemoveTag(model, tag)
	end
	for _, desc in model:GetDescendants() do
		if desc:IsA("Script") or desc:IsA("LocalScript") or desc:IsA("ProximityPrompt") or desc:IsA("ClickDetector") then
			desc:Destroy()
			continue
		end
		for _, tag in CollectionService:GetTags(desc) do
			CollectionService:RemoveTag(desc, tag)
		end
		if desc:IsA("BasePart") then
			desc.CanCollide = false
			desc.CanQuery = false
			desc.CanTouch = false
			desc.Anchored = true
			desc.CastShadow = false
		end
	end
end

local function playPoof(cframe: CFrame, placeableName: string, isMove: boolean)
	local placeableItems = ReplicatedStorage:FindFirstChild("PlaceableItems")
	local template = placeableItems and placeableItems:FindFirstChild(placeableName)

	-- Always play the sound even if the visual template is missing.
	local soundId = if isMove then PlacementConfig.Sounds.Move else PlacementConfig.Sounds.Stash
	playSoundAtPosition(soundId, cframe.Position)

	if not template or not template:IsA("Model") then
		return
	end

	local clone = template:Clone()
	strip(clone)
	clone.Name = placeableName .. "_Poof"
	clone:PivotTo(cframe)
	clone.Parent = getPoofFolder()

	-- Build a parallel sequence of per-part Size + Transparency tweens.
	local seq = MotionMaster.Sequence({ Parallel = true })
	for _, desc in clone:GetDescendants() do
		if desc:IsA("BasePart") then
			local tw = MotionMaster.Create(desc, {
				Size = Vector3.new(0.05, 0.05, 0.05),
				Transparency = 1,
			}, {
				Duration = PlacementConfig.PlaceableActions.PoofDuration,
				Model = "EaseInQuad",
			})
			seq:Add(tw)
		end
	end

	seq:OnComplete(function()
		seq:Destroy()
		if clone.Parent then
			clone:Destroy()
		end
	end):Play()
end

if IS_CLIENT then
	BroadcastPlaceablePoof.OnClientEvent:Connect(playPoof)
end

return PlaceableActions

## Placeable Actions (Stash / Move)

Stash returns a placed item to the player's Backpack. Move does the same and auto-equips it. The action is triggered by invisible `ImageButton`s placed by the GUI author inside the placeable's own GUI (the one opened by its existing `ProximityPrompt`).

### Requirements per placeable

A placeable supports Stash/Move only when **all three** of the following are present:

1. **Model** in `ReplicatedStorage/PlaceableItems/<Name>` — already required for placement.
2. **Tool template** in `ReplicatedStorage/PlaceableTools/<Name>` with attribute `PlaceableName = "<Name>"`. The Tool must have a `Handle` BasePart and otherwise be a fully authored tool the player can equip and use.
3. **GUI buttons** named exactly `MoveButton` and `StashButton` (`ImageButton` instances) anywhere inside the GUI that the placeable's `ProximityPrompt` opens. To make them invisible-but-clickable, set `ImageTransparency = 1` and `BackgroundTransparency = 1`.

If `PlaceableTools/<Name>` is missing, both buttons silently fail server-side (no model is destroyed, no item is lost). If a button is missing from the GUI, the bind helper logs a warning at runtime.

### How to enable Stash/Move on a new placeable — step by step

1. Confirm `ReplicatedStorage/PlaceableItems/<Name>` exists (this is the placement Model — already required).
2. Author a Tool in `ReplicatedStorage/PlaceableTools/<Name>` (create the `PlaceableTools` folder if it does not exist yet). Set the attribute `PlaceableName = "<Name>"` on the Tool. The Tool's `Handle` and animation/behavior scripts are unrelated to this system — author them as you would any normal placeable tool.
3. In the placeable's GUI (the one the existing `ProximityPrompt` opens), add two `ImageButton`s named exactly `MoveButton` and `StashButton`. Place them anywhere inside the GUI's descendants — depth does not matter. To make them invisible-but-clickable, set `ImageTransparency = 1` and `BackgroundTransparency = 1`.
4. In the controller script that opens that GUI, call `PlaceableActions.bind` when the GUI is shown for a specific placed Model, and `Unbind` when the GUI closes:

   ```lua
   local PlaceableActions = require(ReplicatedStorage.SharedModules.PlaceableActions)

   -- When the GUI opens for placedModel:
   local binding = PlaceableActions.bind(placedModel, guiRoot)

   -- When the GUI closes (or the controller cleans up):
   binding:Unbind()
   ```

5. (Optional) Set sound IDs in `PlacementConfig.Sounds.Stash` and `.Move`. Leave as `""` to disable sound playback.
6. (Optional) Tune cooldown and poof duration in `PlacementConfig.PlaceableActions`.

### Server-side guarantees

- Per-player cooldown (`PlacementConfig.PlaceableActions.Cooldown`, default 0.4s) gates spam.
- Target must be a direct child of `workspace.PlacedObjects` and carry a non-empty `PlaceableName` attribute (set automatically by `PlacementServer` when items are placed).
- Atomic claim ensures simultaneous requests from two players never double-grant the Tool.
- No distance check — the per-placeable `ProximityPrompt` enforces locality at GUI-open time.

### Visual feedback

On success, every client receives a `BroadcastPlaceablePoof` and renders a transient clone of the placeable's model that shrinks to nothing over `PlacementConfig.PlaceableActions.PoofDuration` seconds while the configured sound plays at the position. The transient clone is parented to `workspace.PlaceablePoofs` and destroyed when the tween completes.

### Caveats

- Without a matching Tool in `PlaceableTools/`, Stash/Move silently fail for that placeable. Always pair a new placement Model with a Tool template in the same PR.
- Stash/Move discards any per-instance state on the placed Model. The new Tool spawns from the clean template. If state preservation is required, add an attribute-snapshot step before destroy (out of scope for this feature).
- "Anyone nearby can stash anyone's placement" is by design. Add per-instance ownership tracking if grief becomes an issue.
