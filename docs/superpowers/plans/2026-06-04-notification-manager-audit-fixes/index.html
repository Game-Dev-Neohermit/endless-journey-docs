NotificationManager Audit Fixes Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Fix every finding from the NotificationManager audit — the blocking nil-Play() crash, the two behavioral risks, the four nits, and the lineHeight question — without changing the public API or the shared MotionMaster library.

Architecture: Introduce one contained track(cleaner, tween, index?) helper that create→adds→plays a MotionMaster tween, fixing the crash and (via a shared "sizeTween" janitor index) collapsing several frame-Size races into one. Add an entering flag so the Y-fade Heartbeat yields to the intro animation, rebind the ViewportSize listener when CurrentCamera changes, adopt Janitor.Janitor types, pass settings into ensureContainer, drop a dead config field, and remove a phantom text line.

Tech Stack: Luau, Rojo, Roblox engine. In-tree deps: MotionMaster, SoundManager, Signals, howmanysmall/janitor (ReplicatedStorage.Packages.Janitor, type Janitor.Janitor).

Verification note: This project has no automated test suite — verification is in Studio (per CLAUDE.md). Per user preferences: do not run selene or rojo build; the user syncs live via Rojo and verifies in Studio. "Verify" steps below are Luau-LSP type checks or Studio checkpoints the user performs.

Task 3: Add the track helper and route closeEntry through it (blocking-bug primitive)​

Files:

  • Modify: src/ReplicatedStorage/SharedModules/NotificationManager/init.luau

Introduce the create→add→play helper and give it its first real use in closeEntry, where the close tween adopts the shared "sizeTween" index. This keeps the helper exercised before Task 4 wires the five entrance tweens.

  • Step 1: Define the track helper just below the module-scope locals

Place the helper near the top so it is in scope for every caller (resizeAll, closeEntry, show) — Luau local function is only visible to code that textually follows it, and resizeAll appears early in the file.

Find the module-scope locals block:

local initialized = false

local playerGui: Instance

Insert the helper between local pendingResize = false and the -- ── Settings helpers comment:

local initialized = false
local player: Player
local playerGui: Instance
local managerJanitor: Janitor.Janitor
local entries: { Entry } = {}
local layoutCounter = 0
local pendingResize = false

-- ── Tween helper ─────────────────────────────────────────────────

-- Create → track in the janitor → play. MotionMaster's TweenObject:Play()
-- returns nil, so the create/add/play steps must be separate (never
-- `cleaner:Add(Create(...):Play(), ...)`). An optional janitor `index` lets a
-- newer tween on the same property cancel/replace the prior one at that index.
local function track(cleaner: Janitor.Janitor, tween, index: string?)
	cleaner:Add(tween, "Destroy", index)
	tween:Play()
	return tween
end

-- ── Settings helpers ─────────────────────────────────────────────

(The managerJanitor: Janitor.Janitor annotation reflects Task 2's change — apply Task 2 first.)

  • Step 2: Convert closeEntry to use track with the "sizeTween" index

Replace the body of closeEntry:

local function closeEntry(entry: Entry)
	if closing[entry] then
		return
	end
	closing[entry] = true
	removeEntry(entry)

	local frame = entry.frame
	local closeTween = MotionMaster.Create(frame, { Size = UDim2.fromOffset(0, 0) }, {
		Duration = NotificationConfig.AnimDuration,
		Model = NotificationConfig.AnimEasing,
	})
	-- Track the close tween so it stops if the entry cleaner is force-destroyed.
	entry.cleaner:Add(closeTween, "Destroy")
	closeTween:OnComplete(function()
		-- Leave closing[entry] = true permanently to block task.delay re-entry
		-- after the entry has been cleaned up.
		entry.cleaner:Destroy()
	end)
	closeTween:Play()
end

with:

local function closeEntry(entry: Entry)
	if closing[entry] then
		return
	end
	closing[entry] = true
	removeEntry(entry)

	local frame = entry.frame
	-- Index "sizeTween": adopting the shared frame.Size slot cancels any in-flight
	-- intro/resize size tween so they don't fight the close-out shrink.
	local closeTween = track(entry.cleaner, MotionMaster.Create(frame, { Size = UDim2.fromOffset(0, 0) }, {
		Duration = NotificationConfig.AnimDuration,
		Model = NotificationConfig.AnimEasing,
	}), "sizeTween")
	closeTween:OnComplete(function()
		-- Leave closing[entry] = true permanently to block task.delay re-entry
		-- after the entry has been cleaned up.
		entry.cleaner:Destroy()
	end)
end

Note: track already calls :Play(); attaching OnComplete immediately after is safe because completion fires at least one frame later (AnimDuration ≈ 0.33s).

Open the file with Luau LSP. Expected: no errors. track is now defined and used once.

Task 4: Fix the blocking bug — route the five entrance tweens through track (🔴 blocking)​

Files:

  • Modify: src/ReplicatedStorage/SharedModules/NotificationManager/init.luau

The five entrance animations currently call cleaner:Add(MotionMaster.Create(...):Play(), "Destroy"). Because :Play() returns nil, the first add throws and aborts show, leaking every notification. Route them all through track; give the frame-Size tween the "sizeTween" index and an OnComplete that clears entering.

  • Step 1: Replace the entrance-animation block

Find this block in show:

	-- Animations (#14): all via MotionMaster, tracked by the entry Janitor.
	cleaner:Add(MotionMaster.Create(textGradient, { Offset = Vector2.new(0, 0) }, {
		Duration = NotificationConfig.GradientSweepDuration,
		Model = NotificationConfig.AnimEasing,
	}):Play(), "Destroy")
	cleaner:Add(MotionMaster.Create(frame, { Size = UDim2.fromOffset(sizeInfo.Width, sizeInfo.Height) }, {
		Duration = NotificationConfig.AnimDuration,
		Model = NotificationConfig.AnimEasing,
	}):Play(), "Destroy")
	cleaner:Add(MotionMaster.Create(icon, { ImageTransparency = 0 }, {
		Duration = NotificationConfig.AnimDuration,
		Model = NotificationConfig.AnimEasing,
	}):Play(), "Destroy")
	cleaner:Add(MotionMaster.Create(textLabel, { TextTransparency = 0 }, {
		Duration = NotificationConfig.AnimDuration,
		Model = NotificationConfig.AnimEasing,
	}):Play(), "Destroy")
	if timeFiller then
		cleaner:Add(MotionMaster.Create(timeFiller, { Size = UDim2.fromScale(1, 0) }, {
			Duration = notifTime,
			Model = "Linear",
		}):Play(), "Destroy")
	end

Replace it with:

	-- Animations (#14): all via MotionMaster, tracked by the entry Janitor.
	-- track() does create→add→play because TweenObject:Play() returns nil.
	track(cleaner, MotionMaster.Create(textGradient, { Offset = Vector2.new(0, 0) }, {
		Duration = NotificationConfig.GradientSweepDuration,
		Model = NotificationConfig.AnimEasing,
	}))
	-- Intro size tween owns the shared "sizeTween" slot; its completion hands
	-- transparency control from the intro tweens to the Y-fade Heartbeat.
	local introSizeTween = track(cleaner, MotionMaster.Create(frame, {
		Size = UDim2.fromOffset(sizeInfo.Width, sizeInfo.Height),
	}, {
		Duration = NotificationConfig.AnimDuration,
		Model = NotificationConfig.AnimEasing,
	}), "sizeTween")
	introSizeTween:OnComplete(function()
		entry.entering = false
	end)
	track(cleaner, MotionMaster.Create(icon, { ImageTransparency = 0 }, {
		Duration = NotificationConfig.AnimDuration,
		Model = NotificationConfig.AnimEasing,
	}))
	track(cleaner, MotionMaster.Create(textLabel, { TextTransparency = 0 }, {
		Duration = NotificationConfig.AnimDuration,
		Model = NotificationConfig.AnimEasing,
	}))
	if timeFiller then
		track(cleaner, MotionMaster.Create(timeFiller, { Size = UDim2.fromScale(1, 0) }, {
			Duration = notifTime,
			Model = "Linear",
		}))
	end

Note: the entry local is already declared above this block (the entry table literal with entering = true from Task 2), so entry.entering is in scope for the OnComplete closure.

  • Step 2: Verify type-check

Open the file with Luau LSP. Expected: no errors. introSizeTween is the value returned by track (the TweenObject), so :OnComplete is valid.

  • Step 3: Commit
git add src/ReplicatedStorage/SharedModules/NotificationManager/init.luau

Task 8: Rebind the ViewportSize listener when CurrentCamera changes (🟡 risk)​

Files:

  • Modify: src/ReplicatedStorage/SharedModules/NotificationManager/init.luau

The Init-time ViewportSize connection binds the camera once; if CurrentCamera is replaced (respawn / camera swaps) resize silently stops. Add a bindCamera() that (re)connects under a janitor index and a CurrentCamera listener that rebinds.

  • Step 1: Define bindCamera in the resize section

Find the requestResize definition:

local function requestResize()
	if pendingResize then
		return
	end
	pendingResize = true
	task.defer(function()
		pendingResize = false
		resizeAll()
	end)
end

Immediately after it, add:

-- Bind the ViewportSize listener to the current camera. Re-callable: the
-- "cameraViewport" janitor index disconnects the previous camera's listener.
local function bindCamera()
	local camera = Workspace.CurrentCamera
	if not camera then
		return
	end
	managerJanitor:Add(
		camera:GetPropertyChangedSignal("ViewportSize"):Connect(requestResize),
		"Disconnect",
		"cameraViewport"
	)
end

managerJanitor is a module-scope upvalue assigned in Init before bindCamera is ever called, so the closure resolves it correctly at call time.

  • Step 2: Replace the static connection in Init

Find in NotificationManager.Init:

	-- Debounced viewport resize (#10).
	managerJanitor:Add(
		Workspace.CurrentCamera:GetPropertyChangedSignal("ViewportSize"):Connect(requestResize),
		"Disconnect"
	)

Replace it with:

	-- Debounced viewport resize (#10), rebinding if CurrentCamera is replaced.
	managerJanitor:Add(
		Workspace:GetPropertyChangedSignal("CurrentCamera"):Connect(function()
			bindCamera()
			requestResize()
		end),
		"Disconnect"
	)
	bindCamera()

Open the file with Luau LSP. Expected: no errors.
