Train Frozen Start Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: The game begins frozen (no fuel drain, no junk spawn); the first un-brake of the train starts everything, one time per server session.

Architecture: A hasStarted flag in the authoritative TrainFuelManager gates the fuel drain rate to 0 until the first un-brake. A new boolean Signals.SetTrainStarted tells JunkService whether to spawn at all, keeping the existing SetTrainState (fast/slow) concern separate. No client changes.

Tech Stack: Luau, Rojo, in-process Signals event bus, typed Packets.

Project note on verification: This repo has no automated test suite — verification happens in Studio (per CLAUDE.md). Do not run rojo build or selene (per project memory). Each task's verification is by code inspection; final behavioral verification is done by the user live-syncing in Studio. Commit after each task.

Task 2: Gate fuel drain on hasStarted in TrainFuelManager​

Files:

  • Modify: src/ServerStorage/SharedModules/TrainFuelManager.luau

  • Step 1: Add the hasStarted state flag

In the -- [[ STATE ]] block (currently ends around the isRefueling line), add a new flag. Locate:

local isRefueling = false -- serializes concurrent refuel requests

Add immediately below:

local hasStarted = false -- false until the first un-brake; while false, fuel is frozen (rate 0)
  • Step 2: Make rateForState() return 0 while frozen

Replace the existing function:

local function rateForState(): number
	if isStalled then
		return 0
	elseif isBraked then
		return TrainConfig.STOPPED_DRAIN_PER_SEC
	end
	return TrainConfig.RUNNING_DRAIN_PER_SEC
end

with:

local function rateForState(): number
	if not hasStarted then
		return 0 -- frozen pre-game phase: no drain, no scheduled stall
	elseif isStalled then
		return 0
	elseif isBraked then
		return TrainConfig.STOPPED_DRAIN_PER_SEC
	end
	return TrainConfig.RUNNING_DRAIN_PER_SEC
end
  • Step 3: Start the game on the first un-brake in handleToggleBrake

Locate the toggle + commit lines near the end of handleToggleBrake:

	isBraked = not isBraked
	commitEvent()
	return true, isBraked, TrainResultCodes.NONE

Replace with:

	isBraked = not isBraked
	if not hasStarted and not isBraked then
		hasStarted = true
		Signals.SetTrainStarted:Fire(true)
	end
	commitEvent()
	return true, isBraked, TrainResultCodes.NONE
  • Step 4: Reset frozen state in Initialize()

Locate the assignments in TrainFuelManager.Initialize():

	fuelAtLastEvent = TrainConfig.INITIAL_FUEL
	lastEventTime = now()
	isBraked = TrainConfig.INITIAL_BRAKED
	isStalled = false
	gameOverFired = false
	currentRate = rateForState()
	scheduleNonce = 0
	lastRunningState = isRunning()
	isRefueling = false

Replace with (adds hasStarted = false before currentRate is computed, so the initial rate is 0):

	fuelAtLastEvent = TrainConfig.INITIAL_FUEL
	lastEventTime = now()
	isBraked = TrainConfig.INITIAL_BRAKED
	isStalled = false
	gameOverFired = false
	hasStarted = false
	currentRate = rateForState()
	scheduleNonce = 0
	lastRunningState = isRunning()
	isRefueling = false
  • Step 5: Broadcast the initial frozen state

Locate, near the end of Initialize():

	-- Broadcast initial state. Same timestamp as lastEventTime so client extrapolation is exact.
	scheduleNonce += 1
	Signals.SetTrainState:Fire(isRunning())
	reschedule()
	Packets.TrainStateSync:Fire(fuelAtLastEvent, currentRate, isBraked, isStalled, lastEventTime)

Insert a SetTrainStarted:Fire(false) so JunkService is explicitly told spawning is off:

	-- Broadcast initial state. Same timestamp as lastEventTime so client extrapolation is exact.
	scheduleNonce += 1
	Signals.SetTrainStarted:Fire(false)
	Signals.SetTrainState:Fire(isRunning())
	reschedule()
	Packets.TrainStateSync:Fire(fuelAtLastEvent, currentRate, isBraked, isStalled, lastEventTime)
  • Step 6: Verify by inspection

Confirm: (a) while hasStarted == false, rateForState() returns 0, so currentRate is 0 and reschedule() (which only schedules when currentRate > 0 or isStalled) schedules nothing — fuel never drains, never stalls pre-start. (b) handleToggleBrake only fires SetTrainStarted(true) once, on the first transition to un-braked, before commitEvent(). (c) Since the train always starts braked (INITIAL_BRAKED = true), the first toggle is the only way to reach un-braked while not started.

  • Step 7: Commit
git add src/ServerStorage/SharedModules/TrainFuelManager.luau
git commit -m "feat(train): freeze fuel until first un-brake"

Task 3: Gate junk spawning on SetTrainStarted in JunkService​

Files:

  • Modify: src/ServerScriptService/JunkService.server.luau

  • Step 1: Default IsSpawning to false

Locate the CurrentState table:

local CurrentState = {
	Speed = JunkConfig.DEFAULT_JUNK_SPEED,
	SpawnRate = JunkConfig.DEFAULT_SPAWN_RATE,
	IsSpawning = true,
}

Change IsSpawning to false:

local CurrentState = {
	Speed = JunkConfig.DEFAULT_JUNK_SPEED,
	SpawnRate = JunkConfig.DEFAULT_SPAWN_RATE,
	IsSpawning = false, -- off until the train is first un-braked (SetTrainStarted)
}
  • Step 2: Connect SetTrainStarted to toggle spawning

Locate the existing SetTrainState connection block:

Signals.SetTrainState:Connect(SetTrainState)

Add immediately below:

local function SetTrainStarted(started: boolean)
	CurrentState.IsSpawning = started
	if started then
		print("JunkService: Train started - Spawns Enabled")
	end
end
Signals.SetTrainStarted:Connect(SetTrainStarted)
  • Step 3: Gate the spawn loop

Locate the top of the spawn loop body:

task.spawn(function()
	while true do
		local rate = CurrentState.SpawnRate * GlobalModifiers.GlobalSpawnRateMult
		task.wait(rate)

		if currentCount >= JunkConfig.MAX_SERVER_JUNKS then
			continue
		end

Insert an IsSpawning gate right after the task.wait(rate):

task.spawn(function()
	while true do
		local rate = CurrentState.SpawnRate * GlobalModifiers.GlobalSpawnRateMult
		task.wait(rate)

		if not CurrentState.IsSpawning then
			continue
		end

		if currentCount >= JunkConfig.MAX_SERVER_JUNKS then
			continue
		end
  • Step 4: Verify by inspection

Confirm: (a) IsSpawning starts false, so the loop idles (waits then continues) until SetTrainStarted(true) fires. (b) The default-false plus the handler means load order is safe — if SetTrainStarted(false) fires before this connection exists, the default already gates spawning; SetTrainStarted(true) only fires later on un-brake, after the handler is connected. (c) distanceTravelled still only advances while isTrainMoving, which stays false during the frozen phase via SetTrainState(false) — no change needed.

  • Step 5: Commit
git add src/ServerScriptService/JunkService.server.luau
git commit -m "feat(junk): hold spawns until train starts"
