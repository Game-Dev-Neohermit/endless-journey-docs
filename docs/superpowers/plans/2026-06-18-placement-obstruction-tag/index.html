Placement Obstruction Tag Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Make build placement respect static world fixtures (shield generator, tech-tree bench) by switching the obstruction filter to a single PlacementObstruction CollectionService tag.

Architecture: A PlacementObstruction tag becomes the sole source of truth for "this volume blocks build placement." BuildObstructionFilter reads CollectionService:GetTagged instead of the PlacedObjects folder; placed items are tagged on their CollisionBox at finalize time; static fixtures are tagged by hand in Studio. The tag is applied at CollisionBox granularity so the spatial query tests one box per obstruction instead of full mesh hierarchies.

Tech Stack: Luau, Roblox CollectionService, workspace:GetPartBoundsInBox.

Global Constraints​

  • No automated test suite exists in this project. Verification is manual in Roblox Studio (per CLAUDE.md). There is no test-runner step.
  • Do not run rojo build or selene (user syncs live with Studio; both are wasted work per user preference).
  • Tag string must be exactly PlacementObstruction in every file that references it.
  • Tag at the CollisionBox part level, never the whole model — TechTreeBenchPlaceholder has a TrajectoryPoints sub-model whose parts are scattered across the map.
  • Do not commit unless the user explicitly asks. If committing, commit spec + plan + code together (per user preference) and use the Haiku model for the git step.

function PlacementSystem:BuildObstructionFilter(extra: { Model }?): { Instance }
	local filter: { Instance } = {
		self.GhostModelsFolder,
	}

	for _, obstruction in CollectionService:GetTagged(OBSTRUCTION_TAG) do
		table.insert(filter, obstruction)
	end

	for _, player in Players:GetPlayers() do
		if player.Character then
			table.insert(filter, player.Character)
		end
	end

	for _, enemy in CollectionService:GetTagged("Enemy") do
		table.insert(filter, enemy)
	end

	if extra then
		for _, model in extra do
			table.insert(filter, model)
		end
	end

	return filter
end

local function finalizeModel(model: Model)
	local taggedObstruction = false

	for _, inst in model:GetDescendants() do
		if not inst:IsA("BasePart") then
			continue
		end
		local part = inst :: BasePart
		part.Anchored = true

		if part.Name == "CollisionBox" then
			CollectionService:AddTag(part, OBSTRUCTION_TAG)
			taggedObstruction = true
		end

		local isIgnored = part.Name == "RootPart" or part.Name == "CollisionBox"
		if not isIgnored then
			local current: Instance? = part
			while current and current ~= model do
				if CollectionService:HasTag(current, PLACEMENT_IGNORE_TAG) then
					isIgnored = true
					break
				end
				current = current.Parent
			end
		end

		if isIgnored then
			part.Transparency = 1
			part.CanCollide = false
			part.CastShadow = false
			continue
		end

		part.Transparency = 0
		part.CanCollide = true
		part.CastShadow = true
	end

	-- Fallback: a placeable with no CollisionBox still must block placement.
	-- (PlacementSystem warns and uses bounding-box collision for these.)
	if not taggedObstruction then
		local anchor = model.PrimaryPart
		if anchor then
			CollectionService:AddTag(anchor, OBSTRUCTION_TAG)
		else
			CollectionService:AddTag(model, OBSTRUCTION_TAG)
		end
	end
end
