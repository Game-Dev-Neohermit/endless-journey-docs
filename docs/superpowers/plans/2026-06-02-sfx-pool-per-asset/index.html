SFX Per-Asset Sound Pool Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Replace the single shared Sound pool with per-asset sub-pools so SoundId never changes on acquire, eliminating the reload delay that causes audible latency on every grabhook fire.

Architecture: Pool.luau maintains a soundSubPools table keyed by asset ID string. Each sub-pool is a GenericPoolObject whose insertFunction pre-sets SoundId on every allocated instance. Pool.Acquire now accepts the asset ID plus optional pool-size hints (forwarded from SoundDef.PoolInitial / SoundDef.PoolMax). SFX.PlayAt passes those hints through, and playPositional swaps the play order to wait-for-loaded → play so the first play of a cold session still fires the moment the asset is ready.

Tech Stack: Luau, Roblox GenericPoolObject, GenericPoolInstance, SoundService

Which sounds actually benefit: Only sounds played via SoundManager.PlaySFXAt go through the pool. GrabHookFire is the only high-frequency user of that path, so it is the only entry given explicit pool sizing. PlaySFXAt is also used by PlacementPlace, PlaceableMove, and PlaceableStash (low-frequency / currently empty IDs — default 1/5 is fine), and remote GrabHookLoop enters the pool on other clients via the replication receive (SFX.ConnectReplication → playPositional, default sizing). GrabHookCooldown and ProximityPickup use PlaySFX (2D, direct, no pool); local GrabHookLoop uses PlayLooped (direct). So GrabHookCooldown, ProximityPickup, and GrabHookLoop get no pool fields — they would be inert.

Replace the entire file with:

--!strict
-- Pooled instances for positional one-shot SFX.
-- Sound instances are pooled per asset ID: SoundId never changes on acquire,
-- so IsLoaded stays true and Play() fires without a reload delay.

local ReplicatedStorage = game:GetService("ReplicatedStorage")
local SharedModules = ReplicatedStorage.SharedModules
local InstancePool = require(SharedModules.GenericPoolInstance)
local ObjectPool = require(SharedModules.GenericPoolObject)

local Pool = {}

local DEFAULT_INITIAL = 1
local DEFAULT_MAX = 5

local staticPartPool
local soundSubPools: { [string]: ObjectPool.GenericPool } = {}
local pitchPool

local function ensure()
	if staticPartPool then
		return
	end
	local template = ReplicatedStorage:WaitForChild("StaticPart")
	assert(template:IsA("Part"), "StaticPart template is invalid")
	local poolLocation = ReplicatedStorage:WaitForChild("Pools")
	staticPartPool = InstancePool.new(template, 5, 20, 5, poolLocation)
	pitchPool = ObjectPool.new(Instance, { "PitchShiftSoundEffect" }, 0, 20, 5)
end

function Pool.Ensure()
	ensure()
end

local function getOrCreateSoundPool(assetId: string, initial: number?, max: number?): ObjectPool.GenericPool
	local sub = soundSubPools[assetId]
	if not sub then
		local mx = max or DEFAULT_MAX
		local init = math.min(initial or DEFAULT_INITIAL, mx)
		local expand = math.max(1, math.floor(mx / 10))
		sub = ObjectPool.new(Instance, { "Sound" }, init, mx, expand, function(s: any)
			local snd: Sound = s :: Sound
			snd.SoundId = assetId
		end)
		soundSubPools[assetId] = sub
	end
	return sub
end

-- Acquire a part positioned at `position` with a Sound parented to it.
-- The returned Sound already has SoundId = assetId and is likely already loaded.
function Pool.Acquire(position: Vector3, assetId: string, initial: number?, max: number?): (Part, Sound)
	ensure()
	local sub = getOrCreateSoundPool(assetId, initial, max)
	local sound = sub:RetrieveObject() :: Sound
	if sound.SoundId ~= assetId then
		sound.SoundId = assetId
	end
	local part = staticPartPool:RetrieveObject(CFrame.new(position)) :: Part
	part.Parent = workspace
	sound.Parent = part
	return part, sound
end

function Pool.AcquirePitch(): PitchShiftSoundEffect
	ensure()
	return pitchPool:RetrieveObject()
end

-- Return a part + sound (+optional pitch effect) to their pools.
function Pool.Release(part: Part, sound: Sound, pitch: PitchShiftSoundEffect?)
	ensure()
	if pitch then
		pitchPool:InsertObject(pitch)
	end
	task.defer(function()
		local sub = soundSubPools[sound.SoundId]
		if sub then
			sub:InsertObject(sound)
		end
		task.defer(function()
			staticPartPool:InsertObject(part)
		end)
	end)
end

return Pool

Notes on the expand formula: math.max(1, math.floor(mx / 10)) gives expand=1 for DEFAULT_MAX=5 and expand=1 for GrabHookFire's PoolMax=12 — both satisfy GenericPoolObject's requirement that expandSize ≤ maxSize. The insertFunction receives every Sound on initial allocation, pool expansion, and return, keeping SoundId correct in all cases.

Part / pitch pools unchanged: staticPartPool keeps its current sizing (5 / 20 / 5) and pitchPool keeps (0 / 20 / 5) — matching the spec's "Part pool and PitchShiftSoundEffect pool remain unmodified." Only the shared Sound pool is replaced by per-asset sub-pools.

-- Internal: pooled positional play (pitch via PitchShiftSoundEffect).
local function playPositional(id: string, position: Vector3, volume: number, pitch: number)
	local part, sound = Pool.Acquire(position)
	sound.SoundId = id
	sound.Volume = volume
	sound.PlaybackSpeed = 1.0
	sound.SoundGroup = Groups.Get("SFX")

	local pitchEffect: PitchShiftSoundEffect? = nil
	if pitch and pitch ~= 1.0 then
		local effect = Pool.AcquirePitch()
		effect.Octave = pitch
		effect.Parent = sound
		pitchEffect = effect
	end

	sound:Play()
	if not sound.IsLoaded then
		sound.Loaded:Wait()
	end
	task.delay(sound.TimeLength + 0.05, function()
		Pool.Release(part, sound, pitchEffect)
	end)
end

	sound.Volume = volume
	sound.PlaybackSpeed = 1.0
	sound.SoundGroup = Groups.Get("SFX")
