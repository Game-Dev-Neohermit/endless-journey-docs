Train Refuel Hold-Check Fix Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Fix the PromptButtonHoldBegan energy check in TrainClient so it reads Type/Tier from the tool's PrimaryPart (where JunkToolManager sets them) instead of the Tool root.

Architecture: Single file change — two identical loops inside the PromptButtonHoldBegan handler both use item:GetAttribute("Tier") on the Tool root. Replace both with a PrimaryPart lookup that matches the server's getEnergyTier logic. No other files touched.

Tech Stack: Luau, Roblox Studio (live Rojo sync — no rojo build, no selene)

Task 1: Fix the Backpack loop and Character loop in PromptButtonHoldBegan​

Files:

  • Modify: src/StarterPlayer/StarterPlayerScripts/TrainClient.client.luau:161-188

  • Step 1: Open the file and locate the handler

    The handler is inside registerEngine, connected to prompt.PromptButtonHoldBegan. It currently reads:

    local holdConn: RBXScriptConnection = prompt.PromptButtonHoldBegan:Connect(function()
        local hasEnergy = false
        for _, item in LocalPlayer.Backpack:GetChildren() do
            if item:IsA("Tool") and item:GetAttribute("Tier") then
                hasEnergy = true
                break
            end
        end
        if not hasEnergy then
            local char = LocalPlayer.Character
            if char then
                for _, item in char:GetChildren() do
                    if item:IsA("Tool") and item:GetAttribute("Tier") then
                        hasEnergy = true
                        break
                    end
                end
            end
        end
        if not hasEnergy then
            -- TODO: notify player (no energy tools) via custom notification module
            warn("You must hold energy item to refuel the engine")
            prompt.Enabled = false
            task.delay(1, function()
                prompt.Enabled = true
            end)
        end
    end)

  • Step 2: Replace both loops with the PrimaryPart-based check

    Replace the entire handler body with:

    local holdConn: RBXScriptConnection = prompt.PromptButtonHoldBegan:Connect(function()
        local hasEnergy = false
        for _, item in LocalPlayer.Backpack:GetChildren() do
            local pp = item:IsA("Tool") and item.PrimaryPart
            if pp and pp:GetAttribute("Type") == "Energy" and pp:GetAttribute("Tier") then
                hasEnergy = true
                break
            end
        end
        if not hasEnergy then
            local char = LocalPlayer.Character
            if char then
                for _, item in char:GetChildren() do
                    local pp = item:IsA("Tool") and item.PrimaryPart
                    if pp and pp:GetAttribute("Type") == "Energy" and pp:GetAttribute("Tier") then
                        hasEnergy = true
                        break
                    end
                end
            end
        end
        if not hasEnergy then
            -- TODO: notify player (no energy tools) via custom notification module
            warn("You must hold energy item to refuel the engine")
            prompt.Enabled = false
            task.delay(1, function()
                prompt.Enabled = true
            end)
        end
    end)

  • Step 3: Verify in Studio

    With Rojo live-syncing:

    1. Play the game in Studio.
    2. Pick up at least one Energy junk item (any tier) via the GrabHook — it should land in your Backpack as a Tool.
    3. Walk up to the engine and start the refuel hold.
    4. Expected: hold completes, fuel increases, success toast appears. The console warn "You must hold energy item to refuel the engine" must NOT print.
    5. Also verify the negative case: approach the engine with no Energy tools in Backpack or equipped — the warn should still print and the hold should cancel.

  • Step 4: Commit

    git add src/StarterPlayer/StarterPlayerScripts/TrainClient.client.luau
    git commit -m "fix(train-refuel): read Type/Tier from PrimaryPart in hold pre-check"
