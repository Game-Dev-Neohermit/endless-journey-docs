XP & Level System Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Add a persistent, party-shared XP & Level system (cap 100) stored with ProfileStore, earning XP from enemy kills and train "go"-time, replicated to clients with a level-up toast.

Architecture: A place-agnostic server module (XPManager) owns the ProfileStore profile lifecycle, XP→level derivation, the award API, and client replication. A gameplay-only loader script (XPSystemLoader) wires the two earning sources (train go-state via Signals.SetTrainState, enemy deaths via the EnemyNPC tag) to XPManager.AddPartyXP. A client controller (XPController) bridges replication packets to a signal and shows the level-up toast. TotalXP is the single stored value; level/progress are derived from it via a pure XPCurve module.

Tech Stack: Roblox Luau, Rojo, ProfileStore (madstudioroblox/profilestore), the project's Packets (typed RemoteEvent wrapper), Signals (in-process bus), Janitor (cleanup), and NotificationManager (toasts).

Spec: docs/superpowers/specs/2026-06-11-xp-level-system-design.md

Task 3: Add XPCurve (pure math)​

Files:

  • Create: src/ReplicatedStorage/SharedModules/XPCurve.luau

  • Step 1: Write the curve module

--!strict

local ReplicatedStorage = game:GetService("ReplicatedStorage")
local XPConfig = require(ReplicatedStorage.SharedModules.Configs.XPConfig)

--[=[
	@class XPCurve
	Pure functions deriving level and progress from a single cumulative
	`totalXP` value. Cumulative thresholds are precomputed once at require time
	from `XPConfig`. Used server-side by `XPManager`; safe to require anywhere.
]=]
local XPCurve = {}

-- XP required to advance from `level` to `level + 1`. 0 at/above MAX_LEVEL.
function XPCurve.xpToNext(level: number): number
	if level >= XPConfig.MAX_LEVEL then
		return 0
	end
	return math.round(XPConfig.CURVE_COEFF * level ^ XPConfig.CURVE_EXP) + XPConfig.CURVE_OFFSET
end

-- CUMULATIVE[L] = total XP required to BE level L. CUMULATIVE[1] = 0.
local CUMULATIVE: { number } = {}
do
	CUMULATIVE[1] = 0
	for level = 2, XPConfig.MAX_LEVEL do
		CUMULATIVE[level] = CUMULATIVE[level - 1] + XPCurve.xpToNext(level - 1)
	end
end

-- Highest level whose threshold is <= totalXP, clamped to [1, MAX_LEVEL].
function XPCurve.levelFromTotal(totalXP: number): number
	for level = XPConfig.MAX_LEVEL, 1, -1 do
		if totalXP >= CUMULATIVE[level] then
			return level
		end
	end
	return 1
end

-- Returns (level, xpIntoLevel, xpForNextLevel). At cap, xpForNextLevel = 0.
function XPCurve.progress(totalXP: number): (number, number, number)
	local level = XPCurve.levelFromTotal(totalXP)
	local xpIntoLevel = totalXP - CUMULATIVE[level]
	local xpForNextLevel = XPCurve.xpToNext(level)
	return level, xpIntoLevel, xpForNextLevel
end

return XPCurve

Task 6: Add XPManager (profile lifecycle + award API + replication)​

Files:

  • Create: src/ServerStorage/SharedModules/XPManager.luau

  • Step 1: Write the manager

--!strict

--[=[
	@class XPManager
	@server
	Place-agnostic authority for player XP/Level. Owns the ProfileStore profile
	lifecycle (one session per player, key = UserId), derives level/progress
	from the single stored `TotalXP` via `XPCurve`, exposes the award API, and
	replicates state to the owning client via `XPStateSync` / `XPLevelUp`.

	Runs in BOTH the lobby and gameplay places. Earning sources (train distance,
	enemy kills) live in the gameplay-only `XPSystemLoader`, not here.

	Cross-place: `STORE_NAME` + `tostring(UserId)` key are identical in every
	place of the universe, so the same DataStore record is shared. ProfileStore
	session-locking serializes the lobby↔gameplay teleport handoff automatically.
]=]

local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerStorage = game:GetService("ServerStorage")

local SharedModules = ReplicatedStorage.SharedModules
local XPConfig = require(SharedModules.Configs:WaitForChild("XPConfig"))
local XPCurve = require(SharedModules:WaitForChild("XPCurve"))
local Packets = require(SharedModules:WaitForChild("Packets"))
local ProfileStore = require(ServerStorage.SharedModules:WaitForChild("ProfileStore"))

local PROFILE_TEMPLATE = {
	TotalXP = 0,
}

local PlayerStore = ProfileStore.New(XPConfig.STORE_NAME, PROFILE_TEMPLATE)
local Profiles: { [Player]: typeof(PlayerStore:StartSessionAsync("0")) } = {}

local XPManager = {}

-- Fire the current snapshot to one player.
local function replicate(player: Player)
	local profile = Profiles[player]
	if not profile then
		return
	end
	local level, xpIntoLevel, xpForNextLevel = XPCurve.progress(profile.Data.TotalXP)
	Packets.XPStateSync:FireClient(player, level, xpIntoLevel, xpForNextLevel)
end

--[=[
	@within XPManager
	Award `amount` XP to a single player. No-op if amount <= 0 or the player's
	profile is not loaded. Fires `XPLevelUp` when the level increases, then
	replicates the new snapshot.
]=]
function XPManager.AddXP(player: Player, amount: number)
	if amount <= 0 then
		return
	end
	local profile = Profiles[player]
	if not profile then
		return
	end
	local oldLevel = XPCurve.levelFromTotal(profile.Data.TotalXP)
	profile.Data.TotalXP += amount
	local newLevel, xpIntoLevel, xpForNextLevel = XPCurve.progress(profile.Data.TotalXP)
	if newLevel > oldLevel then
		Packets.XPLevelUp:FireClient(player, newLevel)
	end
	Packets.XPStateSync:FireClient(player, newLevel, xpIntoLevel, xpForNextLevel)
end

--[=[
	@within XPManager
	Award `amount` XP to every player in the server with a loaded profile.
	XP is party-shared and one party occupies one server, so this is the
	primary award path for both kills and distance.
]=]
function XPManager.AddPartyXP(amount: number)
	if amount <= 0 then
		return
	end
	for _, player in Players:GetPlayers() do
		if Profiles[player] then
			XPManager.AddXP(player, amount)
		end
	end
end

local function onPlayerAdded(player: Player)
	local profile = PlayerStore:StartSessionAsync(tostring(player.UserId), {
		Cancel = function()
			return player.Parent ~= Players
		end,
	})

	if profile == nil then
		player:Kick("XP profile failed to load — please rejoin.")
		return
	end

	profile:AddUserId(player.UserId) -- GDPR compliance
	profile:Reconcile() -- fill missing fields from PROFILE_TEMPLATE

	profile.OnSessionEnd:Connect(function()
		Profiles[player] = nil
		player:Kick("XP profile session ended — please rejoin.")
	end)

	if player.Parent == Players then
		Profiles[player] = profile
		replicate(player)
	else
		-- Player left before the session started.
		profile:EndSession()
	end
end

--[=[
	@within XPManager
	Wire up the profile lifecycle. Call exactly once per server (from a loader).
]=]
function XPManager.Initialize()
	-- Players who joined before this script ran.
	for _, player in Players:GetPlayers() do
		task.spawn(onPlayerAdded, player)
	end

	Players.PlayerAdded:Connect(onPlayerAdded)

	Players.PlayerRemoving:Connect(function(player)
		local profile = Profiles[player]
		if profile then
			profile:EndSession()
		end
	end)
end

return XPManager

Task 7: Add XPSystemLoader (gameplay earners)​

Files:

  • Create: src/ServerScriptService/XPSystemLoader.server.luau

  • Step 1: Write the loader

--!strict

--[=[
	@class XPSystemLoader
	@server
	Gameplay-place entry point for the XP system. Initializes `XPManager`
	(profile lifecycle + replication), then wires the two earning sources:

	- **Distance:** while the train is in its "go" state (running — not braked,
	  not stalled), award `XPConfig.DISTANCE_XP_PER_TICK` to the whole party
	  every `XPConfig.DISTANCE_TICK_SECONDS`. Go-state is read from
	  `Signals.SetTrainState` (the train starts braked, so no XP accrues
	  pre-start).
	- **Kills:** award `XPConfig.KILL_XP` to the whole party whenever an
	  `EnemyNPC`-tagged model's Humanoid dies (attribution-agnostic — shared XP).

	Do NOT run this in the lobby place; the lobby runs `XPManager.Initialize`
	only (for display + session handoff), without earners.
]=]

local CollectionService = game:GetService("CollectionService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local ServerStorage = game:GetService("ServerStorage")

local SharedModules = ReplicatedStorage.SharedModules
local XPConfig = require(SharedModules.Configs:WaitForChild("XPConfig"))
local Signals = require(SharedModules:WaitForChild("Signals"))
local Janitor = require(ReplicatedStorage.Packages:WaitForChild("Janitor"))
local XPManager = require(ServerStorage.SharedModules:WaitForChild("XPManager"))

XPManager.Initialize()

-- ── Distance earning ──
local trainRunning = false
Signals.SetTrainState:Connect(function(running: boolean)
	trainRunning = running
end)

task.spawn(function()
	while true do
		task.wait(XPConfig.DISTANCE_TICK_SECONDS)
		if trainRunning then
			XPManager.AddPartyXP(XPConfig.DISTANCE_XP_PER_TICK)
		end
	end
end)

-- ── Kill earning ──
-- One Janitor per tracked enemy (project idiom for keyed collections), so each
-- enemy's Humanoid.Died connection is cleaned up when the enemy is untagged.
local enemies: { [Instance]: Janitor.Janitor } = {}

local function watchEnemy(model: Instance)
	if not model:IsA("Model") or enemies[model] then
		return
	end
	local humanoid = model:FindFirstChildWhichIsA("Humanoid")
	if not humanoid then
		warn(("[XPSystemLoader] EnemyNPC '%s' has no Humanoid — not tracking for kill XP."):format(model.Name))
		return
	end
	local cleaner = Janitor.new()
	cleaner:Add(humanoid.Died:Connect(function()
		XPManager.AddPartyXP(XPConfig.KILL_XP)
	end), "Disconnect")
	enemies[model] = cleaner
end

local function unwatchEnemy(model: Instance)
	local cleaner = enemies[model]
	if cleaner then
		cleaner:Destroy()
		enemies[model] = nil
	end
end

for _, model in CollectionService:GetTagged(XPConfig.ENEMY_TAG) do
	watchEnemy(model)
end
CollectionService:GetInstanceAddedSignal(XPConfig.ENEMY_TAG):Connect(watchEnemy)
CollectionService:GetInstanceRemovedSignal(XPConfig.ENEMY_TAG):Connect(unwatchEnemy)

# Progression (XP & Level)

Server-authoritative, party-shared XP & Level system persisted with **ProfileStore**.

## Data model

The profile stores a single value, `TotalXP` (lifetime cumulative). Level and
progress are **derived** from it via [`XPCurve`](../../src/ReplicatedStorage/SharedModules/XPCurve.luau),
so re-tuning the curve never desyncs saved data.

## Curve

`xpToNext(L) = round(CURVE_COEFF * L ^ CURVE_EXP) + CURVE_OFFSET` (defaults
`5`, `1.5`, `45`), cap `MAX_LEVEL = 100`. Total to level 100 ≈ 204,000 XP. All
constants live in `Configs/XPConfig.luau`.

## Earning (party-shared)

XP is shared with the whole party; one party occupies one server, so every
player in the server receives the full award.

- **Distance:** while the train is in its "go" state (running — not braked, not
  stalled), the party earns `DISTANCE_XP_PER_TICK` every `DISTANCE_TICK_SECONDS`.
  Driven off `Signals.SetTrainState`. The train starts braked, so no XP accrues
  before the first un-brake.
- **Kills:** any `EnemyNPC` death awards `KILL_XP` to the party (attribution-
  agnostic). Wired in `XPSystemLoader`.

## Components

- `Configs/XPConfig.luau` — tuning constants.
- `XPCurve.luau` — pure level/progress math.
- `XPManager.luau` (ServerStorage) — profile lifecycle, award API (`AddXP`,
  `AddPartyXP`), replication. Runs in **both** places.
- `XPSystemLoader.server.luau` — gameplay-only earner wiring.
- `XPController.client.luau` — replication bridge → `Signals.OnXPChanged`, and
  the level-up toast via `Signals.RequestNotification`.

## Cross-place (lobby ↔ gameplay)

DataStores are universe-wide. Both places use the same `STORE_NAME` and key
(`tostring(UserId)`), so XP/Level are shared automatically; ProfileStore
session-locking serializes the teleport handoff. **The lobby place must run
`XPManager.Initialize()` and `XPController` (for display + clean handoff) but
NOT `XPSystemLoader`** — no earners in the lobby. The lobby mirror is a separate
deployment, not part of this repo.

## Not yet built

XP bar HUD (will consume `OnXPChanged`), level rewards (hook: `XPLevelUp`),
per-killer attribution, additional XP sources.
