Cannon + Cannon Damage Perk Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Add a grid-placeable, manned cannon that fires server-authoritative explosive arc shells with cooldown + overheat, scaled by the existing CannonDamage party perk — completing perk Spec 5.

Architecture: The cannon reuses two existing stacks. (1) Weapon/projectile: the shell is the rocket path from WeaponServer — a FastCast2 cast with a gravity Acceleration, a replicated cosmetic stepped along it, and CombatService.ApplyAOE on impact. (2) Placement: the cannon is a normal placeable (PlaceableItems/Cannon → workspace/PlacedObjects), so build/stash/move come for free. Server is authoritative for occupancy, cooldown, overheat, origin, and damage; the client only previews and renders FX. Heat is published as attributes on the placed cannon Model (no extra packet). The CannonDamage perk is consumed at the single server damage line: damage = CannonConfig.Damage * (1 + PartyPerkBuffs.CannonDamageBonus).

Tech Stack: Luau, Rojo, FastCast2, Janitor, Packets (typed RemoteEvents/Functions), Signals (client event bus), SoundManager, CollectionService.

Verification note: This repo has no automated test suite — verification happens in Roblox Studio (per CLAUDE.md). Each task ends with a concrete Studio check the developer performs, plus a commit. Do not run rojo build, selene, or attempt automated playtests.

Task 4: CannonServer (server authority)​

Files:

  • Create: src/ServerScriptService/CannonServer.server.luau

  • Step 1: Write the full server module

--!strict

--[=[
    @class CannonServer
    @server
    Authority for the manned cannon (Perk Spec 5). Discovers placed cannons in
    workspace.PlacedObjects (by the PlaceableName attribute), validates mount/fire
    requests, and simulates an authoritative explosive arc shell via a FastCast2
    cast with a gravity Acceleration (the rocket pattern from WeaponServer). Damage
    is scaled by the CannonDamage party perk and applied through CombatService.ApplyAOE.
    Heat is tracked per cannon and published as Heat/Overheated attributes on the
    placed Model (no extra packet). Client aim is never trusted for damage.
]=]

local CollectionService = game:GetService("CollectionService")
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local RunService = game:GetService("RunService")
local ServerStorage = game:GetService("ServerStorage")

local SharedModules = ReplicatedStorage:WaitForChild("SharedModules")
local Packets = require(SharedModules:WaitForChild("Packets"))
local CannonConfig = require(SharedModules.Configs:WaitForChild("CannonConfig"))
local FastCast2 = require(SharedModules:WaitForChild("FastCast2"))
local Janitor = require(ReplicatedStorage.Packages:WaitForChild("Janitor"))

local ServerStorageShared = ServerStorage:WaitForChild("SharedModules")
local ServerProjectile = require(ServerStorageShared:WaitForChild("ServerProjectile"))
local CombatService = require(ServerStorageShared:WaitForChild("CombatService"))

local ReqMountCannon = Packets.ReqMountCannon
local ReqFireCannon = Packets.ReqFireCannon
local CannonFired = Packets.CannonFired
local ExplosionAt = Packets.ExplosionAt

-- ── Per-cannon record ────────────────────────────────────────────────
type CannonRec = {
	model: Model,
	muzzle: BasePart?,
	cleaner: Janitor.Janitor,
	occupant: Player?,
	lastFire: number,
	heat: number,
	overheatUntil: number,
}

local cannons: { [Model]: CannonRec } = {}
local cannonByPlayer: { [Player]: Model } = {}

-- ── Helpers ──────────────────────────────────────────────────────────

local function getMuzzle(model: Model): BasePart?
	local m = model:FindFirstChild(CannonConfig.MUZZLE_PART_NAME)
	return (m and m:IsA("BasePart")) and (m :: BasePart) or nil
end

-- A player counts as a live occupant only while their character is alive. This
-- lets another player take over a cannon whose occupant died without dismounting.
local function isLiveOccupant(player: Player?): boolean
	if not player then
		return false
	end
	local char = player.Character
	local hum = char and char:FindFirstChildOfClass("Humanoid")
	return hum ~= nil and hum.Health > 0
end

local function clearOccupant(rec: CannonRec)
	if rec.occupant then
		cannonByPlayer[rec.occupant] = nil
		rec.occupant = nil
	end
end

-- ── AOE application (Humanoids via CombatService + EnemyShip seam) ────
local function applyCannonAOE(center: Vector3, radius: number, damage: number, shooter: Player, ignore: { Instance })
	-- Humanoid targets (EnemyNPC rigs + players, subject to faction rules).
	CombatService.ApplyAOE(center, radius, damage, "AOE", shooter, ignore)
	-- EnemyShip seam: non-Humanoid destructibles with a numeric `Health` attribute.
	-- Inert until the enemy-ship spec tags ships. Linear falloff to the blast edge.
	for _, ship in CollectionService:GetTagged(CannonConfig.ENEMY_SHIP_TAG) do
		if ship:IsA("Model") then
			local dist = (ship:GetPivot().Position - center).Magnitude
			if dist <= radius then
				local hp = ship:GetAttribute("Health")
				if type(hp) == "number" then
					local newHp = hp - damage * (1 - dist / radius)
					ship:SetAttribute("Health", newHp)
					if newHp <= 0 then
						ship:Destroy()
					end
				end
			end
		end
	end
end

-- ── Authoritative shell caster (gravity arc + AOE; steps a cosmetic) ──
local shellCaster = FastCast2.new()
shellCaster.LengthChanged = function(cast, lastPoint, dir, _displacement)
	local cosmetic = cast.UserData and cast.UserData.cosmetic
	if cosmetic and cosmetic.Parent then
		cosmetic.CFrame = CFrame.lookAlong(lastPoint, dir)
	end
end
shellCaster.Hit = function(cast, result, _velocity, _cosmetic)
	local data = cast.UserData
	if not data then
		return
	end
	if data.cosmetic and data.cosmetic.Parent then
		data.cosmetic:Destroy()
	end
	if not result then
		return
	end
	local center = result.Position
	applyCannonAOE(center, data.radius, data.damage, data.shooter, data.ignore)
	ExplosionAt:Fire(center, data.radius, CannonConfig.WeaponName)
end
shellCaster:Init("BulkMoveTo", false)

-- ── Discovery (placed cannons in workspace.PlacedObjects) ─────────────

local function register(model: Model)
	if cannons[model] then
		return
	end
	local rec: CannonRec = {
		model = model,
		muzzle = getMuzzle(model),
		cleaner = Janitor.new(),
		occupant = nil,
		lastFire = 0,
		heat = 0,
		overheatUntil = 0,
	}
	cannons[model] = rec
	model:SetAttribute("Heat", 0)
	model:SetAttribute("Overheated", false)
end

local function unregister(model: Model)
	local rec = cannons[model]
	if not rec then
		return
	end
	clearOccupant(rec)
	rec.cleaner:Destroy()
	cannons[model] = nil
end

-- PlacementServer parents the placed clone, THEN sets PlaceableName on the next
-- line, so the attribute may be absent on ChildAdded. Register immediately if it's
-- already correct, otherwise wait one shot for the attribute to arrive.
local function tryRegister(child: Instance)
	if not child:IsA("Model") then
		return
	end
	local model = child :: Model
	if model:GetAttribute("PlaceableName") == CannonConfig.PLACEABLE_NAME then
		register(model)
	elseif model:GetAttribute("PlaceableName") == nil then
		local conn: RBXScriptConnection
		conn = model:GetAttributeChangedSignal("PlaceableName"):Connect(function()
			conn:Disconnect()
			if model.Parent and model:GetAttribute("PlaceableName") == CannonConfig.PLACEABLE_NAME then
				register(model)
			end
		end)
	end
end

local placedFolder = workspace:WaitForChild("PlacedObjects", 30)
if not placedFolder then
	-- PlacementServer creates this at startup; without it the cannon cannot exist.
	placedFolder = Instance.new("Folder")
	placedFolder.Name = "PlacedObjects"
	placedFolder.Parent = workspace
	warn("[CannonServer] workspace.PlacedObjects was missing; created a fallback.")
end

for _, child in placedFolder:GetChildren() do
	tryRegister(child)
end
placedFolder.ChildAdded:Connect(tryRegister)
placedFolder.ChildRemoved:Connect(function(child)
	if child:IsA("Model") then
		unregister(child :: Model)
	end
end)

-- ── Mount / dismount ─────────────────────────────────────────────────

ReqMountCannon.OnServerInvoke = function(player: Player, target: Instance?): boolean
	-- Dismount.
	if target == nil then
		local current = cannonByPlayer[player]
		if current then
			local rec = cannons[current]
			if rec and rec.occupant == player then
				clearOccupant(rec)
			else
				cannonByPlayer[player] = nil
			end
		end
		return true
	end

	if typeof(target) ~= "Instance" or not target:IsA("Model") then
		return false
	end
	local model = target :: Model
	local rec = cannons[model]
	if not rec then
		return false
	end

	-- Single occupant: reject only if a DIFFERENT, still-live player holds it.
	if rec.occupant and rec.occupant ~= player and isLiveOccupant(rec.occupant) then
		return false
	end

	-- Proximity (anti-teleport-mount).
	local char = player.Character
	local hrpInst = char and char:FindFirstChild("HumanoidRootPart")
	local hrp = (hrpInst and hrpInst:IsA("BasePart")) and (hrpInst :: BasePart) or nil
	if not hrp then
		return false
	end
	if (hrp.Position - model:GetPivot().Position).Magnitude > CannonConfig.MountRange then
		return false
	end

	-- Release any cannon this player previously held.
	local prev = cannonByPlayer[player]
	if prev and prev ~= model then
		local prevRec = cannons[prev]
		if prevRec and prevRec.occupant == player then
			clearOccupant(prevRec)
		end
	end

	-- Take over a dead occupant's seat if needed.
	if rec.occupant and rec.occupant ~= player then
		clearOccupant(rec)
	end

	rec.occupant = player
	cannonByPlayer[player] = model
	return true
end

-- ── Fire ─────────────────────────────────────────────────────────────

ReqFireCannon.OnServerInvoke = function(player: Player, _origin: Vector3, direction: Vector3): (boolean, number)
	local model = cannonByPlayer[player]
	if not model then
		return false, 0
	end
	local rec = cannons[model]
	if not rec or rec.occupant ~= player then
		return false, 0
	end

	local now = os.clock()
	-- Overheat lock.
	if now < rec.overheatUntil then
		return false, rec.overheatUntil - now
	end
	-- Cooldown.
	local elapsed = now - rec.lastFire
	if elapsed < CannonConfig.FireCooldown then
		return false, CannonConfig.FireCooldown - elapsed
	end
	-- Direction sanity (reject NaN/zero before normalizing; NaN ~= NaN).
	local dmag = direction.Magnitude
	if dmag ~= dmag or dmag < 1e-4 then
		return false, 0
	end
	local unit = direction / dmag

	-- Server-authoritative origin: the cannon's own muzzle, NOT the client's.
	local muzzle = rec.muzzle or getMuzzle(model)
	if not muzzle then
		return false, 0
	end
	rec.muzzle = muzzle
	local muzzlePos = muzzle.Position

	rec.lastFire = now

	-- Perk multiplier: server-written party buff, read per shot (unforgeable).
	local buffs = ReplicatedStorage:FindFirstChild("PartyPerkBuffs")
	local bonus = buffs and buffs:GetAttribute("CannonDamageBonus")
	if type(bonus) ~= "number" then
		bonus = 0
	end
	local damage = CannonConfig.Damage * (1 + bonus)

	-- Authoritative arc shell (rocket pattern + gravity).
	local ignore: { Instance } = { model }
	if player.Character then
		table.insert(ignore, player.Character)
	end
	local cosmetic = ServerProjectile.spawnRocket(CannonConfig.ShellTemplate, CFrame.lookAlong(muzzlePos, unit))
	local behavior = FastCast2.newBehavior()
	local params = RaycastParams.new()
	params.FilterType = Enum.RaycastFilterType.Exclude
	params.FilterDescendantsInstances = ignore
	behavior.RaycastParams = params
	behavior.Acceleration = CannonConfig.Gravity
	behavior.MaxDistance = CannonConfig.MaxAimDistance
	behavior.UserData = {
		shooter = player,
		radius = CannonConfig.AOERadius,
		damage = damage,
		cosmetic = cosmetic,
		ignore = ignore,
	}
	behavior.FastCastEventsConfig.UseLengthChanged = true
	shellCaster:RaycastFire(muzzlePos, unit, CannonConfig.ShellSpeed, behavior)

	-- Safety: if the cast never reports a hit, remove the cosmetic.
	if cosmetic then
		local lifetime = (CannonConfig.MaxAimDistance / CannonConfig.ShellSpeed) + 1
		task.delay(lifetime, function()
			if cosmetic.Parent then
				cosmetic:Destroy()
			end
		end)
	end

	-- Heat.
	rec.heat = math.min(CannonConfig.MaxHeat, rec.heat + CannonConfig.HeatPerShot)
	model:SetAttribute("Heat", rec.heat / CannonConfig.MaxHeat)
	if rec.heat >= CannonConfig.MaxHeat then
		rec.overheatUntil = now + CannonConfig.OverheatLockTime
		model:SetAttribute("Overheated", true)
	end

	-- Broadcast for muzzle flash + barrel snap + fire sound on every client.
	CannonFired:Fire(player, muzzlePos, unit * CannonConfig.ShellSpeed)

	return true, 0
end

-- ── Heat decay + overheat release (server tick) ──────────────────────

RunService.Heartbeat:Connect(function(dt: number)
	local now = os.clock()
	for model, rec in cannons do
		if rec.heat > 0 then
			rec.heat = math.max(0, rec.heat - CannonConfig.HeatDecayPerSec * dt)
			model:SetAttribute("Heat", rec.heat / CannonConfig.MaxHeat)
		end
		if rec.overheatUntil ~= 0 and now >= rec.overheatUntil then
			rec.overheatUntil = 0
			model:SetAttribute("Overheated", false)
		end
	end
end)

-- ── Cleanup ──────────────────────────────────────────────────────────

Players.PlayerRemoving:Connect(function(player: Player)
	local model = cannonByPlayer[player]
	if model then
		local rec = cannons[model]
		if rec and rec.occupant == player then
			clearOccupant(rec)
		else
			cannonByPlayer[player] = nil
		end
	end
end)

local UserInputService = game:GetService("UserInputService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local CannonConfig = require(SharedModules.Configs:WaitForChild("CannonConfig"))
local Signals = require(SharedModules:WaitForChild("Signals"))
local SoundManager = require(SharedModules:WaitForChild("SoundManager"))
local Janitor = require(ReplicatedStorage.Packages:WaitForChild("Janitor"))

local ReqMountCannon = Packets.ReqMountCannon
local ReqFireCannon = Packets.ReqFireCannon

local player = Players.LocalPlayer

-- ── Arc preview constants (mirrors TrajectoryPreview's math) ──────────
local SAMPLE_COUNT = 20
local SEGMENT_COUNT = SAMPLE_COUNT - 1
local HORIZON = 4.0
local SEGMENT_THICKNESS = 0.2
local ARC_COLOR = Color3.fromRGB(255, 170, 70)
local PROJECTILE_GROUP = "WeaponProjectile"

-- ── Mounted-session state (nil when not manning a cannon) ─────────────
local mountedModel: Model? = nil
local sessionJanitor: Janitor.Janitor? = nil
local nextFireClock = 0 -- local client-side rate gate (server is authoritative)

local function getMuzzle(model: Model): BasePart?
	local m = model:FindFirstChild(CannonConfig.MUZZLE_PART_NAME)
	return (m and m:IsA("BasePart")) and (m :: BasePart) or nil
end

-- Aim direction = camera look from the viewport center.
local function getAimDirection(): Vector3?
	local camera = workspace.CurrentCamera
	if not camera then
		return nil
	end
	local viewport = camera.ViewportSize
	local ray = camera:ViewportPointToRay(viewport.X / 2, viewport.Y / 2)
	return ray.Direction.Unit
end

-- ── Arc preview pool ─────────────────────────────────────────────────
local function makeSegment(parent: Instance): BasePart
	local part = Instance.new("Part")
	part.Anchored = true
	part.CanCollide = false
	part.CanQuery = false
	part.CanTouch = false
	part.CastShadow = false
	part.Material = Enum.Material.Neon
	part.Color = ARC_COLOR
	part.Transparency = 1
	part.Size = Vector3.new(SEGMENT_THICKNESS, SEGMENT_THICKNESS, 1)
	part.Parent = parent
	return part
end

local function placeSegment(seg: BasePart, a: Vector3, b: Vector3)
	local delta = b - a
	local length = delta.Magnitude
	if length < 1e-3 then
		seg.Transparency = 1
		return
	end
	seg.Size = Vector3.new(SEGMENT_THICKNESS, SEGMENT_THICKNESS, length)
	seg.CFrame = CFrame.lookAt(a, b) * CFrame.new(0, 0, -length / 2)
	seg.Transparency = 0
end

-- ── Mount / dismount ─────────────────────────────────────────────────

local function dismount()
	if not mountedModel then
		return
	end
	mountedModel = nil
	if sessionJanitor then
		sessionJanitor:Destroy()
		sessionJanitor = nil
	end
	-- Restore movement.
	local char = player.Character
	local hum = char and char:FindFirstChildOfClass("Humanoid")
	if hum then
		hum.WalkSpeed = 16
		hum.JumpPower = 50
		hum.UseJumpPower = true
	end
	Signals.OnCannonMounted:Fire(nil)
	task.spawn(function()
		ReqMountCannon:Fire(nil)
	end)
end

local function fire()
	local model = mountedModel
	if not model then
		return
	end
	if model:GetAttribute("Overheated") == true then
		return
	end
	if os.clock() < nextFireClock then
		return
	end
	local muzzle = getMuzzle(model)
	local dir = getAimDirection()
	if not muzzle or not dir then
		return
	end
	-- Optimistic local gate; server returns the authoritative remaining time.
	nextFireClock = os.clock() + CannonConfig.FireCooldown
	task.spawn(function()
		local accepted, remaining = ReqFireCannon:Fire(muzzle.Position, dir)
		if not accepted then
			nextFireClock = os.clock() + (remaining or 0)
		end
	end)
end

local function mount(model: Model)
	if mountedModel == model then
		return
	end
	if mountedModel then
		dismount()
	end

	local accepted = ReqMountCannon:Fire(model)
	if not accepted then
		return
	end

	mountedModel = model
	local jan = Janitor.new()
	sessionJanitor = jan

	-- Lock movement while manning.
	local char = player.Character
	local hum = char and char:FindFirstChildOfClass("Humanoid")
	if hum then
		hum.WalkSpeed = CannonConfig.MountedWalkSpeed
		hum.JumpPower = 0
		hum.UseJumpPower = true
	end

	-- Arc preview pool.
	local folder = Instance.new("Folder")
	folder.Name = "CannonArcPreview"
	folder.Parent = workspace.CurrentCamera or workspace
	jan:Add(folder, "Destroy")
	local segments: { BasePart } = table.create(SEGMENT_COUNT)
	for i = 1, SEGMENT_COUNT do
		segments[i] = makeSegment(folder)
	end

	local rayParams = RaycastParams.new()
	rayParams.FilterType = Enum.RaycastFilterType.Exclude
	-- Build the filter without a nil hole if the character isn't loaded.
	local filterList: { Instance } = { folder, model }
	if char then
		table.insert(filterList, char)
	end
	rayParams.FilterDescendantsInstances = filterList
	rayParams.CollisionGroup = PROJECTILE_GROUP
	rayParams.RespectCanCollide = true

	-- Per-frame arc render.
	jan:Add(RunService.RenderStepped:Connect(function()
		local muzzle = getMuzzle(model)
		local dir = getAimDirection()
		if not muzzle or not dir then
			for _, seg in segments do
				seg.Transparency = 1
			end
			return
		end
		local startPos = muzzle.Position
		local velocity = dir * CannonConfig.ShellSpeed
		local accel = CannonConfig.Gravity
		local dt = HORIZON / SEGMENT_COUNT
		local points: { Vector3 } = table.create(SAMPLE_COUNT)
		for i = 0, SEGMENT_COUNT do
			local t = i * dt
			points[i + 1] = startPos + velocity * t + 0.5 * accel * (t * t)
		end
		local hitSegment: number? = nil
		for i = 1, SEGMENT_COUNT do
			local a = points[i]
			local b = points[i + 1]
			local result = workspace:Raycast(a, b - a, rayParams)
			if result then
				placeSegment(segments[i], a, result.Position)
				hitSegment = i
				break
			end
			placeSegment(segments[i], a, b)
		end
		if hitSegment then
			for i = hitSegment + 1, SEGMENT_COUNT do
				segments[i].Transparency = 1
			end
		end
	end), "Disconnect")

	-- Dismount if the cannon is stashed/destroyed under us.
	jan:Add(model.AncestryChanged:Connect(function(_, parent)
		if parent == nil then
			dismount()
		end
	end), "Disconnect")

	-- Dismount on death.
	if hum then
		jan:Add(hum.Died:Connect(function()
			dismount()
		end), "Disconnect")
	end

	Signals.OnCannonMounted:Fire(model)
end

local placedFolder = workspace:WaitForChild("PlacedObjects")

local function attachPrompt(model: Model)
	if model:GetAttribute("PlaceableName") ~= CannonConfig.PLACEABLE_NAME then
		return
	end
	local promptPart = model:FindFirstChild(CannonConfig.MOUNT_PROMPT_PART_NAME)
	if not (promptPart and promptPart:IsA("BasePart")) then
		return
	end
	if promptPart:FindFirstChildOfClass("ProximityPrompt") then
		return
	end
	local prompt = Instance.new("ProximityPrompt")
	prompt.ActionText = CannonConfig.PromptActionText
	prompt.ObjectText = CannonConfig.PromptObjectText
	prompt.MaxActivationDistance = CannonConfig.MountRange
	prompt.RequiresLineOfSight = false
	prompt.Parent = promptPart
	prompt.Triggered:Connect(function(triggerPlayer)
		if triggerPlayer == player then
			mount(model)
		end
	end)
end

local function tryAttach(child: Instance)
	if not child:IsA("Model") then
		return
	end
	local model = child :: Model
	if model:GetAttribute("PlaceableName") == CannonConfig.PLACEABLE_NAME then
		attachPrompt(model)
	elseif model:GetAttribute("PlaceableName") == nil then
		local conn: RBXScriptConnection
		conn = model:GetAttributeChangedSignal("PlaceableName"):Connect(function()
			conn:Disconnect()
			if model.Parent then
				attachPrompt(model)
			end
		end)
	end
end

for _, child in placedFolder:GetChildren() do
	tryAttach(child)
end
placedFolder.ChildAdded:Connect(tryAttach)

# Cannon System

A grid-placeable, **manned** cannon that fires server-authoritative explosive arc
shells. It hosts the **Cannon Damage** party perk (`CannonDamageBonus`) and completes
perk Spec 5. The cannon reuses the weapon stack (`FastCast2` + `ServerProjectile` +
`CombatService.ApplyAOE`) and the placement stack (`PlaceableItems` → `PlacedObjects`).

## Placement → mount → fire

1. **Place** — the cannon is a placeable (`PlaceableItems/Cannon` + `PlaceableTools/Cannon`).
   Placement, stash, and move are inherited from the placement system; the placed clone
   lands in `workspace/PlacedObjects` with a `PlaceableName = "Cannon"` attribute.
2. **Mount** — `CannonController` attaches a `ProximityPrompt` to each placed cannon's
   `MountPromptPart`. Triggering it sends `ReqMountCannon(model)`; the server validates
   proximity + single-occupancy and records the gunner. Mounting locks the gunner's
   movement and shows a ballistic arc preview.
3. **Fire** — input sends `ReqFireCannon(muzzle, aimDir)`. The server validates occupancy,
   cooldown, and overheat, then simulates the shell **from its own muzzle CFrame** with a
   gravity `Acceleration`. On impact it applies `Damage × (1 + CannonDamageBonus)` via
   `CombatService.ApplyAOE` and broadcasts `CannonFired` (muzzle flash + barrel snap +
   sound) and `ExplosionAt` (boom).

## Overheat

Each shot adds `HeatPerShot`; heat decays at `HeatDecayPerSec`. Reaching `MaxHeat` locks
the cannon for `OverheatLockTime`. Heat (0–1) and `Overheated` are **attributes on the
placed Model** (no packet); `CannonGuiController` reads them to drive the gunner's heat bar.

## Server authority & anti-exploit

Occupancy, cooldown, overheat-lock, and shell origin are all re-validated server-side;
the server fires from its own muzzle, so a forged origin/aim cannot help. Single occupant
per cannon (a live occupant blocks takeover; a dead one is replaced). `CannonDamageBonus`
is read server-side from the server-written `PartyPerkBuffs` folder per shot — unforgeable.
Faction routing is inherited from `CombatService`, so `EnemyNPC` rigs must be in a hostile
faction to take player damage.

## EnemyShip forward seam

`CannonServer.applyCannonAOE` damages Humanoids via `CombatService` **and** decrements a
numeric `Health` attribute on in-radius models tagged `EnemyShip` (linear falloff,
destroy at ≤0). This is inert until the future enemy-ship spec tags ships; it requires no
change to the perk hook.

  `CannonGuiController.client.luau`

- Signal: `OnCannonMounted`
