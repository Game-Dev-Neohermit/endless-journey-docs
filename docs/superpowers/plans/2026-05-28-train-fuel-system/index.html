Train Fuel System Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Add a global, server-authoritative train fuel system: players refuel by feeding collected Energy junk into the engine via a ProximityPrompt, a separate brake lever stops/resumes the train, and a HUD bar shows the shared fuel level.

Architecture: A dedicated TrainFuelManager server module (mirroring StaminaManager) holds a single global fuel value computed algebraically (event-driven, no per-frame loop). State changes broadcast a TrainStateSync packet; clients predict the bar locally. The manager reuses the existing Signals.SetTrainState (already consumed by JunkService) so braking and stalling slow the floating junk with no JunkService changes.

Tech Stack: Luau, Rojo, the in-tree Packet networking lib, Signals event bus, MotionMaster (client UI only), CollectionService tags, ProximityPrompt.

Verification note (read first)​

This project has no automated test suite — verification happens in Studio via live Rojo sync. Per project conventions, do not run rojo build, selene, or manual playtests as plan steps. Each task's verification is: (1) a focused self-review of the written code against the step, and (2) an optional Studio live-sync observation the user can perform. Commits are frequent and per-task. The engine/lever models do not exist yet; all model-facing code is tag-gated so their absence causes no runtime errors.

--!strict
--!optimize 2

-- ┌─────────────────────────────────────────────────────────────────────────┐
-- │  TrainFuelManager                                                        │
-- │  Authoritative, server-wide (global) train fuel state.                   │
-- │                                                                          │
-- │  Fuel is computed algebraically from the last event — there is no        │
-- │  per-frame loop. Each state change (refuel, brake, stall, resume, init)  │
-- │  snapshots the fuel, updates the drain rate, broadcasts TrainStateSync,  │
-- │  and (re)schedules the next deterministic transition via task.delay,     │
-- │  guarded by a generation nonce. Clients predict the bar locally.         │
-- │                                                                          │
-- │  Reuses Signals.SetTrainState (consumed by JunkService) so braking and   │
-- │  stalling slow the floating junk.                                        │
-- └─────────────────────────────────────────────────────────────────────────┘

local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local CollectionService = game:GetService("CollectionService")

local Shared = ReplicatedStorage.SharedModules
local Configs = Shared.Configs
local TrainConfig = require(Configs:WaitForChild("TrainConfig"))
local TrainResultCodes = require(Shared:WaitForChild("TrainResultCodes"))
local Packets = require(Shared:WaitForChild("Packets"))
local Signals = require(Shared:WaitForChild("Signals"))

local TrainFuelManager = {}

-- [[ STATE ]]
local fuelAtLastEvent = TrainConfig.MAX_FUEL
local lastEventTime = 0
local currentRate = TrainConfig.RUNNING_DRAIN_PER_SEC
local isBraked = false
local isStalled = false
local gameOverFired = false
local scheduleNonce = 0
local lastRunningState = true

-- [[ HELPERS ]]
local function now(): number
	return workspace:GetServerTimeNow()
end

local function getFuel(): number
	local elapsed = now() - lastEventTime
	return math.clamp(fuelAtLastEvent - currentRate * elapsed, 0, TrainConfig.MAX_FUEL)
end

local function isRunning(): boolean
	return not isBraked and not isStalled
end

local function rateForState(): number
	if isStalled then
		return 0
	elseif isBraked then
		return TrainConfig.STOPPED_DRAIN_PER_SEC
	end
	return TrainConfig.RUNNING_DRAIN_PER_SEC
end

local function broadcast()
	Packets.TrainStateSync:Fire(getFuel(), currentRate, isBraked, isStalled, now())
end

-- Forward declarations (mutually recursive: commitEvent -> reschedule -> onStall -> commitEvent)
local commitEvent: (fuelOverride: number?) -> ()
local reschedule: () -> ()
local onStall: () -> ()
local onGameOver: () -> ()

function reschedule()
	local myNonce = scheduleNonce
	if isStalled then
		if not gameOverFired then
			task.delay(TrainConfig.GAME_OVER_DELAY, function()
				if scheduleNonce ~= myNonce then
					return
				end
				onGameOver()
			end)
		end
	elseif currentRate > 0 then
		local timeToEmpty = getFuel() / currentRate
		task.delay(timeToEmpty, function()
			if scheduleNonce ~= myNonce then
				return
			end
			onStall()
		end)
	end
end

-- Snapshot fuel under the OLD rate, then switch to the new rate, bump the nonce
-- (invalidating any pending scheduled callback), reschedule, broadcast, and fire
-- SetTrainState only when the running state actually flips.
function commitEvent(fuelOverride: number?)
	fuelAtLastEvent = fuelOverride or getFuel()
	lastEventTime = now()
	currentRate = rateForState()
	scheduleNonce += 1
	reschedule()
	broadcast()

	local running = isRunning()
	if running ~= lastRunningState then
		lastRunningState = running
		Signals.SetTrainState:Fire(running)
	end
end

function onStall()
	if isStalled then
		return
	end
	isStalled = true
	commitEvent(0) -- force exact 0 to avoid float drift
end

function onGameOver()
	if gameOverFired then
		return
	end
	gameOverFired = true
	print("[TrainFuel] GAME OVER — train out of fuel")
	-- TODO: real game-over mechanic (round reset / respawn / UI). Placeholder for now.
end

-- [[ ENERGY TOOL IDENTIFICATION ]]
local ENERGY_TYPE = "Energy"

local function getEnergyTier(tool: Instance): number?
	if not tool:IsA("Tool") then
		return nil
	end
	local pp = (tool :: Tool).PrimaryPart
	if not pp then
		return nil
	end
	if pp:GetAttribute("Type") ~= ENERGY_TYPE then
		return nil
	end
	local tier = pp:GetAttribute("Tier")
	if typeof(tier) ~= "number" then
		return nil
	end
	return tier :: number
end

local function gatherEnergyTools(player: Player): { Tool }
	local result: { Tool } = {}
	for _, item in player.Backpack:GetChildren() do
		if getEnergyTier(item) then
			table.insert(result, item :: Tool)
		end
	end
	local character = player.Character
	if character then
		local equipped = character:FindFirstChildWhichIsA("Tool")
		if equipped and getEnergyTier(equipped) then
			table.insert(result, equipped)
		end
	end
	return result
end

-- [[ PROXIMITY VALIDATION ]]
-- promptPart is the BasePart that holds the prompt; distance is measured to it
-- using the prompt's authored MaxActivationDistance plus server tolerance.
local function findPromptPart(model: Model, partName: string): (BasePart?, ProximityPrompt?)
	local part = model:FindFirstChild(partName, true)
	if not (part and part:IsA("BasePart")) then
		return nil, nil
	end
	local prompt = part:FindFirstChildWhichIsA("ProximityPrompt")
	return part :: BasePart, prompt
end

local function isPlayerNear(player: Player, promptPart: BasePart, prompt: ProximityPrompt): boolean
	local character = player.Character
	local hrp = character and character:FindFirstChild("HumanoidRootPart") :: BasePart?
	if not hrp then
		return false
	end
	local limit = prompt.MaxActivationDistance + TrainConfig.PROXIMITY_TOLERANCE
	return (hrp.Position - promptPart.Position).Magnitude <= limit
end

-- [[ REFUEL HANDLER ]]
local function handleRefuel(player: Player, engine: Instance): (boolean, number, number)
	if not (engine:IsA("Model") and CollectionService:HasTag(engine, TrainConfig.ENGINE_TAG)) then
		return false, 0, TrainResultCodes.INVALID_ENGINE
	end
	local promptPart, prompt = findPromptPart(engine :: Model, TrainConfig.REFUEL_PROMPT_PART)
	if not (promptPart and prompt) then
		return false, 0, TrainResultCodes.INVALID_ENGINE
	end
	if not isPlayerNear(player, promptPart, prompt) then
		return false, 0, TrainResultCodes.TOO_FAR
	end
	if getFuel() >= TrainConfig.MAX_FUEL then
		return false, 0, TrainResultCodes.FUEL_FULL
	end

	local tools = gatherEnergyTools(player)
	if #tools == 0 then
		return false, 0, TrainResultCodes.NO_ENERGY
	end

	-- Smallest recharge value first, so a big stockpile isn't blown on a small top-up.
	table.sort(tools, function(a, b)
		local va = TrainConfig.TierRecharge[getEnergyTier(a) or 0] or 0
		local vb = TrainConfig.TierRecharge[getEnergyTier(b) or 0] or 0
		return va < vb
	end)

	local humanoid = player.Character and player.Character:FindFirstChildWhichIsA("Humanoid") :: Humanoid?
	local fuel = getFuel()
	local fuelAdded = 0

	for _, tool in tools do
		if fuel >= TrainConfig.MAX_FUEL then
			break
		end
		local tier = getEnergyTier(tool)
		local value = tier and TrainConfig.TierRecharge[tier] or 0
		if value <= 0 then
			continue
		end
		-- Consume the tool (unequip first if it is the equipped one).
		if player.Character and tool.Parent == player.Character and humanoid then
			humanoid:UnequipTools()
		end
		tool:Destroy()
		local before = fuel
		fuel = math.min(TrainConfig.MAX_FUEL, fuel + value)
		fuelAdded += fuel - before
	end

	if fuelAdded <= 0 then
		return false, 0, TrainResultCodes.FUEL_FULL
	end

	-- Clear stall on any positive refuel, then apply as an event.
	if isStalled and fuel > 0 then
		isStalled = false
		gameOverFired = false
	end
	commitEvent(fuel)

	return true, fuelAdded, TrainResultCodes.NONE
end

-- [[ BRAKE HANDLER ]]
local function handleToggleBrake(player: Player, lever: Instance): (boolean, boolean, number)
	if not (lever:IsA("Model") and CollectionService:HasTag(lever, TrainConfig.BRAKE_LEVER_TAG)) then
		return false, isBraked, TrainResultCodes.INVALID_LEVER
	end
	local promptPart, prompt = findPromptPart(lever :: Model, TrainConfig.BRAKE_PROMPT_PART)
	if not (promptPart and prompt) then
		return false, isBraked, TrainResultCodes.INVALID_LEVER
	end
	if not isPlayerNear(player, promptPart, prompt) then
		return false, isBraked, TrainResultCodes.TOO_FAR
	end
	if isStalled then
		return false, isBraked, TrainResultCodes.STALLED
	end

	isBraked = not isBraked
	commitEvent()
	return true, isBraked, TrainResultCodes.NONE
end

-- [[ PUBLIC ]]
function TrainFuelManager.Initialize()
	fuelAtLastEvent = TrainConfig.MAX_FUEL
	lastEventTime = now()
	currentRate = TrainConfig.RUNNING_DRAIN_PER_SEC
	isBraked = false
	isStalled = false
	gameOverFired = false
	lastRunningState = true

	Packets.ReqRefuelTrain.OnServerInvoke = handleRefuel
	Packets.ReqToggleBrake.OnServerInvoke = handleToggleBrake

	-- Send the current snapshot to each joining player so their HUD initializes.
	Players.PlayerAdded:Connect(function(player: Player)
		Packets.TrainStateSync:FireClient(player, getFuel(), currentRate, isBraked, isStalled, now())
	end)

	-- Train starts running on a full tank.
	scheduleNonce += 1
	Signals.SetTrainState:Fire(true)
	reschedule()
	broadcast()
end

return TrainFuelManager

local function showToast(message: string, success: boolean)
	toastLabel.Text = message
	toastLabel.TextColor3 = success and SUCCESS_COLOR or FAILURE_COLOR
	toastFrame.Visible = true
	toastFrame.BackgroundTransparency = 0.2
	if toastTween then
		toastTween:Cancel()
		toastTween = nil
	end
	toastSerial += 1
	local mySerial = toastSerial
	task.delay(TOAST_TIME, function()
		if mySerial ~= toastSerial then
			return
		end
		local tw = MotionMaster.Create(toastFrame, { BackgroundTransparency = 1 }, {
			Duration = 0.4,
			Model = "EaseOutQuad",
		})
		toastTween = tw
		tw:OnComplete(function()
			tw:Destroy()
			if mySerial == toastSerial then
				toastFrame.Visible = false
				toastTween = nil
			end
		end)
		tw:Play()
	end)

local REFUEL_FAIL: { [number]: string } = {
	[TrainResultCodes.INVALID_ENGINE] = "Refuel failed: invalid engine.",
	[TrainResultCodes.TOO_FAR] = "Refuel failed: move closer to the engine.",
	[TrainResultCodes.NO_ENERGY] = "Refuel failed: no energy to feed.",
	[TrainResultCodes.FUEL_FULL] = "Fuel tank is already full.",

local BRAKE_FAIL: { [number]: string } = {
	[TrainResultCodes.INVALID_LEVER] = "Brake failed: invalid lever.",

	[TrainResultCodes.STALLED] = "Out of fuel — refuel before using the brake.",

-- ── Prompt registration ──
type LeverEntry = { prompt: ProximityPrompt, conn: RBXScriptConnection }
local knownEngines: { [Model]: RBXScriptConnection } = {}
local knownLevers: { [Model]: LeverEntry } = {}

local function findPrompt(model: Model, partName: string): ProximityPrompt?
	local part = model:FindFirstChild(partName, true)
	if not (part and part:IsA("BasePart")) then
		return nil
	end
	return part:FindFirstChildWhichIsA("ProximityPrompt")
end

local function leverActionText(braked: boolean): string
	return braked and TrainConfig.BRAKE_ACTION_RESUME or TrainConfig.BRAKE_ACTION_STOP
end

local function updateBrakeActionTexts()
	for _, entry in knownLevers do
		entry.prompt.ActionText = leverActionText(currentIsBraked)
	end
end

local function registerEngine(engine: Model)
	if knownEngines[engine] then
		return
	end
	local prompt = findPrompt(engine, TrainConfig.REFUEL_PROMPT_PART)
	if not prompt then
		warn(("[TrainClient] Engine '%s' missing %s/ProximityPrompt — skipping."):format(engine.Name, TrainConfig.REFUEL_PROMPT_PART))
		return
	end
	local conn = prompt.Triggered:Connect(function()
		task.spawn(function()
			local success, fuelAdded, reason = Packets.ReqRefuelTrain:Fire(engine)
			if success then
				showToast(("Refueled  +%d"):format(math.floor(fuelAdded + 0.5)), true)
			else
				showToast(REFUEL_FAIL[reason] or "Refuel failed.", false)
			end
		end)
	end)
	knownEngines[engine] = conn
end

local function registerLever(lever: Model)
	if knownLevers[lever] then
		return
	end
	local prompt = findPrompt(lever, TrainConfig.BRAKE_PROMPT_PART)
	if not prompt then
		warn(("[TrainClient] Lever '%s' missing %s/ProximityPrompt — skipping."):format(lever.Name, TrainConfig.BRAKE_PROMPT_PART))
		return
	end
	prompt.ActionText = leverActionText(currentIsBraked)
	local conn = prompt.Triggered:Connect(function()
		task.spawn(function()
			local success, braked, reason = Packets.ReqToggleBrake:Fire(lever)
			if success then
				showToast(braked and "Train stopped." or "Train resumed.", true)
			else
				showToast(BRAKE_FAIL[reason] or "Brake failed.", false)
			end
		end)
	end)
	knownLevers[lever] = { prompt = prompt, conn = conn }
end

local function unregisterEngine(engine: Model)
	local conn = knownEngines[engine]
	if conn then
		conn:Disconnect()
		knownEngines[engine] = nil
	end
end

local function unregisterLever(lever: Model)
	local entry = knownLevers[lever]
	if entry then
		entry.conn:Disconnect()
		knownLevers[lever] = nil
	end
end

local function predictedFuel(): number
	local elapsed = workspace:GetServerTimeNow() - snap.serverTime
	return math.clamp(snap.fuel - snap.rate * elapsed, 0, TrainConfig.MAX_FUEL)
end

Signals.OnTrainStateChanged:Connect(function(fuel, rate, isBraked, isStalled, serverTime)
	snap.fuel = fuel
	snap.rate = rate
	snap.isBraked = isBraked
	snap.isStalled = isStalled
	snap.serverTime = serverTime
end)

RunService.RenderStepped:Connect(function(dt: number)
	local target = predictedFuel()
	-- Frame-rate-independent exponential smoothing.
	local alpha = 1 - math.exp(-dt * SMOOTH_K)
	displayedFuel += (target - displayedFuel) * alpha

	local pct = displayedFuel / TrainConfig.MAX_FUEL
	bar.Size = UDim2.fromScale(math.clamp(pct, 0, 1), 1)

	local roundedPct = math.floor(pct * 100 + 0.5)
	if snap.isStalled then
		bar.BackgroundColor3 = STALLED_COLOR
		label.Text = "OUT OF FUEL"
	elseif snap.isBraked then
		bar.BackgroundColor3 = BRAKED_COLOR
		label.Text = ("BRAKED  %d%%"):format(roundedPct)
	else
		bar.BackgroundColor3 = RUNNING_COLOR
		label.Text = ("FUEL  %d%%"):format(roundedPct)
	end
end)

## Train Fuel System

Global, server-wide fuel (0–100). Authoritative state lives in
`ServerStorage/SharedModules/TrainFuelManager.luau` (loaded by
`ServerScriptService/TrainFuelSystemLoader.server.luau`). Fuel is computed
algebraically from the last event — there is no per-frame loop. Each event
(refuel, brake toggle, stall, resume, init) snapshots fuel, switches the drain
rate, broadcasts `TrainStateSync`, and reschedules the next transition via a
nonce-guarded `task.delay`.

- **Running** drains `RUNNING_DRAIN_PER_SEC` (full tank ≈ 10 min). **Braked**
  drains `STOPPED_DRAIN_PER_SEC` (5× slower). **Stalled** (fuel 0) drains nothing.
- Braking and stalling fire the existing `Signals.SetTrainState(false)`, which
  `JunkService` consumes to slow the floating junk. Resuming/refueling fires `true`.
- **Refuel:** players feed collected **Energy** Tools (Tier attribute 1–5) at the
  engine's `RefuelPromptPart` prompt. The server consumes them smallest-recharge-first
  and stops at the cap, preserving the player's stockpile. Values in
  `TrainConfig.TierRecharge`.
- **Brake:** a separate `TrainBrakeLever`-tagged model's `BrakePromptPart` prompt
  toggles stop/resume. Locked out while stalled.
- **Out of fuel:** at 0 the train stalls (junk slows like braked); after
  `GAME_OVER_DELAY` (180 s) without refuel, a placeholder `print` fires (real
  game-over is a TODO). Refueling above 0 cancels the countdown and resumes.
- **HUD:** `TrainFuelGuiController` builds a bar in code and predicts fuel locally
  from the last snapshot's rate + serverTime.

**Models (authored in Studio, tag-gated):** an engine `Model` tagged `TrainEngine`
with a `PrimaryPart` and a child BasePart `RefuelPromptPart` holding a `ProximityPrompt`;
a `Model` tagged `TrainBrakeLever` with a `PrimaryPart` and a child BasePart
`BrakePromptPart` holding a `ProximityPrompt`. Prompt `MaxActivationDistance` and the
refuel prompt's text are set in Studio; the script only sets the lever prompt's `ActionText`.
