Consistent Floating-Junk Speed Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Make all floating junk — existing and newly spawned — share one smoothly-ramped speed so train stop/start changes the apparent motion of every junk consistently, with server despawn kept aligned to client despawn.

Architecture: Linear junk speed becomes a single global value on each side instead of a per-junk baked-in value. Both server and client integrate the same smoothstep-ramped currentSpeed over time. The client moves every junk by currentSpeed * dt; the server integrates the identical timeline into a global junkOdometer and despawns each junk on distance-since-spawn, so both sides retire a junk at the same point. Train state changes broadcast a new target speed via a new SetJunkSpeed packet.

Tech Stack: Luau, Rojo, the project's Packets typed networking layer, Signals event bus.

Testing note: This project has no automated test suite — verification is done by the user in Roblox Studio. Each task ends with a concrete "Studio verification" description of expected behavior and a commit. Do not run rojo build, selene, or attempt automated playtesting.

  • Step 2: Add the shared ramp helper

After the ramp state declarations, add:

-- Advance currentSpeed toward rampTo using smoothstep over SPEED_RAMP_DURATION.
local function advanceSpeed()
	local duration = JunkConfig.SPEED_RAMP_DURATION
	if duration <= 0 then
		currentSpeed = rampTo
		return
	end
	local alpha = math.clamp((os.clock() - rampStart) / duration, 0, 1)
	local smooth = alpha * alpha * (3 - 2 * alpha)
	currentSpeed = rampFrom + (rampTo - rampFrom) * smooth
end

-- Advance currentSpeed toward rampTo using smoothstep over SPEED_RAMP_DURATION.
local function advanceSpeed()
	local duration = JunkConfig.SPEED_RAMP_DURATION
	if duration <= 0 then
		currentSpeed = rampTo
		return
	end
	local alpha = math.clamp((os.clock() - rampStart) / duration, 0, 1)

Then replace the PreSimulation loop body (lines 259-275) so it advances the speed once per frame and moves every junk by the shared currentSpeed:

RunService.PreSimulation:Connect(function(dt)
	advanceSpeed()
	local moveAmount = currentSpeed * dt

	for i = #activeJunks, 1, -1 do
		local data = activeJunks[i]
		local direction = JunkConfig.MOVE_DIRECTION
		local cf = data.Model:GetPivot()
		local newCF = (cf + direction * moveAmount)
			* CFrame.Angles(data.RotSpeed.X * dt, data.RotSpeed.Y * dt, data.RotSpeed.Z * dt)

		data.Model:PivotTo(newCF)
		data.DistanceTraveled += moveAmount

		if data.DistanceTraveled > JunkConfig.DESPAWN_DISTANCE then
			RemoveJunkLocal(data.Id)
		end
	end
end)
