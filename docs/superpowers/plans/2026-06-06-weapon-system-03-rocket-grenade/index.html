Weapon System — Plan 3: Rocket Launcher + Grenade (FastCast2)

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Add the two FastCast2-driven explosive weapons — a rocket launcher (projectile gun, AOE on impact) and a grenade (thrown spherecast arc, AOE on fuse) — with area damage + falloff, server-authoritative simulation, and replicated cosmetics/explosions. Depends on Plan 1 and Plan 2.

Architecture: FastCast2 in serial mode, one reused caster per role. Clients run cosmetic-only casters (via a shared ProjectileVisuals module); the server runs validation casters (no cosmetic) that apply AOE via CombatService.ApplyAOE. Explosions are a single broadcast (ExplosionAt) so every client renders one boom. The rocket reuses Plan 2's ReqFireWeapon; the grenade adds ReqThrowGrenade.

Tech Stack: Luau, Rojo, FastCast2 (serial), Packet, Signals, Janitor, SoundManager, MotionMaster, CollectionService.

Source spec: docs/superpowers/specs/2026-06-06-weapon-system-design.md (§3 rocket/grenade flows, §5 configs, §12 effects).

FastCast2 facts this plan relies on (verified against the imported fork source):

  • local caster = FastCast2.new() → serial caster; set caster.Hit, caster.CastTerminating, caster.LengthChanged, caster.CastFire to callbacks → caster:Init(movementMode, useObjectCache).
  • caster:RaycastFire(origin, dir, speed, behavior) and caster:SpherecastFire(origin, radius, dir, speed, behavior).
  • behavior = FastCast2.newBehavior(); fields: RaycastParams, Acceleration (gravity), MaxDistance, CosmeticBulletTemplate, CosmeticBulletContainer, UserData, and FastCastEventsConfig (a table of Use* booleans).
  • Event signatures (serial): Hit(cast, result, velocity, cosmeticBullet), CastTerminating(cast), LengthChanged(cast, lastPoint, rayDir, displacement), CastFire(cast, origin, dir, velocity, behavior).
  • With no CanPierce callback the cast stops on first hit (perfect for a rocket).
  • FastCastEventsConfig defaults: UseHit = true, UseCastTerminating = true, UseLengthChanged = false, no UseCastFire key → to receive CastFire/LengthChanged you must set those flags true on the behavior.
  • cast.UserData is a copy of behavior.UserData (set per fire to carry shooter/weapon context).
  • FastCast2:GetPositionCast(cast) and FastCast2:TerminateCast(cast) are static helpers on the module.
  • No ObjectCache needed at these volumes; use CosmeticBulletTemplate/CosmeticBulletContainer (cloned per shot, auto-cleaned on terminate).

Conventions: No automated tests (verify in Studio), commits use Haiku, --!strict + Moonwave header.

Task 3: WeaponValidation — AOE falloff + sphere query​

Files: Modify src/ReplicatedStorage/SharedModules/WeaponValidation.luau

  • Step 1: Before return WeaponValidation, add:
-- Linear AOE falloff: full `maxDamage` at the center, 0 at `radius` and beyond.
function WeaponValidation.aoeFalloff(center: Vector3, hitPos: Vector3, radius: number, maxDamage: number): number
	if radius <= 0 then
		return 0
	end
	local distance = (hitPos - center).Magnitude
	if distance >= radius then
		return 0
	end
	return maxDamage * (1 - distance / radius)
end

-- Unique Humanoid-bearing Models whose root is within `radius` of `center`.
-- Returns { { model, humanoid, distance } } for AOE damage application.
export type AOETarget = { model: Model, humanoid: Humanoid, distance: number }
function WeaponValidation.queryAOEModels(center: Vector3, radius: number, ignore: { Instance }): { AOETarget }
	local params = OverlapParams.new()
	params.FilterType = Enum.RaycastFilterType.Exclude
	params.FilterDescendantsInstances = ignore
	params.MaxParts = 200

	local parts = workspace:GetPartBoundsInRadius(center, radius, params)

	local seen: { [Model]: true } = {}
	local result: { AOETarget } = {}
	for _, part in parts do
		local model, humanoid = WeaponValidation.resolveHumanoidModel(part)
		if model and humanoid and not seen[model] then
			seen[model] = true
			local root = model:FindFirstChild("HumanoidRootPart") :: BasePart?
			local pos = root and root.Position or part.Position
			table.insert(result, { model = model, humanoid = humanoid, distance = (pos - center).Magnitude })
		end
	end
	return result
end

Task 4: CombatService — ApplyAOE​

Files: Modify src/ServerStorage/SharedModules/CombatService.luau

  • Step 1: Before return CombatService, add:
-- Apply area damage with linear falloff to every damageable target within
-- `radius` of `center`. `ignore` excludes e.g. the shooter's own character when
-- friendly self-damage is undesired (pass {} to allow self-damage).
function CombatService.ApplyAOE(
	center: Vector3,
	radius: number,
	maxDamage: number,
	attackType: WeaponTypes.DamageType,
	source: Player?,
	ignore: { Instance }
)
	local targets = WeaponValidation.queryAOEModels(center, radius, ignore)
	for _, target in targets do
		local amount = WeaponValidation.aoeFalloff(center, target.model:GetPivot().Position, radius, maxDamage)
		if amount > 0 then
			CombatService.ApplyToModel(target.model, target.humanoid, amount, attackType, source, "Explosion")
		end
	end
end

attackType will be "AOE", and the hard-coded "Explosion" variant matches HealthManager's AOEVariant validation. model:GetPivot().Position is used for falloff distance (robust for both rigs and prop models).

Task 6: ProjectileVisuals (shared client cosmetic casters)​

Files: Create src/ReplicatedStorage/SharedModules/ProjectileVisuals.luau

One module, two reused serial casters (rocket + grenade), cosmetic-only. Used by the shooter's handler AND by WeaponEffectsController for other players, so the flight visual is identical everywhere. Explosion FX is NOT done here (it's driven by ExplosionAt); these casters only fly + self-clean the cosmetic on hit.

  • Step 1: Write the module:
--!strict

--[=[
    @class ProjectileVisuals
    @client
    Cosmetic-only FastCast2 projectile rendering shared by the local shooter and
    by WeaponEffectsController (for other players). Holds one reused serial caster
    per role (rocket, grenade). The cosmetic part flies the configured arc and is
    auto-cleaned on the cast's own surface hit (or after a safety lifetime).
    Damage and explosions are server-authoritative and NOT handled here.
]=]

local ReplicatedStorage = game:GetService("ReplicatedStorage")

local SharedModules = ReplicatedStorage.SharedModules
local FastCast2 = require(SharedModules:WaitForChild("FastCast2"))
local WeaponConfig = require(SharedModules.Configs:WaitForChild("WeaponConfig"))
local WeaponTypes = require(SharedModules:WaitForChild("WeaponTypes"))

local assetsFolder = ReplicatedStorage:WaitForChild("WeaponAssets")

-- Cosmetic projectiles live here so they never get caught by gameplay raycasts.
local container = Instance.new("Folder")
container.Name = "ProjectileCosmetics"
container.Parent = workspace

local ProjectileVisuals = {}

local function makeCaster(): any
	local caster = FastCast2.new()
	-- Cosmetic-only: nothing to do on Hit/Terminate beyond FastCast's own cleanup,
	-- which returns/destroys the cosmetic part automatically.
	caster:Init("BulkMoveTo", false)
	return caster
end

local rocketCaster = makeCaster()
local grenadeCaster = makeCaster()

local function baseBehavior(template: BasePart, acceleration: Vector3, maxDistance: number, ignore: { Instance })
	local behavior = FastCast2.newBehavior()
	local params = RaycastParams.new()
	params.FilterType = Enum.RaycastFilterType.Exclude
	params.FilterDescendantsInstances = ignore
	behavior.RaycastParams = params
	behavior.Acceleration = acceleration
	behavior.MaxDistance = maxDistance
	behavior.CosmeticBulletTemplate = template
	behavior.CosmeticBulletContainer = container
	return behavior
end

local function getTemplate(name: string): BasePart?
	local t = assetsFolder:FindFirstChild(name)
	return (t and t:IsA("BasePart")) and t or nil
end

-- Fly a cosmetic rocket. `ignore` should include the shooter's character.
function ProjectileVisuals.fireRocket(weaponName: string, origin: Vector3, direction: Vector3, ignore: { Instance })
	local config = WeaponConfig[weaponName] :: WeaponTypes.GunWeaponConfig
	local template = getTemplate(config.CosmeticTemplate or "Rocket")
	if not template then
		return
	end
	local behavior = baseBehavior(template, config.Gravity or Vector3.zero, config.MaxDistance, ignore)
	rocketCaster:RaycastFire(origin, direction.Unit, config.ProjectileSpeed or 120, behavior)
end

-- Fly a cosmetic grenade arc. `ignore` should include the thrower's character.
function ProjectileVisuals.fireGrenade(weaponName: string, origin: Vector3, direction: Vector3, ignore: { Instance })
	local config = WeaponConfig[weaponName] :: WeaponTypes.ThrowableWeaponConfig
	local template = getTemplate(config.CosmeticTemplate or "Grenade")
	if not template then
		return
	end
	local behavior = baseBehavior(template, config.Gravity, 2000, ignore)
	grenadeCaster:SpherecastFire(origin, config.SpherecastRadius, direction.Unit, config.ThrowSpeed, behavior)
end

return ProjectileVisuals

Task 8: ThrowableHandler (client grenade)​

Files: Create src/StarterPlayer/StarterPlayerScripts/WeaponHandlers/ThrowableHandler.luau

  • Step 1: Write the module:
--!strict

--[=[
    @class ThrowableHandler
    @client
    Category handler for thrown weapons (grenade). On activate it gates on the
    throw cooldown, plays the throw sound, renders a local cosmetic arc via
    ProjectileVisuals, and sends `ReqThrowGrenade`. Damage + the authoritative
    detonation are server-side; the explosion FX arrives via `ExplosionAt`.
]=]

local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local SharedModules = ReplicatedStorage.SharedModules
local WeaponValidation = require(SharedModules:WaitForChild("WeaponValidation"))
local WeaponTypes = require(SharedModules:WaitForChild("WeaponTypes"))
local Packets = require(SharedModules:WaitForChild("Packets"))
local SoundManager = require(SharedModules:WaitForChild("SoundManager"))
local ProjectileVisuals = require(SharedModules:WaitForChild("ProjectileVisuals"))

local MeleeHandler = require(script.Parent:WaitForChild("MeleeHandler"))
export type HandlerContext = MeleeHandler.HandlerContext

local player = Players.LocalPlayer
local lastThrow: { [string]: number } = {}

local ThrowableHandler = {}

local function getThrowOriginDir(character: Model, tool: Tool): (Vector3, Vector3)
	local handle = tool:FindFirstChild("Handle") :: BasePart?
	local origin = handle and handle.Position or character:GetPivot().Position
	local camera = workspace.CurrentCamera
	local viewport = camera.ViewportSize
	local ray = camera:ViewportPointToRay(viewport.X / 2, viewport.Y / 2)
	-- Bias the throw slightly upward for a natural lob.
	local direction = (ray.Direction + Vector3.new(0, 0.25, 0)).Unit
	return origin, direction
end

function ThrowableHandler.OnEquip(_context: HandlerContext) end

function ThrowableHandler.OnActivate(context: HandlerContext)
	local config = context.config :: WeaponTypes.ThrowableWeaponConfig
	local now = os.clock()
	if not WeaponValidation.canFire(lastThrow[config.ToolName] or -math.huge, config.CooldownTime, now) then
		return
	end
	lastThrow[config.ToolName] = now

	local origin, direction = getThrowOriginDir(context.character, context.tool)
	SoundManager.PlaySFXAt(config.ThrowSound, origin, { Replicate = true })
	ProjectileVisuals.fireGrenade(config.ToolName, origin, direction, { context.character })
	Packets.ReqThrowGrenade:Fire(origin, direction)
end

function ThrowableHandler.OnUnequip(_context: HandlerContext) end

return ThrowableHandler

	if (origin - root.Position).Magnitude > MAX_ORIGIN_DISTANCE then
		return
	end

	WeaponState.SetLastFire(player, gun.ToolName, now)
	WeaponState.SetAmmo(player, gun.ToolName, WeaponValidation.ammoAfterShot(mag), reserve)
	local unit = direction.Unit

	if gun.FireMode == "Projectile" then
		-- Rocket: run the authoritative server cast; AOE applied in rocketServerCaster.Hit.
		local behavior = FastCast2.newBehavior()
		local params = RaycastParams.new()
		params.FilterType = Enum.RaycastFilterType.Exclude
		params.FilterDescendantsInstances = { character }
		behavior.RaycastParams = params
		behavior.Acceleration = gun.Gravity or Vector3.zero
		behavior.MaxDistance = gun.MaxDistance
		behavior.UserData = {
			shooter = player,
			character = character,
			weaponName = gun.ToolName,
			radius = gun.AOERadius or 0,
			aoeDamage = gun.AOEDamage or 0,
		}
		rocketServerCaster:RaycastFire(origin, unit, gun.ProjectileSpeed or 120, behavior)
		Packets.ProjectileSpawned:Fire(player, gun.ToolName, origin, unit, gun.ProjectileSpeed or 120)
	else
		-- Hitscan path (Plan 2).
		local hitParams = RaycastParams.new()
		hitParams.FilterType = Enum.RaycastFilterType.Exclude
		hitParams.FilterDescendantsInstances = { character }
		local result = workspace:Raycast(origin, unit * gun.MaxDistance, hitParams)
		local endpoint = origin + unit * gun.MaxDistance
		local isHit = false
		if result then
			endpoint = result.Position
			local model, humanoid = WeaponValidation.resolveHumanoidModel(result.Instance)
			if model and humanoid then
				local amount = gun.Damage
				if result.Instance.Name == "Head" then
					amount *= (gun.HeadshotMultiplier or 1)
				end
				isHit = CombatService.ApplyToModel(model, humanoid, amount, gun.DamageType, player)
			end
		end
		Packets.WeaponFired:Fire(player, gun.ToolName, origin, endpoint, isHit)
	end

	local newMag, newReserve = WeaponState.GetAmmo(player, gun.ToolName)
	Packets.WeaponAmmoSync:FireClient(player, gun.ToolName, newMag, newReserve)

local GRENADE_MAX_ORIGIN_DISTANCE = 14

local function onThrowGrenade(player: Player, origin: Vector3, direction: Vector3)
	local _tool, config = getEquippedWeapon(player)
	if not config or config.Category ~= "Throwable" then
		return
	end
	local grenade = config :: WeaponTypes.ThrowableWeaponConfig

	local now = os.clock()
	if not WeaponValidation.canFire(WeaponState.GetLastFire(player, grenade.ToolName), grenade.CooldownTime, now) then
		return
	end
	local character = player.Character
	local root = character and character:FindFirstChild("HumanoidRootPart") :: BasePart?
	if not character or not root then
		return
	end
	if (origin - root.Position).Magnitude > GRENADE_MAX_ORIGIN_DISTANCE then
		return
	end
	WeaponState.SetLastFire(player, grenade.ToolName, now)

	local record = { lastPos = origin, restPos = nil :: Vector3?, character = character }

	local behavior = FastCast2.newBehavior()
	local params = RaycastParams.new()
	params.FilterType = Enum.RaycastFilterType.Exclude
	params.FilterDescendantsInstances = { character }
	behavior.RaycastParams = params
	behavior.Acceleration = grenade.Gravity
	behavior.MaxDistance = 2000
	behavior.UserData = record
	behavior.FastCastEventsConfig.UseLengthChanged = true -- needed to track lastPos

	grenadeServerCaster:SpherecastFire(origin, grenade.SpherecastRadius, direction.Unit, grenade.ThrowSpeed, behavior)
	Packets.GrenadeThrown:Fire(player, grenade.ToolName, origin, direction.Unit, grenade.ThrowSpeed)

	task.delay(grenade.FuseTime, function()
		local center = record.restPos or record.lastPos
		CombatService.ApplyAOE(center, grenade.AOERadius, grenade.AOEDamage, "AOE", player, {})
		Packets.ExplosionAt:Fire(center, grenade.AOERadius, grenade.ToolName)
	end)
end

Packets.ReqThrowGrenade.OnServerEvent:Connect(onThrowGrenade)

Grenade AOE passes ignore = {} so the thrower can take self-damage (classic grenade behavior). Change to { character } if you want thrower immunity.
