DamageNumbers Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Build a client-only, render-only DamageNumbers module that spawns pooled world-space billboard damage numbers which pop from small to large, drift upward, fade out, and can be toggled on/off at runtime.

Architecture: A DamageNumberConfig data module holds all tuning (named style presets, timings, pool sizes, billboard size). DamageNumbers builds a BillboardGui template, manages a GenericPoolInstance pool of anchor parts, and on Show(pos, amount, styleName) acquires an entry, applies the style, jitters the position, and plays pop + rise + fade via MotionMaster. Each live number owns a Janitor; on completion the entry is released to the pool. A tiny client bootstrap pre-warms the pool.

Tech Stack: Luau, Rojo, Roblox BillboardGui/UIScale, GenericPoolInstance (object pool), MotionMaster (animation), Janitor (cleanup).

local DamageNumberConfig = {}

-- Initial toggle state. The settings menu calls DamageNumbers.SetEnabled later.
DamageNumberConfig.StartEnabled = true

-- Style name used when Show() is called without one (or with an unknown one).
DamageNumberConfig.DefaultStyle = "normal"

export type Style = {
	Color: Color3,
	Font: Enum.Font,
	SizeScale: number, -- multiplier applied to Billboard.BaseSize (world studs)
	StrokeColor: Color3,
	StrokeTransparency: number,
}

-- Named presets. Add more here without touching the module.
DamageNumberConfig.Styles = {
	normal = {
		Color = Color3.fromRGB(255, 255, 255),
		Font = Enum.Font.GothamBold,
		SizeScale = 1,
		StrokeColor = Color3.fromRGB(0, 0, 0),
		StrokeTransparency = 0.4,
	},
	crit = {
		Color = Color3.fromRGB(255, 86, 86),
		Font = Enum.Font.GothamBlack,
		SizeScale = 1.5,
		StrokeColor = Color3.fromRGB(40, 0, 0),
		StrokeTransparency = 0.2,
	},
	heal = {
		Color = Color3.fromRGB(120, 255, 130),
		Font = Enum.Font.GothamBold,
		SizeScale = 1,
		StrokeColor = Color3.fromRGB(0, 40, 0),
		StrokeTransparency = 0.4,
	},
} :: { [string]: Style }

-- Pop-in: UIScale.Scale animates StartScale -> 1 with an overshoot curve.
DamageNumberConfig.Pop = {
	Duration = 0.18,
	StartScale = 0.2,
}

-- Upward drift over the number's lifetime (studs of BillboardGui.StudsOffsetWorldSpace.Y).
DamageNumberConfig.Rise = {
	Height = 4,
	Easing = "EaseOutQuad", -- MotionMaster built-in AlphaModels name (decelerate)
}

-- Fade-out window at the end of life (TextTransparency/TextStrokeTransparency -> 1).
DamageNumberConfig.Fade = {
	Duration = 0.4,
}

-- Total seconds on screen before the entry is released to the pool.
DamageNumberConfig.Lifetime = 1.0

-- Random spawn offset so rapid hits fan out instead of stacking (+/- studs per axis).
DamageNumberConfig.Jitter = {
	Horizontal = 1.2,
	Vertical = 0.6,
}

-- Object pool sizing (GenericPoolInstance).
DamageNumberConfig.Pool = {
	InitialSize = 24,
	MaxSize = 200,
}

-- BillboardGui appearance. BaseSize is in Scale units so numbers shrink with
-- camera distance (world-space size). MaxDistance culls far ones.
DamageNumberConfig.Billboard = {
	BaseSize = UDim2.fromScale(4, 1.5),
	MaxDistance = 120,
	AlwaysOnTop = false,
}

return DamageNumberConfig

Create src/ReplicatedStorage/SharedModules/DamageNumbers.luau:

--!strict

--[=[
	@class DamageNumbers
	@client
	Render-only floating damage numbers. Any client code calls
	`DamageNumbers.Show(worldPosition, amount, styleName?)` to spawn a
	world-space `BillboardGui` that pops from small to large, drifts upward, and
	fades out. Instances are pooled (`GenericPoolInstance`) and animated with
	`MotionMaster`. This module renders only — it never computes or applies
	damage (damage is server-authoritative; see `CombatService`). Styling lives
	in `Configs/DamageNumberConfig`.

	`SetEnabled(false)` stops new numbers (for a settings-menu toggle); numbers
	already on screen finish their animation.
]=]

local ReplicatedStorage = game:GetService("ReplicatedStorage")

local SharedModules = ReplicatedStorage.SharedModules
local GenericPoolInstance = require(SharedModules.GenericPoolInstance)
local MotionMaster = require(SharedModules.MotionMaster)
local Config = require(SharedModules.Configs.DamageNumberConfig)
local Janitor = require(ReplicatedStorage.Packages.Janitor)

local DamageNumbers = {}

local enabled = Config.StartEnabled
local pool: any = nil -- GenericPoolInstance pool (lazy-built in Init)
local activeJanitors: { [Instance]: any } = {} -- anchor part -> Janitor of its live tween(s)

-- Build the template that the pool clones: an anchored, invisible, non-colliding
-- part holding a BillboardGui > TextLabel > UIScale.
local function buildTemplate(): BasePart
	local part = Instance.new("Part")
	part.Name = "DamageNumber"
	part.Size = Vector3.new(0.2, 0.2, 0.2)
	part.Transparency = 1
	part.Anchored = true
	part.CanCollide = false
	part.CanQuery = false
	part.CanTouch = false
	part.Massless = true
	part.Locked = true

	local billboard = Instance.new("BillboardGui")
	billboard.Name = "Billboard"
	billboard.Size = Config.Billboard.BaseSize
	billboard.MaxDistance = Config.Billboard.MaxDistance
	billboard.AlwaysOnTop = Config.Billboard.AlwaysOnTop
	billboard.LightInfluence = 0
	billboard.ResetOnSpawn = false
	billboard.Parent = part

	local label = Instance.new("TextLabel")
	label.Name = "Amount"
	label.Size = UDim2.fromScale(1, 1)
	label.BackgroundTransparency = 1
	label.TextScaled = true
	label.Font = Enum.Font.GothamBold
	label.Text = "0"
	label.TextStrokeTransparency = 0.4
	label.Parent = billboard

	local scale = Instance.new("UIScale")
	scale.Name = "Pop"
	scale.Scale = 0
	scale.Parent = label

	return part
end

-- Reset a pooled entry to its idle/hidden state. Used as the pool insertFunction
-- so returned entries are clean for reuse.
local function resetEntry(part: any)
	local billboard = part:FindFirstChild("Billboard") :: BillboardGui?
	if not billboard then
		return
	end
	billboard.StudsOffsetWorldSpace = Vector3.zero
	local label = billboard:FindFirstChild("Amount") :: TextLabel?
	if label then
		label.TextTransparency = 1
		label.TextStrokeTransparency = 1
		local uiScale = label:FindFirstChild("Pop") :: UIScale?
		if uiScale then
			uiScale.Scale = 0
		end
	end
end

--[=[
	@within DamageNumbers
	Build the pool and pre-warm it. Idempotent — safe to call multiple times.
	If never called, the module lazy-initializes on the first `Show`.
]=]
function DamageNumbers.Init()
	if pool then
		return
	end
	local template = buildTemplate()
	pool = GenericPoolInstance.new(
		template,
		Config.Pool.InitialSize,
		Config.Pool.MaxSize,
		Config.Pool.InitialSize, -- expandSize: grow by the initial size when exhausted
		workspace,
		resetEntry
	)
	template:Destroy() -- the pool cloned it; drop our copy
end

--[=[
	@within DamageNumbers
	Enable or disable spawning of new damage numbers. In-flight numbers are not
	affected. Intended for a settings-menu toggle.
	@param value boolean
]=]
function DamageNumbers.SetEnabled(value: boolean)
	enabled = value
end

--[=[
	@within DamageNumbers
	@return boolean -- whether new damage numbers will spawn
]=]
function DamageNumbers.IsEnabled(): boolean
	return enabled
end

--[=[
	@within DamageNumbers
	Spawn a floating damage number at a world position. No-op if disabled or
	`amount <= 0`. `styleName` defaults to `Config.DefaultStyle`; an unknown
	style falls back to the default.
	@param worldPosition Vector3
	@param amount number
	@param styleName string?
]=]
function DamageNumbers.Show(worldPosition: Vector3, amount: number, styleName: string?)
	if not enabled or amount <= 0 then
		return
	end
	if not pool then
		DamageNumbers.Init()
	end
	-- Animation added in Task 3.
end

return DamageNumbers

Task 3: Animated Show (pop + rise + fade + jitter + lifecycle)​

Files:

  • Modify: src/ReplicatedStorage/SharedModules/DamageNumbers.luau (replace the Show stub and add helpers above it)

  • Step 1: Add the overshoot curve and jitter helper

Near the top of the module (after the local DamageNumbers = {} line and the state locals), add:

-- Back-out overshoot curve for the pop (alpha -> eased alpha, peaks > 1 then
-- settles to 1). MotionMaster's built-in AlphaModels has no back-out, and it
-- does NOT clamp the eased alpha, so the overshoot renders. Passed as Model.
local function backOut(t: number): number
	local c = 1.70158
	t = t - 1
	return t * t * ((c + 1) * t + c) + 1
end

-- Random symmetric offset within the configured jitter ranges.
local function jitterOffset(): Vector3
	local h = Config.Jitter.Horizontal
	local v = Config.Jitter.Vertical
	return Vector3.new(
		(math.random() * 2 - 1) * h,
		(math.random() * 2 - 1) * v,
		(math.random() * 2 - 1) * h
	)
end
  • Step 2: Replace the Show stub with the full implementation

Replace the entire function DamageNumbers.Show(...) ... end block from Task 2 with:

--[=[
	@within DamageNumbers
	Spawn a floating damage number at a world position. No-op if disabled or
	`amount <= 0`. `styleName` defaults to `Config.DefaultStyle`; an unknown
	style falls back to the default.
	@param worldPosition Vector3
	@param amount number
	@param styleName string?
]=]
function DamageNumbers.Show(worldPosition: Vector3, amount: number, styleName: string?)
	if not enabled or amount <= 0 then
		return
	end
	if not pool then
		DamageNumbers.Init()
	end

	local style = Config.Styles[styleName or Config.DefaultStyle] or Config.Styles[Config.DefaultStyle]

	-- Acquire a pooled anchor part and position it (jittered) at the hit point.
	local spawnPos = worldPosition + jitterOffset()
	local part = pool:RetrieveObject(CFrame.new(spawnPos))

	local billboard = part:FindFirstChild("Billboard") :: BillboardGui
	local label = billboard:FindFirstChild("Amount") :: TextLabel
	local uiScale = label:FindFirstChild("Pop") :: UIScale

	-- Apply style + content.
	label.Text = tostring(math.round(amount))
	label.Font = style.Font
	label.TextColor3 = style.Color
	label.TextStrokeColor3 = style.StrokeColor
	label.TextStrokeTransparency = style.StrokeTransparency
	label.TextTransparency = 0
	billboard.Size = UDim2.fromScale(
		Config.Billboard.BaseSize.X.Scale * style.SizeScale,
		Config.Billboard.BaseSize.Y.Scale * style.SizeScale
	)
	billboard.StudsOffsetWorldSpace = Vector3.zero
	uiScale.Scale = Config.Pop.StartScale

	-- One Janitor per live number; cancels tweens + the fade thread on release.
	local cleaner = Janitor.new()
	activeJanitors[part] = cleaner

	-- Pop: scale StartScale -> 1 with overshoot.
	cleaner:Add(
		MotionMaster.Play(uiScale, { Scale = 1 }, { Duration = Config.Pop.Duration, Model = backOut }),
		"Destroy"
	)

	-- Rise: drift up over the full lifetime; its completion releases the entry.
	local rise = MotionMaster.Play(
		billboard,
		{ StudsOffsetWorldSpace = Vector3.new(0, Config.Rise.Height, 0) },
		{ Duration = Config.Lifetime, Model = Config.Rise.Easing }
	)
	cleaner:Add(rise, "Destroy")

	-- Fade: starts near the end of life. Tracked so cleanup can cancel it.
	local fadeThread = task.delay(Config.Lifetime - Config.Fade.Duration, function()
		cleaner:Add(
			MotionMaster.Play(
				label,
				{ TextTransparency = 1, TextStrokeTransparency = 1 },
				{ Duration = Config.Fade.Duration, Model = "Linear" }
			),
			"Destroy"
		)
	end)
	cleaner:Add(function()
		task.cancel(fadeThread)
	end, true)

	-- On lifetime end: clean tweens and return the entry to the pool.
	rise:OnComplete(function()
		if activeJanitors[part] then
			activeJanitors[part] = nil
			cleaner:Destroy()
			pool:InsertObject(part) -- resetEntry hides it for reuse
		end
	end)
end

# Damage Numbers

`DamageNumbers` is a **client-only, render-only** module that shows floating
world-space damage numbers above targets. It does not compute or apply damage —
damage stays server-authoritative (see [CombatService](#)). Any client code
calls it with a position and an amount.

## API

| Function | Description |
| --- | --- |
| `DamageNumbers.Show(worldPosition, amount, styleName?)` | Spawn a number. No-op if disabled or `amount <= 0`. `styleName` defaults to the config default; unknown names fall back to it. |
| `DamageNumbers.SetEnabled(value)` | Toggle spawning of new numbers (for a settings menu). In-flight numbers finish. |
| `DamageNumbers.IsEnabled()` | Returns the current toggle state. |
| `DamageNumbers.Init()` | Build + pre-warm the pool. Idempotent; lazy-runs on first `Show` otherwise. Called once by `DamageNumbersController`. |

## Behaviour

Each number is a pooled `BillboardGui` (`GenericPoolInstance`). On `Show` it
acquires an entry, applies a named **style** (color/font/size/stroke), offsets
the spawn by a random **jitter** so rapid hits fan out, then animates with
`MotionMaster`:

- **Pop** — `UIScale.Scale` from `Pop.StartScale` to `1` with a back-out
  overshoot.
- **Rise** — `BillboardGui.StudsOffsetWorldSpace.Y` drifts up by `Rise.Height`
  over the lifetime.
- **Fade** — text/stroke transparency goes to `1` during the final
  `Fade.Duration`.

When the rise finishes, the entry's `Janitor` is destroyed and the part returns
to the pool. The billboard uses world-space (`Scale`) sizing, so numbers shrink
with camera distance and cull past `Billboard.MaxDistance`.

## Tuning

All tuning is in
[`Configs/DamageNumberConfig`](#): `Styles` (named presets — `normal`, `crit`,
`heal` out of the box), `Pop`/`Rise`/`Fade`/`Lifetime` timing, `Jitter`, `Pool`
sizing, and `Billboard` size/distance. Add a new look by adding a `Styles`
entry and passing its name to `Show`.

## Out of scope

No combat wiring, `Packets`, or `Signals` — a damage source (client predicted
or a server damage broadcast) calls `Show` directly. The settings menu just
calls `SetEnabled`. The toggle is not persisted.
