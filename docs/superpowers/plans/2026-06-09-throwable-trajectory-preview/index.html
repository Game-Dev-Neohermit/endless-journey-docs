Throwable Trajectory Preview Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Execution model (decided): Implementation is done by Sonnet. After each task's code steps are complete and committed, an Opus reviewer inspects that task's diff against the task spec BEFORE the next task starts — do not advance on Sonnet self-review alone. The Opus reviewer checks: correctness vs. the task's stated behavior, type consistency with earlier tasks, no placeholders, and adherence to project conventions (Janitor cleanup, no ad-hoc TweenService, no rojo build/selene runs). If the reviewer flags issues, Sonnet fixes them and the reviewer re-checks before proceeding. The final Studio verification (Task 3) is the human's, as noted there.

Goal: Show the local player a live green glowing trajectory arc, raycast-truncated to real geometry with a landing marker, while a throwable weapon (Grenade, C4) is equipped.

Architecture: A new client-only module TrajectoryPreview.luau owns a pre-allocated part pool and a RenderStepped loop. It recomputes the ballistic parabola each frame from the live camera/handle, raycasts each segment to stop at geometry, and positions reused neon parts. ThrowableHandler calls show on equip and hide on unequip. No server change, no packets — purely local cosmetic.

Tech Stack: Luau, Roblox RunService.RenderStepped, workspace:Raycast, RaycastParams (CollisionGroup = WeaponProjectile), Janitor (howmanysmall/janitor), neon BasePart pooling.

Note on testing: This project has no automated test suite — verification happens in Roblox Studio (per CLAUDE.md). "Verify" steps below are concrete Studio checks the developer performs after syncing with rojo serve. Do not run rojo build or selene (project preference).

Interface refinement vs. spec​

The spec wrote the signature as show(config). Implementation needs the tool Handle (origin point) and the local character (raycast exclusion), so the real signature is:

TrajectoryPreview.show(config: ThrowableWeaponConfig, character: Model, tool: Tool)
TrajectoryPreview.hide()

Shared constants (must match the server exactly)​

  • SPAWN_OFFSET = 2.5 — identical to ServerProjectile.SPAWN_OFFSET; the arc starts where the real clone spawns.
  • Upward aim bias Vector3.new(0, 0.25, 0) — identical to getThrowOriginDir in ThrowableHandler.
  • Gravity source: workspace.Gravity (the throwable is a plain physics body with no custom gravity).

  • Step 1: Write the full module

Create src/StarterPlayer/StarterPlayerScripts/WeaponHandlers/TrajectoryPreview.luau with exactly this content:

--!strict

--[=[
    @class TrajectoryPreview
    @client
    Client-only predictive arc for thrown weapons (Grenade, C4). While a throwable
    is equipped, `show` starts a RenderStepped loop that recomputes the ballistic
    parabola each frame from the live camera + handle, raycasts each segment to stop
    at real geometry, and positions a fixed pool of reused green neon parts plus a
    landing marker. The arc starts at the SAME offset point the server spawns the
    real clone (SPAWN_OFFSET) and uses the SAME upward aim bias as ThrowableHandler,
    so the preview matches the projectile's actual free-flight path. Purely cosmetic
    and local — no networking. `hide` tears the whole pool down via one Janitor.
]=]

local Players = game:GetService("Players")
local RunService = game:GetService("RunService")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Janitor = require(ReplicatedStorage.Packages:WaitForChild("Janitor"))
local WeaponTypes = require(ReplicatedStorage.SharedModules:WaitForChild("WeaponTypes"))

-- Must match ServerProjectile.SPAWN_OFFSET so the arc starts where the real clone spawns.
local SPAWN_OFFSET = 2.5
-- Must match getThrowOriginDir's upward lob bias in ThrowableHandler.
local AIM_BIAS = Vector3.new(0, 0.25, 0)

-- 20 sample points -> 19 segments between them.
local SAMPLE_COUNT = 20
local SEGMENT_COUNT = SAMPLE_COUNT - 1
-- Fixed flight-time horizon. The raycast truncates the arc at real geometry, so this
-- only needs to be "long enough" for the longest throw — never computed analytically
-- (an analytic 2*vy/g estimate collapses to ~0 when aiming downward).
local HORIZON = 4.0

local SEGMENT_THICKNESS = 0.18
local ARC_COLOR = Color3.fromRGB(80, 255, 140)
local MARKER_SIZE = 1.6
local MARKER_THICKNESS = 0.1
-- Raycasts behave as if cast from this collision group, so they pass through player
-- characters exactly like the real projectile (WeaponProjectile vs Character = false).
local PROJECTILE_GROUP = "WeaponProjectile"

local player = Players.LocalPlayer

local TrajectoryPreview = {}

-- Active-session state. Nil when nothing is showing.
local janitor: Janitor.Janitor? = nil
local folder: Folder? = nil
local segments: { BasePart } = {}
local marker: BasePart? = nil
local raycastParams: RaycastParams? = nil

local function makeSegment(parent: Instance): BasePart
	local part = Instance.new("Part")
	part.Anchored = true
	part.CanCollide = false
	part.CanQuery = false
	part.CanTouch = false
	part.CastShadow = false
	part.Material = Enum.Material.Neon
	part.Color = ARC_COLOR
	part.Size = Vector3.new(SEGMENT_THICKNESS, SEGMENT_THICKNESS, 1)
	part.Transparency = 1
	part.Parent = parent
	return part
end

local function makeMarker(parent: Instance): BasePart
	local part = Instance.new("Part")
	part.Anchored = true
	part.CanCollide = false
	part.CanQuery = false
	part.CanTouch = false
	part.CastShadow = false
	part.Material = Enum.Material.Neon
	part.Color = ARC_COLOR
	part.Size = Vector3.new(MARKER_SIZE, MARKER_SIZE, MARKER_THICKNESS)
	part.Transparency = 1
	part.Parent = parent
	return part
end

-- Hide every segment + the marker (used when we can't compute an arc this frame).
local function hideAll()
	for _, seg in segments do
		seg.Transparency = 1
	end
	if marker then
		marker.Transparency = 1
	end
end

-- Place one segment spanning a->b and reveal it.
local function placeSegment(seg: BasePart, a: Vector3, b: Vector3)
	local delta = b - a
	local length = delta.Magnitude
	if length < 1e-3 then
		seg.Transparency = 1
		return
	end
	seg.Size = Vector3.new(SEGMENT_THICKNESS, SEGMENT_THICKNESS, length)
	seg.CFrame = CFrame.lookAt(a, b) * CFrame.new(0, 0, -length / 2)
	seg.Transparency = 0
end

-- One frame: recompute origin/direction, sample the parabola, raycast-truncate,
-- position the pool. `character`/`tool` captured by the show() closure.
local function render(config: WeaponTypes.ThrowableWeaponConfig, character: Model, tool: Tool)
	local camera = workspace.CurrentCamera
	local handle = tool:FindFirstChild("Handle") :: BasePart?
	if not camera or not character.Parent or not handle then
		hideAll()
		return
	end

	local viewport = camera.ViewportSize
	local ray = camera:ViewportPointToRay(viewport.X / 2, viewport.Y / 2)
	local direction = (ray.Direction + AIM_BIAS).Unit
	local startPos = handle.Position + direction * SPAWN_OFFSET

	local velocity = direction * config.ThrowSpeed
	local accel = Vector3.new(0, -workspace.Gravity, 0)
	local dt = HORIZON / SEGMENT_COUNT

	-- Sample the parabola: pos(t) = start + v*t + 0.5*a*t^2.
	local points: { Vector3 } = table.create(SAMPLE_COUNT)
	for i = 0, SEGMENT_COUNT do
		local t = i * dt
		points[i + 1] = startPos + velocity * t + 0.5 * accel * (t * t)
	end

	-- Walk segments in order; raycast each. First hit truncates the arc.
	local hitResult: RaycastResult? = nil
	local hitSegment: number? = nil
	for i = 1, SEGMENT_COUNT do
		local a = points[i]
		local b = points[i + 1]
		local result = workspace:Raycast(a, b - a, raycastParams)
		if result then
			hitResult = result
			hitSegment = i
			placeSegment(segments[i], a, result.Position)
			break
		end
		placeSegment(segments[i], a, b)
	end

	-- Hide every segment past the truncation point (if any).
	if hitSegment then
		for i = (hitSegment :: number) + 1, SEGMENT_COUNT do
			segments[i].Transparency = 1
		end
	end

	-- Landing marker: at the hit (flat on the surface) or at the last sample.
	if marker then
		if hitResult then
			marker.CFrame = CFrame.lookAlong(hitResult.Position, hitResult.Normal)
			marker.Transparency = 0
		else
			marker.CFrame = CFrame.new(points[SAMPLE_COUNT])
			marker.Transparency = 0
		end
	end
end

--[=[
    @within TrajectoryPreview
    Start showing the arc for an equipped throwable. Idempotent: a second call
    tears the previous session down first. Captures `character`/`tool` for the
    per-frame origin + raycast filtering.
]=]
function TrajectoryPreview.show(config: WeaponTypes.ThrowableWeaponConfig, character: Model, tool: Tool)
	TrajectoryPreview.hide()

	local jan = Janitor.new()
	janitor = jan

	local f = Instance.new("Folder")
	f.Name = "TrajectoryPreview"
	f.Parent = workspace.CurrentCamera or workspace
	jan:Add(f, "Destroy")
	folder = f

	segments = table.create(SEGMENT_COUNT)
	for i = 1, SEGMENT_COUNT do
		segments[i] = makeSegment(f)
	end
	marker = makeMarker(f)

	local params = RaycastParams.new()
	params.FilterType = Enum.RaycastFilterType.Exclude
	params.FilterDescendantsInstances = { character, f }
	params.CollisionGroup = PROJECTILE_GROUP
	params.RespectCanCollide = true
	raycastParams = params

	jan:Add(RunService.RenderStepped:Connect(function()
		render(config, character, tool)
	end), "Disconnect")

	-- Clear module-level references when the Janitor is destroyed.
	jan:Add(function()
		segments = {}
		marker = nil
		folder = nil
		raycastParams = nil
	end, true)
end

--[=[
    @within TrajectoryPreview
    Stop showing the arc and destroy the whole pool. Safe to call when nothing
    is showing.
]=]
function TrajectoryPreview.hide()
	if janitor then
		janitor:Destroy()
		janitor = nil
	end
end

return TrajectoryPreview

Task 3: Studio verification​

Files: none (manual verification by the developer).

Sync with rojo serve and press Play in Studio. Confirm each item:

  • Step 1: Arc appears on equip. Equip the Grenade. A green glowing arc appears immediately, starting just ahead of the character and curving down to a green landing marker.

  • Step 2: Arc tracks the camera live. Sweep the camera around while standing still and while walking. The arc and marker follow the aim smoothly every frame with no flicker.

  • Step 3: Arc stops at geometry. Aim at a wall, the floor close in front of you, a rooftop edge, and straight down. Confirm the arc bends to stop at the surface (does not pass through walls), and the landing marker lies flat on the hit surface (oriented to its normal).

  • Step 4: Arc passes through characters. Aim through another player / NPC. The arc should pass through the character (not stop on them), matching how the real projectile flies.

  • Step 5: Prediction matches the throw. Throw the grenade and confirm it lands at (or very near) where the marker predicted.

  • Step 6: C4 differs by speed. Equip C4 (slower ThrowSpeed = 55 vs grenade 70). Confirm the arc is shorter/steeper accordingly, same green style.

  • Step 7: Cleanup. Unequip — the arc disappears completely (no leftover parts under Camera/workspace). Die/respawn while equipped — confirm no orphaned parts and no errors in the Output window. Equip/unequip rapidly several times — no duplicate arcs, no errors.

If any check fails, fix the module and re-verify before continuing.
