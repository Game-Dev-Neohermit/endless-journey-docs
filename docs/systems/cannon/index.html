Cannon System

A grid-placeable, manned cannon that fires server-authoritative explosive arc shells. It hosts the Cannon Damage party perk (CannonDamageBonus) and completes perk Spec 5. The cannon reuses the weapon stack (FastCast2 + ServerProjectile + CombatService.ApplyAOE) and the placement stack (PlaceableItems → PlacedObjects).

Placement → mount → fire​

  1. Place — the cannon is a placeable (PlaceableItems/Cannon + PlaceableTools/Cannon). Placement, stash, and move are inherited from the placement system; the placed clone lands in workspace/PlacedObjects with a PlaceableName = "Cannon" attribute.
  2. Mount — CannonController attaches a ProximityPrompt to each placed cannon's MountPromptPart. Triggering it sends ReqMountCannon(model); the server validates proximity + single-occupancy and records the gunner. Mounting locks the gunner's movement and shows a ballistic arc preview.
  3. Fire — input sends ReqFireCannon(muzzle, aimDir). The server validates occupancy, cooldown, and overheat, then simulates the shell from its own muzzle CFrame with a gravity Acceleration. On impact it applies Damage × (1 + CannonDamageBonus) via CombatService.ApplyAOE and broadcasts CannonFired (muzzle flash + barrel snap + sound) and ExplosionAt (boom).

Overheat​

Each shot adds HeatPerShot; heat decays at HeatDecayPerSec. Reaching MaxHeat locks the cannon for OverheatLockTime. Heat (0–1) and Overheated are attributes on the placed Model (no packet); CannonGuiController reads them to drive the gunner's heat bar.

Server authority & anti-exploit​

Occupancy, cooldown, overheat-lock, and shell origin are all re-validated server-side; the server fires from its own muzzle, so a forged origin/aim cannot help. Single occupant per cannon (a live occupant blocks takeover; a dead one is replaced). CannonDamageBonus is read server-side from the server-written PartyPerkBuffs folder per shot — unforgeable. Faction routing is inherited from CombatService, so EnemyNPC rigs must be in a hostile faction to take player damage.

EnemyShip forward seam​

CannonServer.applyCannonAOE damages Humanoids via CombatService and decrements a numeric Health attribute on in-radius models tagged EnemyShip (linear falloff, destroy at ≤0). This is inert until the future enemy-ship spec tags ships; it requires no change to the perk hook.

Key files​

  • Config: ReplicatedStorage/SharedModules/Configs/CannonConfig.luau
  • Server: ServerScriptService/CannonServer.server.luau
  • Client: StarterPlayer/StarterPlayerScripts/CannonController.client.luau, CannonGuiController.client.luau
  • Packets: ReqMountCannon, ReqFireCannon, CannonFired (impact reuses ExplosionAt)
  • Signal: OnCannonMounted
