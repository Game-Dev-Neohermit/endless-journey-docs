GrabHook

The GrabHook is a player tool that fires a tethered hook to collect floating junk. The client owns all raycasting and rope visuals; the server validates the claim and awards the item.

Data flow​

Player equips GrabHook tool
  • mouse.TargetFilter = PlacedObjects folder (so placed items don't occlude aim)
  • Signals.RequestShootingCamera:Fire(true) ──► CameraController enters aim mode

RenderStepped (every frame while equipped)
  • GetAimedJunk(): Spherecast from handle attachment toward mouse.Hit
    - radius = Physics.HitboxRadius (2 studs)
    - max distance = Physics.MaxDistance (150 studs)
    - angle gate: must be within 90° of character forward vector
  • if junk found → ShowForceField(junkPart, junkId)  [highlight effect]
  • if aim lost for > 0.08 s grace → HideForceField

Player clicks (tool.Activated)
  • cooldown check (Physics.Cooldown = 1.1 s)
  • Signals.TryClaimJunk:Fire(id, hitPoint) ──────────────────────────► JunkController
                                                                          → Packets.ReqJunkClaim → JunkService (server)
                                                                          ← BeginJunkRetract (broadcast)
  • FireGrappleAndAttach(targetPart, hitPoint, junkId, token):
    1. Instance.new("Attachment") on junk part ("HookAttachment")
    2. GrabHookVisuals.CreateBeam(handleAtt, junkAtt, targetPart)
    3. GrabHookVisuals.AnimateProjectile → three-phase animation:
         FLIGHT: junkAtt.WorldPosition lerps toward junk at Physics.Speed (200 studs/s)
                 beam curves oscillate (Amplitude=12, Frequency=40, Decay=4)
         LATCH:  single transition frame, curves flattened to 0
         RETRACT: targetPart.Position lerps back to handle at Physics.RetractSpeed (50 studs/s)
    4. on retract complete → Signals.TryFinalizeJunk:Fire(id) ─────────► JunkController
                                                                          → Packets.ReqJunkFinalize → JunkService
                                                                          ← JunkCollected (broadcast)
  • SoundManager.PlaySFXAt("GrabHookFire") — replicated to all clients
  • SoundManager.PlayLooped("GrabHookLoop") with fade-in/out scheduling

Player unequips tool
  • fireToken incremented (invalidates all pending task.delay callbacks)
  • loopHandle:Destroy()
  • Signals.RequestShootingCamera:Fire(false) ──► CameraController exits aim mode

Client / Server / Shared​

Client (GrabHook.client.luau)

  • Runs entirely as a LocalScript inside the Grabhook Tool under StarterPack.
  • GetAimedJunk(rootPart) performs a Spherecast from the handle's Attachment.WorldPosition toward mouse.Hit.Position. Junk ID is resolved by invoking GetJunkIdFromPart via BindableCore (registered by JunkController).
  • A force-field highlight (ReplicatedStorage/ForceField template cloned to workspace) tracks the currently aimed junk part on every RenderStepped tick. A 0.08-second grace window prevents flickering when the spherecast briefly misses.
  • On activation: fires Signals.TryClaimJunk (JunkController handles the network call), increments fireToken to version all pending callbacks, then calls FireGrappleAndAttach.
  • FireGrappleAndAttach creates an Attachment on the target junk part, creates a Beam via GrabHookVisuals.CreateBeam, and calls GrabHookVisuals.AnimateProjectile. When retraction completes, it fires Signals.TryFinalizeJunk and plays a positional pickup sound at the character's CollisionPart/UpperTorso/HumanoidRootPart anchor resolved by CharacterAnchor.
  • Loop sound (GrabHookLoop) is scheduled with a LoopStartDelay (0.15 s) fade-in and timed fade-out matched to the total hook animation duration.

Server (JunkService.server.luau)

  • Validates ReqJunkClaim: reconstructs junk world position from SpawnPos + MOVE_DIRECTION * (junkOdometer - SpawnOdometer), checks player distance against GrabHookConfig.Physics.MaxDistance + 15 studs, enforces per-player cooldown, and reserves the junk.
  • Validates ReqJunkFinalize: checks reservation ownership and the 5-second timeout, marks the junk collected, broadcasts JunkCollected, and gives the corresponding tool to player.Backpack.
  • See Junk for the full server-side claim/finalize detail.

Shared (GrabHookVisuals.luau)

  • CreateBeam(att0, att1, parent) — instantiates a Beam and copies all properties from GrabHookConfig.Visuals onto it.
  • AnimateProjectile(beam, startAtt, targetPart, hitPos, onCleanup) — three-phase RenderStepped loop (Flight / Latch / Retract). Aborts if targetPart leaves workspace (e.g. pool reclaim). Calls onCleanup when retraction completes or on abort.
  • AnimateObserver(beam, startAtt) — simpler decay loop for other players watching the retraction animation, started by JunkController on BeginJunkRetract.

Key files​

  • src/StarterPack/Grabhook/GrabHook.client.luau — tool activation, spherecast aim, force-field highlight, grapple animation orchestration, sound scheduling
  • src/ReplicatedStorage/SharedModules/GrabHookVisuals.luau — beam creation and projectile / observer animation loops
  • src/ReplicatedStorage/SharedModules/Configs/GrabHookConfig.luau — all physics, visuals, and sound timing constants

Gotchas​

Server proximity check uses a latency slack of 15 studs

The claim check compares the player's position against the reconstructed junk position with GrabHookConfig.Physics.MaxDistance + 15. The extra 15 studs compensates for network latency. Increasing MaxDistance without adjusting the slack (or vice versa) can allow or block claims unexpectedly.

  • Shift-lock / aim camera interplay. Equipping the GrabHook fires Signals.RequestShootingCamera(true) to enter aim mode. Unequipping fires (false) to exit. If you add another system that also drives RequestShootingCamera, ensure the signals do not conflict (last writer wins).
  • mouse.TargetFilter = PlacedObjects prevents placed items from blocking the aim raycast. If new workspace folders are added for collidable world geometry that should also be ignored, add them to the filter.
  • fireToken versioning. Incrementing fireToken on unequip cancels all pending task.delay callbacks (sound fade-out, finalize). Never skip the token check inside scheduled callbacks or sounds will play on the next hook cycle.
  • Force-field template must exist. GrabHook.client uses ReplicatedStorage:WaitForChild("ForceField") at startup. If the template is missing, the script will yield indefinitely.
  • Beam and attachment cleanup. AnimateProjectile destroys both the Beam and the HookAttachment on cleanup. If you add more attachments or constraints to the junk part during a hook cycle, extend the CleanupJunkModel function in JunkController to remove them on pool return.
  • CharacterAnchor resolves the positional SFX anchor. The pickup sound plays at CollisionPart → UpperTorso → HumanoidRootPart (first found). SingleCollider avatars that lack HumanoidRootPart but have CollisionPart are handled correctly.
