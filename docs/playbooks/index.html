How-To Playbooks

📄️Add a New Placeable Item

Use this playbook whenever you want a new item to appear in the build-mode palette and be placeable by players.

📄️Tune Stamina Economy

Use this playbook when adjusting how fast stamina drains, regenerates, or how buff pickups feel.

📄️Adjust Junk Flow

Use this playbook when tuning how frequently junk spawns, how long it survives, how fast it moves, or how tier/type probabilities are weighted.

📄️Change Sprint Behavior

Use this playbook when modifying sprint speed, FOV curve, keybinds, or sprint state-machine logic.

📄️Tune Shredder Economy

Use this playbook when adjusting hold duration, arc animation, anti-exploit tolerances, or material yield for the Workbench Shredder.

📄️Update Build Mode UI/UX

Use this playbook when changing build-mode icon assets, ghost visuals, grid overlay appearance, or the button-to-signal mapping in BuildModeGuiController.

📄️Add a Sound (SFX / Music / Ambience)

Use this whenever you need a new game sound — one-shot SFX, positional SFX, looped SFX, a music playlist, or an ambience bed.

📄️Add / Show a Toast Notification

Use this whenever a controller needs to surface a toast message to the local player — success confirmations, warnings, errors, or informational messages.

📄️Add a Network Packet (Client ↔ Server Channel)

Use this whenever a new client-to-server or server-to-client communication channel is needed.

📄️Add an In-Process Signal

Use this whenever two or more scripts on the same side (client-only or server-only) need to communicate without direct coupling — UI intents, gameplay events, or state change notifications.

📄️Enable Stash / Move on a Placeable

Use this when you have a new placeable item and want players to be able to return it to their Backpack (Stash) or immediately re-equip it (Move) from its in-world GUI.

📄️Tune Perks

Use this playbook when adjusting perk values, adding a new perk, or wiring a perk to a new consumer.
