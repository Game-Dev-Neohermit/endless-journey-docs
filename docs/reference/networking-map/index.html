Networking Map

Update this table in the same commit when you add a packet — see also the Add a Packet playbook.

All client↔server traffic goes through Packets (ReplicatedStorage/SharedModules/Packets/init.luau). Never create raw RemoteEvent or RemoteFunction instances outside that module. Reliable packets wrap a typed Packet; high-frequency positional packets use UnreliableRemoteEvent via the makeUnreliable helper.

PacketDirectionTypePurpose
ClientToggleGhostC->SRemoteEventNotify server that the local player entered or exited build mode (isActive, itemName). Server relays via ServerToggleGhost.
ServerToggleGhostS->AllRemoteEventBroadcast another player's build-mode state change (player, isActive, itemName).
ClientUpdateGhostC->SUnreliableRemoteEventHigh-frequency (~20 Hz) ghost CFrame stream from the local player to the server.
ServerUpdateGhostS->OthersUnreliableRemoteEventRelay of another player's ghost CFrame to all other clients.
PlaceItemC->SRemoteEventPlacement request: ray origin, ray direction, rotation degrees, isGridMode flag.
SpawnJunkS->CRemoteEventTell a client's JunkController to spawn a junk visual: (id: U16, modelName: String, startPos: Vector3F32).
SetJunkSpeedS->AllRemoteEventBroadcast new target junk movement speed (targetSpeed: NumberF32, studs/sec). First receipt snaps currentSpeed; subsequent receipts smoothstep-ramp over JunkConfig.SPEED_RAMP_DURATION. Fired on train-state changes and to each joining player.
JunkCollectedS->AllRemoteEventNotify all clients that junk was collected (id, collector) — triggers pool cleanup.
ReqJunkClaimC->S (response)RemoteFunctionReserve junk for the requesting player (id, hitPos). Server validates cooldown and broadcasts BeginJunkRetract. Returns Boolean8 success.
ReqJunkFinalizeC->S (response)RemoteFunctionAward junk after retraction completes (id). Server validates reservation then fires JunkCollected. Returns Boolean8 success.
BeginJunkRetractS->AllRemoteEventBroadcast retraction start (id, fromPos, duration, player) so every client animates its local junk visual toward the collector.
StaminaSprintIntentC->SRemoteEventSprint intent signal from client to server (isSprinting: Boolean8).
StaminaStateSyncS->CRemoteEventAuthoritative stamina sync (currentStamina: F32, isSprinting: Boolean8).
StaminaBuffSyncS->CRemoteEventBuff state sync (isInfinite: Boolean8, regenMultiplier: F32, usageMultiplier: F32).
HealthStateSyncS->CRemoteEventAuthoritative health sync (currentHealth: F32).
ReplicateSoundAtLocationC->S then S->OthersRemoteEventPositional sound replication. SoundManager sends; ReplicatedSoundService relays to other clients with rate-limit + allowlist from SoundConfig.GetReplicatedIds() (SFX defs with Replicate=true). Payload: (Location: Vector3F32, SoundConfig: {Id, Volume, Pitch}).
CreateTweenS->CRemoteEventTweenPlus: create a tween instance (id: U8, target: Instance, tweenInfo, goals).
StartTweenS->CRemoteEventTweenPlus: start a tween (id: U8, ...).
StopTweenS->CRemoteEventTweenPlus: stop a tween (id: U8).
ResetTweenS->CRemoteEventTweenPlus: reset a tween (id: U8).
DestroyTweenS->CRemoteEventTweenPlus: destroy a tween (id: U8).
ReqShredderStartC->S (response)RemoteFunctionShredder handshake step 1: validate proximity + junk count; record session start. Returns (isValid: Boolean8, holdDuration: F32, reasonCode: U8).
ReqShredderCompleteC->S (response)RemoteFunctionShredder handshake step 2: validate timing, proximity, junk count; consume junk. Returns (success: Boolean8, woodCount: U16, metalCount: U16, reasonCode: U8).
PickupItemClaimedS->AllRemoteEventProximity pickup: item claimed by a player (itemId: String, claimer: Player).
PickupItemReadyS->CRemoteEventProximity pickup: item registered and ready to hover (handle: BasePart, itemId: String). Triggers HoverEffect on client.
RequestDropC->SRemoteEventDrop the active craft-material Tool. No payload — server infers item from character:FindFirstChildWhichIsA("Tool") and spawns a world handle with an impulse.
ReqStashPlaceableC->S (response)RemoteFunctionValidate + destroy placed model + grant Tool to Backpack (targetModel: Instance). Returns (success: Boolean8).
ReqMovePlaceableC->S (response)RemoteFunctionSame as Stash but also auto-equips the Tool when a Humanoid exists (targetModel: Instance). Returns (success: Boolean8).
BroadcastPlaceablePoofS->AllRemoteEventVisual + sound poof cue at destroyed model location (pivot: CFrameF32U16, placeableName: String, isMove: Boolean8). Played by every client.
RequestPlacementRevertC->S (response)RemoteFunctionCancel a Move session and revert the item to its stored original spot if free. No payload. Returns Boolean8 reverted. Sent by PlacementClient (cancelPlacement); handled by PlacementServer (OnServerInvoke). Reads PlaceableRevertStore; returns true if the item was re-placed, false if the spot was occupied or no entry existed (client then unequips the tool to Backpack).
TrainStateSyncS->AllRemoteEventBroadcast train fuel state (fuel: F32, rate: F32, isBraked: Boolean8, isStalled: Boolean8, serverTime: F64). Fired on events (refuel, brake toggle, stall, resume, init) and to each joining player. Clients extrapolate locally between events.
SetMusicContextS->CRemoteEventSwitch the client's BGM context (context: String) — a playlist name in SoundConfig.Music.Playlists. Fired by MusicService.SetContext from server gameplay events (pirate attack, outpost/camp). MusicDirector consumes it; "Normal" clears combat.
ReqRefuelTrainC->S (response)RemoteFunctionFeed Energy junk into engine (smallest-first, up to cap) (engine: Instance). Returns (success: Boolean8, fuelAdded: F32, reasonCode: U8).
ReqToggleBrakeC->S (response)RemoteFunctionToggle brake lever (lever: Instance). Returns (success: Boolean8, isBraked: Boolean8, reasonCode: U8).
ReqMeleeSwingC->SRemoteEventRequest a melee swing. No payload — server infers the weapon from the equipped Tool, validates rate/combo, and applies authoritative damage via CombatService.
WeaponImpactS->AllRemoteEventBroadcast a melee/impact hit so every client renders impact FX + sound (position: Vector3F32, weaponName: String). Consumed by WeaponEffectsController.
ReqFireWeaponC->SRemoteEventFire the equipped hitscan gun (origin: Vector3F32, direction: Vector3F32). Server infers the weapon from the equipped Tool and validates rate/ammo/reload-lock/origin-distance, then casts its own authoritative range-capped ray. Non-finite origin/direction are rejected.
ReqReloadWeaponC->S (response)RemoteFunctionReload the equipped gun. No payload. Returns (accepted: Boolean8, reloadTime: NumberF32) (0 if rejected). On accept the server schedules the magazine refill and pushes WeaponMagSync + AmmoPoolSync at completion.
WeaponFiredS->AllRemoteEventBroadcast a gun shot so non-shooters render tracer/impact (shooter: Player, weaponName: String, origin: Vector3F32, endpoint: Vector3F32, isHit: Boolean8). WeaponEffectsController ignores the local player (the shooter draws its own tracer in GunHandler).
WeaponMagSyncS->CRemoteEventAuthoritative magazine count to the owning client (weaponName: String, mag: NumberU16). Sent on equip, after each shot, and on reload completion; reconciles GunHandler's predicted magazine via AmmoApi.
AmmoPoolSyncS->CRemoteEventAuthoritative pool count to the owning client (ammoType: String, amount: NumberU16). Fired by AmmoManager on every pool mutation (shot, reload, craft); reconciles AmmoApi's cached pool.
ReqThrowProjectileC->SRemoteEventThrow the equipped throwable (grenade or C4) (origin: Vector3F32, direction: Vector3F32). Server infers the weapon from the equipped Tool, validates Throwable category/cooldown/origin-distance (NaN-safe), and spawns a server-owned, replicated physics projectile via ServerProjectile. Grenade detonates on a fuse timer; C4 (Manual) is tracked and detonated by ReqDetonate. Non-finite origin/direction are rejected.
ReqDetonateC->SRemoteEventDetonate all of the requester's active manual throwables (C4). No payload. WeaponServer.onDetonate reads each tracked instance's position and detonates via CombatService.ApplyAOE + ExplosionAt, destroying the instances.
ExplosionAtS->AllRemoteEventBroadcast an explosion so every client (including the source) renders one boom FX + sound (center: Vector3F32, radius: NumberF32, weaponName: String). Used by rocket + grenade + C4; damage is applied server-side via CombatService.ApplyAOE.
XPStateSyncS->CRemoteEventAuthoritative XP snapshot to the owning client (level: U8, xpIntoLevel: U32, xpForNextLevel: U32). Sent on profile load and every XP change; bridged to Signals.OnXPChanged by XPController.
XPLevelUpS->CRemoteEventNotify the owning client they leveled up (level: U8). XPController shows a toast; reserved as the hook for future level rewards.
CoinStateSyncS->CRemoteEventAuthoritative coin balance to the owning client (balance: U32). Sent on profile load and every balance change; bridged to Signals.OnCoinsChanged by CoinController.
ReqTechSubmitC->S (response)RemoteFunctionSubmit materials toward a tech node (nodeId: String, materialType: String, amount: NumberU16). Server re-checks bench proximity + TechTreeState.validateSubmit + that the player holds amount Tools, then consumes exactly that many. Returns (success: Boolean8, reason: NumberU8) (TechTreeResultCodes). On full funding the node auto-unlocks.
ReqTechCancelC->S (response)RemoteFunctionCancel a node's funding (nodeId: String) — anyone at the bench may cancel. Refunds the pooled materials as a ProximityPickup ground pile via MaterialEjector. Returns (success: Boolean8, reason: NumberU8).
TechNodeUpdateS->AllRemoteEventPer-node delta broadcast on every change (nodeId: String, metalSubmitted: NumberU16, woodSubmitted: NumberU16, isUnlocked: Boolean8). Typed to the two current materials; widens if a third is added.
ReqTechSnapshotC->S (response)RemoteFunctionRequest the full tech-tree snapshot on GUI init / join. No payload. Returns (state: Any) — serialized { unlocked, pools }.
ReqAllocatePerkC->S (response)RemoteFunctionSpend one point on a perk (perkId: String). Server validates via PerkState.canAllocate and mutates PerkLevels. Returns (success: Boolean8, reasonCode: NumberU8) (PerkResultCodes).
ReqRespecPerksC->S (response)RemoteFunctionRespec a pool (pool: NumberU8): 0 = both, 1 = Personal, 2 = Party. Clears matching PerkLevels entries; points return automatically. Returns (success: Boolean8).
PerkStateSyncS->CRemoteEventAuthoritative perk snapshot to the owning client (perkLevels: Any, personalAvailable: NumberU8, partyAvailable: NumberU8). Sent on profile load, allocate, respec, and level-up.
TrainShieldSyncS->AllRemoteEventBroadcast authoritative shield state (currentShield: F32, maxShield: F32). Event-driven (on damage, recharge, or buff change) and a full send to each joining player via FireClient. No serverTime — the shield has no continuous drain, so clients need no extrapolation. Consumed by TrainShieldController → Signals.OnTrainShieldChanged → TrainShieldGuiController.
ReqRechargeShieldC->S (response)RemoteFunctionFeed the player's Energy tools into a ShieldConsole (smallest-ShieldRecharge-value-first, up to maxShield, never over-filled) (console: Instance). Returns (success: Boolean8, shieldAdded: F32, reasonCode: U8) (TrainResultCodes). Mirrors ReqRefuelTrain.
SyncVolumesS->CRemoteEventDeliver a player's saved audio bus volumes on join (volumes: {[string]: number}). Client applies them directly to the SoundGroup buses without re-saving.
SaveVolumeC->SRemoteEventPersist one bus volume change (group: String, volume: NumberF32). SettingsManager validates the bus against an allowlist and clamps [0,10].

Cannon System​

PacketDirectionPayloadSent byReceived by
ReqMountCannonClient → Server (Response: Boolean8)cannon Model or nilCannonControllerCannonServer
ReqFireCannonClient → Server (Response: Boolean8, NumberF32)muzzle origin, aim directionCannonControllerCannonServer
CannonFiredServer → all Clientsgunner, muzzle origin, initial velocityCannonServerCannonController

Cannon impact reuses ExplosionAt. Cannon heat uses Heat/Overheated attributes on the placed Model, not a packet.

Workbench Crafting System​

PacketDirectionPayloadSent byReceived by
ReqCraftClient → Server (Response: Boolean8 success, NumberU8 code)Instance bench Model, String recipeIdWorkbenchGuiControllerWorkbenchService

Response codes are defined in WorkbenchResultCodes. The bench Instance is proximity-re-checked server-side; the client is never trusted for distance.
